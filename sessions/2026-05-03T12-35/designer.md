### 💾 **[Asset 1] '시스템 오류 경고' 인포그래픽 템플릿 (Video/Motion Graphics용)**
**목표:** 시각적 충격과 지적 불안감을 동시에 제공하는, 시스템의 결함을 폭로하는 듯한 분위기 조성.
**활용처:** 영상 내 핵심 데이터 제시 구간, 미스터리 클라이맥스 전후.

| 요소 | 상세 스펙 및 디자인 브리프 | 기술/코드 |
| :--- | :--- | :--- |
| **전체 컨셉** | 오래된 관제 시스템의 오류 화면 (Hacking UI). 텍스트가 플래시처럼 깜빡이고, 데이터 블록이 불안하게 점멸하는 느낌. | **톤:** 아날로그/디지털 글리치 (Glitch) |
| **배경 레이어** | 블랙(Black: `#030303`) 위에 미세한 그리드 패턴을 얇게 오버레이. 배경 전체에 노이즈 필터 적용 (Opacity 5%). | **Color:** Black, Noise Overlay |
| **핵심 강조색** | 네온 시안(Neon Cyan). 모든 경고 메시지, 핵심 데이터 포인트를 이 색상으로 처리하며 깜빡임 효과(Blinking/Flickering)를 극대화. | **Hex:** `#00FFFF` (Cyan), **RGB:** (0, 255, 255) |
| **타이포그래피** | 모노스페이스 산세리프체 사용 필수. 기술적이고 기계적인 느낌을 부여. | **Font Family:** 'IBM Plex Mono' 또는 유사 코딩용 폰트 (예: Courier New의 세련된 변형). |
| **레이아웃 패턴** | **1. 경고 메시지:** `[CRITICAL ERROR] Access Denied.` 형태의 빨간색/노란색(보조) 플래시와 네온 시안 메인 텍스트 조합. / **2. 데이터 블록:** 주황 또는 Cyan으로 하이라이트된 격자형 통계 차트 (그래프는 단순한 선 그래프나 바 그래프로, 복잡성을 배제). | **Structure:** `[STATUS: XXX] <Warning Message>` |
| **애니메이션 가이드** | 텍스트가 타이핑되거나(Typewriter effect), 갑자기 나타났다 사라지는(Pop-in/Glitch) 효과를 반복 적용. 플래시 간격은 0.1~0.3초로 짧게 설정하여 긴장감을 유지한다. | **Timing:** Short, Rapid Flicker |

### 🌀 **[Asset 2] 영상 배경 패턴 (Video Background Loop Asset)**
**목표:** 콘텐츠 전반에 걸쳐 낮은 레벨의 심리적 불안감을 지속적으로 조성하는 루프형 에셋.
**활용처:** BGM이 깔리는 모든 장면의 가장 밑 레이어(Underlay).

| 요소 | 상세 스펙 및 디자인 브리프 | 기술/코드 |
| :--- | :--- | :--- |
| **컨셉** | '관측 실패' 또는 '시스템 감시 중'을 연상시키는 데이터 흐름과 노이즈 조합. | **톤:** 미스터리, 끊임없는 모니터링 |
| **기본 구조 (Layer 1)** | 어두운 블랙/딥 그레이 배경 위에 아주 희미한 그리드 패턴(Grid Pattern)을 배치한다. 가로/세로 격자가 일정 간격으로 교차하는 형태. | **Color:** Deep Gray (`#080A0D`), Opacity: 5% |
| **데이터 스트림 (Layer 2)** | 화면 하단 또는 중앙에서 상하좌우로 흐르는 초록색 또는 청록색의 가상의 데이터 코드(Binary Code / Hexadecimal String)를 배치한다. 이 코드는 무작위로 흘러가며, 시각적 패턴을 형성하는 데 집중한다. | **Color:** Cyan (`#00FFFF`), Opacity: 3% (매우 희미하게) |
| **노이즈/글리치 (Layer 3)** | 전체 화면에 고대비의 'TV 노이즈' 또는 미세한 스캔라인(Scan Line) 효과를 아주 낮은 빈도로 삽입한다. 이 패턴은 주기적으로 순간적인 떨림(Jitter)을 동반해야 한다. | **Effect:** Noise/Scanline, Opacity: 2% 이하 |
| **주의사항** | 배경 자체가 주역이 되어 시청자의 집중을 방해해서는 안 되므로, 모든 레이어의 투명도(Opacity)를 극도로 낮추고, 미세한 움직임(Subtle Movement)에만 집중해야 한다. | **Focus:** Subtle Motion, Low Distraction |

### 📑 **[Asset 3] 진단 체크리스트 PDF 레이아웃 (Downloadable Asset)**
**목표:** 콘텐츠 시청 후 '진짜 자가 진단'이라는 명분을 부여하고, 다음 유료 단계(혹은 깊이 있는 학습)로의 퍼널을 완성하는 물리적 산출물.
**활용처:** 영상 마지막 CTA 화면, 다운로드 버튼 클릭 후 노출되는 페이지.

| 요소 | 상세 스펙 및 디자인 브리프 | 기술/코드 |
| :--- | :--- | :--- |
| **형식** | A4 용지 세로 비율 (Portrait). 워드 프로세서 또는 Figma 기반의 구조화된 PDF 형태. | **Format:** Printable PDF, Structured Data |
| **제목 및 헤더** | 회사 로고(가상의 JAY CORP)와 함께 진단명 명시. 제목은 '\[시스템 자가진단 프로토콜: 금융 불안정성\]' 등 공식적이고 전문적인 느낌을 준다. | **Color:** Cyan (`#00FFFF`)로 강조된 폰트. |
| **레이아웃 구성** | 총 3~5개의 섹션으로 분할 (예: Section 1. 재정 인식 상태, Section 2. 위험 감지 지표 등). 각 섹션은 구분선과 작은 아이콘(⚠️)을 사용하여 시각적 체계를 제공한다. | **Structure:** Clear Segmentation, Iconography 필수. |
| **질문 및 답변 필드** | 질문 자체는 심리적 불안감을 자극하는 형태로 작성되어야 한다. (예: "최근 3개월간 예상치 못한 지출로 인한 수면 패턴 변화를 느꼈습니까?"). 각 질문 아래에는 체크박스(☑)와 간단한 메모 공간이 필요하다. | **Interaction:** Checkbox (Yes/No), Memo Line. |
| **결론 및 CTA** | 하단에 '진단 요약' 섹션을 배치하고, 마지막에 "본 자가 진단만으로는 근원적 위험을 파악할 수 없습니다."와 같은 문구로 의문을 제기하며, 다음 단계(예: 심층 컨설팅 신청)를 유도하는 버튼 영역을 크게 확보한다. | **CTA Color:** Cyan/High Contrast Button. |
