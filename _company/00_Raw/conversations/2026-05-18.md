#### 🔥 ⭐ [최우선/Anomaly Burst용] 리스크 포인트 1: 핵심 자원 공급망의 지정학적 취약성

*   **핵심 개념:** '탈(脫)공급'으로 인한 전방위 시스템 마비. (Self-RAG 기반: ② 기술적 한계, ③ 핵심 광물)
*   **스토리텔링 플롯:** 20세기 초반의 자원 전쟁이 아닌, **현대 첨단 문명을 지탱하는 '보이지 않는 혈관'**의 차단에 집중합니다. (예: 리튬, 희토류).
*   **Anomaly Burst 자료 (추천):**
    1.  **시각화:** 글로벌 반도체 칩 생산 공정(Fab) 다이어그램이 그려지다가, 특정 원자재 공급 노드에서 **'RED ALERT: SUPPLY INTERRUPTED'** 경고등과 함께 데이터가 끊기는 애니메이션.
    2.  **데이터/카피 (0:31-0:33):** "전 세계 에너지와 AI를 움직이는 핵심 광물 X의 주요 공급처가 지정학적 분쟁으로 인해 **최소 18개월간 봉쇄될 경우**, 글로벌 경제는 [XX]년 단위로 계산된 '파국적 슬럼프'에 진입합니다." (구체적인 수치 공백을 만드는 것이 중요)

#### ⚡️ [깊은 불안감 유발] 리스크 포인트 2: 에너지 및 물류 시스템의 '연쇄적 실패' (Cascading Failure)

*   **핵심 개념:** 한 영역의 오류가 다른 영역으로 파급되는 구조적 취약점. (Self-RAG 기반: ① 에너지 시스템, Self-RAG 기반: ① 물류 지연)
*   **스토리텔링 플롯:** 기후 변화나 전염병 같은 '외부 충격'이 아닌, **시스템 자체의 복잡성(Complexity)** 때문에 발생하는 연쇄 반응을 보여줍니다. (예: 특정 항만 노동 분쟁 $\rightarrow$ 컨테이너 적체 $\rightarrow$ 핵심 광물 운송 차질 $\rightarrow$ 반도체 공장 가동 중단).

*   **강조점:** 복잡성 이론을 차용하여, 인간의 예측 범위를 벗어난 '시스템 고유의 실패'임을 지적해야 합니다.

#### 🧠 [가장 근본적인 위협] 리스크 포인트 3: 인지적 판단 능력(Judgment)의 만료화 (Cognitive Obsolescence)

### 2. ✨ Basic Tier: 미니 리드 마그넷 구체화 및 가치 제안(Value Proposition)

Basic Tier는 *구매하는 것이 아니라, '불확실성을 잠시 해소'하는 경험*을 판매해야 합니다.

**✅ 상품명:** [시스템 위험] Quick Scan: 핵심 취약점 즉시 진단 리포트
**✅ 가격:** ₩9,900 (충동적 구매를 유도하는 심리적 저항선 하에 배치)
**✅ Value Proposition:** "당신의 시스템에서 **가장 치명적인 단 하나의 오류 지점**을 3초 만에 찾아냅니다." [근거: Self-RAG 메모리]

**💡 Basic Tier의 구체적 가치 제안 설계 (The Hook):**
1.  **진단 범위 한정:** "종합 분석이 아닌, 가장 높은 위험도를 가진 단일 항목만 점검합니다." (Scope Limitation)
2.  **결과물의 불완전성:** 리포트에는 **'Red Flag Score (위험 지수)'**와 **'오류 발생 영역(예: 전력 흐름의 3번째 노드)'**만 제시하고, 그 이유나 해결책은 아예 언급하지 않습니다.
    *   *(효과):* 고객은 "어디가 문제인지 알았지만, 왜 문제가 생겼는지 모르겠다"라는 **지식적 공백(Knowledge Gap)**을 느끼게 됩니다. 이것이 Standard Tier로 이동할 강력한 동기 부여가 됩니다.

2.  **활용 원칙:** 모든 텍스트는 기본적으로 **글리치/스캔라인(Glitch/Scanline)** 필터를 통과한 것처럼 처리되어야 합니다. 완벽하게 깨끗하고 부드러운 느낌은 절대 금지입니다.

    *   **[Type 2: 데이터 전송]:** `Neon Cyan`을 사용하여 글자의 아웃라인이나 간격에 미세한 노이즈/반복(Scanline) 효과를 준다. **사용:** 전문 용어, 시간 코드, 중요한 수치 제시 시.

## III. 핵심 UI 컴포넌트 블루프린트 (Core Components Blueprint)

### 1. [🚨 경고문 / Warning Sign Component]
*   **구조:** 화면의 상단 중앙 또는 좌측에 고정 배치(Fixed Position).
*   **색상:** 배경은 `Deep Black` 위에, 테두리/아이콘은 **`Alert Red`**.
*   **요소:**
    1.  [🚨] 아이콘 (크고, 깜빡임 효과 필수)
    2.  "SYSTEM ALERT" 또는 "WARNING" 텍스트 (Type 1 Glitch 적용)
    3.  (선택적) 경고 코드: `ERROR CODE [XXXX]` (Neon Cyan으로 빠르게 흘러나가는 애니메이션)
*   **활용 시점:** 스크립트의 도입부(Hook)와 문제 제기 단계(Tension Build-up)에서 반드시 사용하여, 영상 시작부터 '무언가 잘못되었다'는 인식을 심는다.

### 2. [⏰ 시간 코드 및 데이터 추적 레이아웃 (Timeline Overlay)]
*   **구조:** 화면의 좌측 하단 또는 우측 하단을 가로지르는 반투명한(Opacity 0.8) 네온 시안 바 형태로 고정 배치.
*   **기능:** 현재 스크립트의 시간 흐름을 시각적으로 명시한다. (예: `[T+0:15]`)
*   **디자인 로직:**
    1.  시간 코드가 제시될 때, 해당 섹션의 주요 키워드(예: 'Veracity')가 Neon Cyan으로 하이라이트되며 바 위로 팝업되듯 표시된다.
    2.  섹션 전환 시 (예: `[3-15초]` $\rightarrow$ `[15-30초]`), 배경의 스캔라인 패턴이 짧게 일렁이며 다음 단계로 넘어감을 알린다.

### 3. [🌐 정보 흐름/분열 레이아웃 (Data Breakdown Matrix)]
*   **구조:** 복잡한 개념이나 데이터를 설명할 때 사용되는 그리드(Grid) 형태의 임시 오버레이.
*   **목적:** '정보 과부하'를 시각화한다.
*   **디자인 로직:**
    1.  세 개의 가상 데이터 필드(`A`, `B`, `C`)가 좌우로 배열된다.
    2.  실제 정보(예: Deepfake, AI 생성)는 Neon Cyan의 데이터 스트림 형태로 A와 B에 동시에 표시되지만, 이 둘을 연결하는 **"진실성(Veracity)"** 필드는 빈 공간이거나 `Alert Red`의 노이즈로 가득 차 있어 '정보의 불일치성'을 극대화한다.

---
*   **요약 실행 계획:** 스크립트 진행에 맞춰, (1) 경고문으로 시작 $\rightarrow$ (2) 일반 설명 시에는 [시간 코드]를 사용하며 Neon Cyan 데이터 스트림으로 정보를 채움 $\rightarrow$ (3) 위기 고조 시에는 [정보 흐름/분열 레이아웃]과 Type 1 Glitch 효과(Red)를 폭발적으로 사용하여 긴장감을 최고조로 끌어올린다.
