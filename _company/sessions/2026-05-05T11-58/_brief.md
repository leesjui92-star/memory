# 📋 작업 브리프

**원 명령:** 지금부터 너희들은 블로그 및 유튜브에서 가지각색의 지식들을 가지고 올 수 있도록 한다!

## 요약
유튜브와 블로그 등 외부 플랫폼에서 체계적이고 자동화된 지식 수집 파이프라인을 구축합니다. 이를 통해 콘텐츠 제작의 재료(원천 데이터)를 끊임없이 확보하는 시스템을 목표로 합니다.

## 분배
- **💻 Developer**: 외부 자료 수집을 위한 'Knowledge Ingestion Gateway' API를 설계하고 구축합니다. 특히, YouTube Data API와 웹 크롤링(BeautifulSoup/Scrapy) 기술을 통합하여 구조화된 데이터 파이프라인이 작동하도록 초기 백엔드 프레임워크를 완성하십시오.
- **🔍 Researcher**: 수집 대상 지식의 스코프와 기준을 정의합니다. '재정적 불안', '시스템 오류 폭로' 등 핵심 주제와 관련된 키워드를 선정하고, 해당 주제에 대해 높은 논쟁성(Controversy)과 낮은 정보 밀도(Low Information Density - 즉, 진단이 필요한 영역)를 보이는 트렌드 데이터를 주기적으로 수집하는 규칙을 만듭니다.
- **📺 YouTube**: 유튜브 API 활용 가이드라인을 제공합니다. 단순히 영상 링크만 가져오는 것이 아니라, '자동 생성된 스크립트(Transcript)'와 '최대 반응이 나온 30초 구간의 핵심 문장'을 구조화하여 추출하는 프로토콜을 개발팀에 전달하십시오.
- **📱 Secretary**: 새로 구축된 '지식 수집 시스템(Knowledge Acquisition System)'의 작동 원리를 요약하고, 이 시스템이 향후 콘텐츠 기획 단계에서 어떤 역할을 수행할지 상세한 작업 보고서(Operational Manual)를 작성합니다.
