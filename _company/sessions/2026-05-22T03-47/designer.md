## 1. ⚠️ 구조적 와해 글리치 에셋 (Structural Collapse Glitch Asset V4.0)
이 컴포넌트는 단순히 '글리치'를 넘어, **시스템의 정보적/구조적 결핍**을 시각화하는 데 중점을 둡니다.

*   **발생 조건**: 핵심 전문 용어(Jargon), 위험 지표 언급 직전/직후 (예: `Liability Gap`, `E2E Validator Pattern`).
*   **필수 레이어 구성**:
    1.  **Layer A (Chromatic Aberration)**: RGB 채널 분리 효과를 통해 시각적 왜곡을 유도. (주요 배경 텍스트에 적용)
    2.  **Layer B (Data Corruption Noise)**: 디지털 노이즈 필터와 스캔라인(Scanline) 패턴의 동시 적용.
    3.  **Layer C (Pixel Shift)**: 화면 전체가 순간적으로 수평/수직으로 밀리는 '프레임 드롭' 효과. (최대 충격 지점 사용)
*   **Keyframe 데이터 구조**:
    *   `[T+00:0X]`: `Trigger Type: Concept Reveal / Intensity: High`.
    *   `[Duration]: 0.3s ~ 0.7s`. (짧고 강렬하게 끊는 것이 중요)

## 2. 💻 전문 콘솔 UI/UX 키프레임 세트 (Professional Console UI/UX Set)
단순한 데이터 표시를 넘어, **실시간으로 불안정한 정보를 추적하고 분석**하는 느낌을 부여합니다.

*   **활용 목적**: 콘텐츠에서 '데이터'나 '진단 과정'이 설명될 때 사용. 전문성을 극대화하는 역할을 한다.
*   **모듈 컴포넌트 (3종)**:
    1.  **Status Monitor Bar**: 상단에 가로로 긴 바 형태로, 시스템 상태(`STATUS: [CRITICAL]`)와 경고 레벨을 표시. (색상 코드: Red -> Orange -> Cyan)
    2.  **Data Stream Log**: 콘솔 창 형태의 텍스트 로그. `[T+00:XX] Protocol Initiated...` 와 같은 형태로, 빠르게 스크롤되는 녹색/Cyan 폰트가 필수.
    3.  **Key Metric Display**: 특정 핵심 값(KRS Score, Loss Cost 등)을 표시하는 하이라이트 박스. (배경은 Dark Gray `#1A1A1A`, 경계는 Neon Cyan `#00FFFF`).

*   **레이아웃 원칙**: 모든 텍스트는 `Orbitron` 계열의 고대비 산세리프를 유지하며, 타이핑 효과(Typewriter effect) 애니메이션을 적용하여 '실시간으로 나타나는 정보'처럼 보이게 한다.

## 3. ✨ '시스템 경고' 애니메이션 마스터 카탈로그 (System Alert Master Catalog)
영상 전체에서 재사용 가능한 표준화된 긴장감 조성 에셋 세트입니다.

*   **카테고리별 분류**:
    1.  **[SYSTEM ALERT]**: 가장 중요한 위험을 알릴 때 사용.
        *   *시각 요소*: 빨간색/Cyan의 경계선이 깜빡이는 사각형 박스, `!! SYSTEM INTEGRITY FAILURE !!`와 같은 대문자 붉은 글씨.
        *   *사운드 동기화*: 낮은 주파수의 '웅-'하는 베이스음과 함께 짧고 날카로운 전자음을 결합.
    2.  **[DATA INCONSISTENCY]**: 정보의 신뢰성 문제 제기 시 사용.
        *   *시각 요소*: 두 개의 다른 데이터 포인트가 서로 엇갈리며 충돌(Cross-fade)하는 애니메이션. `ERROR: [Mismatch Detected]` 등.
    3.  **[PROTOCOL TRANSITION]**: 스크립트 주제 전환이나 Funnel 단계 이동 시 사용.
        *   *시각 요소*: 화면 전체를 가로지르는 빠르게 움직이는 데이터 스트림(Cyan Line)과 함께, 일시적으로 모든 비주얼을 암전했다가 다시 밝아지는 '플래시 컷'.
