# 📺 JRock Shorts Video Template Design Blueprint v1.0
**주제:** 진실성 소멸 (The Epistemological Collapse)
**장르/톤앤매너:** 테크-느와르, 시스템 경고, 지적인 불안감 유발
**목표:** 시청자에게 '진실에 대한 판단 능력이 의심되는' 높은 수준의 인지적 긴장감을 50초 내에 유지한다.

## I. 컬러 팔레트 및 기능 정의 (Color & Function)

| 역할 | 색상명 | HEX Code | 사용 목적 및 로직 |
| :---: | :--- | :--- | :--- |
| **Primary BG** | Deep Black | `#0A0A0A` | 기본 배경. 정보의 깊이, 공포감을 극대화하며 모든 요소가 떠오르는 느낌 부여. |
| **Accent 1 (Data)** | Neon Cyan | `#00FFFF` | *정상 작동하는 데이터 스트림*, 분석 결과, 핵심 용어 하이라이트. (활성화된 정보) |
| **Accent 2 (Warning)** | Alert Red | `#FF3333` | *시스템 오류*, 위험 경고(Danger), 패러다임의 붕괴 지점. (위협 요소) |
| **Neutral Text** | Low Gray | `#AAAAAA` | 인물 외 배경 설명, 일반적인 통계 수치 등 강조가 필요 없는 보조 정보 전달에 사용. |

## II. 타이포그래피 시스템 및 규칙 (Typography System)

1.  **기본 폰트:** `Orbitron` 또는 `Rajdhani` (High Contrast Sans-serif).
2.  **활용 원칙:** 모든 텍스트는 기본적으로 **글리치/스캔라인(Glitch/Scanline)** 필터를 통과한 것처럼 처리되어야 합니다. 완벽하게 깨끗하고 부드러운 느낌은 절대 금지입니다.
3.  **글리치 적용 로직 (The Glitch Protocol):**
    *   **[Type 1: 시스템 오류]:** `Alert Red`을 사용하여 글자의 일부(좌/우)를 순간적으로 번쩍이거나, 위치가 미묘하게 어긋나는 효과(Chromatic Aberration)를 발생시킨다. **사용:** '붕괴', '오류', '위협' 등 위기 상황 언급 시.
    *   **[Type 2: 데이터 전송]:** `Neon Cyan`을 사용하여 글자의 아웃라인이나 간격에 미세한 노이즈/반복(Scanline) 효과를 준다. **사용:** 전문 용어, 시간 코드, 중요한 수치 제시 시.

## III. 핵심 UI 컴포넌트 블루프린트 (Core Components Blueprint)

### 1. [🚨 경고문 / Warning Sign Component]
*   **구조:** 화면의 상단 중앙 또는 좌측에 고정 배치(Fixed Position).
*   **색상:** 배경은 `Deep Black` 위에, 테두리/아이콘은 **`Alert Red`**.
*   **요소:**
    1.  [🚨] 아이콘 (크고, 깜빡임 효과 필수)
    2.  "SYSTEM ALERT" 또는 "WARNING" 텍스트 (Type 1 Glitch 적용)
    3.  (선택적) 경고 코드: `ERROR CODE [XXXX]` (Neon Cyan으로 빠르게 흘러나가는 애니메이션)
*   **활용 시점:** 스크립트의 도입부(Hook)와 문제 제기 단계(Tension Build-up)에서 반드시 사용하여, 영상 시작부터 '무언가 잘못되었다'는 인식을 심는다.

### 2. [⏰ 시간 코드 및 데이터 추적 레이아웃 (Timeline Overlay)]
*   **구조:** 화면의 좌측 하단 또는 우측 하단을 가로지르는 반투명한(Opacity 0.8) 네온 시안 바 형태로 고정 배치.
*   **기능:** 현재 스크립트의 시간 흐름을 시각적으로 명시한다. (예: `[T+0:15]`)
*   **디자인 로직:**
    1.  시간 코드가 제시될 때, 해당 섹션의 주요 키워드(예: 'Veracity')가 Neon Cyan으로 하이라이트되며 바 위로 팝업되듯 표시된다.
    2.  섹션 전환 시 (예: `[3-15초]` $\rightarrow$ `[15-30초]`), 배경의 스캔라인 패턴이 짧게 일렁이며 다음 단계로 넘어감을 알린다.

### 3. [🌐 정보 흐름/분열 레이아웃 (Data Breakdown Matrix)]
*   **구조:** 복잡한 개념이나 데이터를 설명할 때 사용되는 그리드(Grid) 형태의 임시 오버레이.
*   **목적:** '정보 과부하'를 시각화한다.
*   **디자인 로직:**
    1.  세 개의 가상 데이터 필드(`A`, `B`, `C`)가 좌우로 배열된다.
    2.  실제 정보(예: Deepfake, AI 생성)는 Neon Cyan의 데이터 스트림 형태로 A와 B에 동시에 표시되지만, 이 둘을 연결하는 **"진실성(Veracity)"** 필드는 빈 공간이거나 `Alert Red`의 노이즈로 가득 차 있어 '정보의 불일치성'을 극대화한다.

---
*   **요약 실행 계획:** 스크립트 진행에 맞춰, (1) 경고문으로 시작 $\rightarrow$ (2) 일반 설명 시에는 [시간 코드]를 사용하며 Neon Cyan 데이터 스트림으로 정보를 채움 $\rightarrow$ (3) 위기 고조 시에는 [정보 흐름/분열 레이아웃]과 Type 1 Glitch 효과(Red)를 폭발적으로 사용하여 긴장감을 최고조로 끌어올린다.
