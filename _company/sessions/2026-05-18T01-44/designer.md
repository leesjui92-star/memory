### 🛠️ [산출물] SST Blueprint v4.0: Mini-LP & Result Report 공통 디자인 시스템 사양서

**목표:** 구매 유도(Mini-LP)와 데이터 수집/신뢰 구축(Report)의 시각적 통일성을 극대화하여, JRock이 제시하는 모든 과정이 하나의 '전문적인 진단 프로토콜'처럼 느껴지게 한다.
**톤앤매너:** 긴급성, 권위적 경고 (Critical Warning), 정밀함 (Precision).

#### 1. 핵심 컬러 팔레트 업데이트 및 역할 정의

| 요소 | 색상 코드 | 명칭/역할 | 적용 원칙 | 근거 |
| :--- | :--- | :--- | :--- | :--- |
| **배경** | `#0A0A0A` (Deep Black) | 기본 배경. 정보의 깊이와 미스터리 조성. | 모든 섹션에 통일적으로 적용. | [근거: Designer 검증된 지식] |
| **Primary Accent** | `#00FFFF` (Neon Cyan) | 정상 작동 데이터, 핵심 성공 메시지, 활성 요소 강조. | 시스템의 '표준' 데이터 스트림. | [근거: Designer 개인 메모리] |
| **Warning Accent** | `#FF3366` (Crimson Red) | **시스템 오류 발생**, 경고문구(Critical Alert), 사용자 입력 실패 지점. | 사용자의 주의를 가장 강력하게 끌어야 하는 곳에 제한적 사용. | [근거: CEO 지시 사항 반영] |
| **Neutral Accent** | `#AAAAAA` (Medium Gray) | 일반 텍스트, 비활성화된 데이터 필드, 구분선. | 정보 과부하 방지 및 가독성 확보. | [근거: Designer 검증된 지식] |

#### 2. 타이포그래피 시스템 (Typographic System)

*   **폰트:** `Orbitron` 또는 `Rajdhani` 계열 (고대비, 기하학적 Sans-serif).
*   **규칙:** 모든 텍스트는 기본적으로 글리치/스캔라인 필터가 적용된 것처럼 처리한다.
*   **계층 구조:**
    1.  **H1 (Title):** `Orbitron` Bold. 크기 최대로, 가장 강한 Glitch 효과를 부여한다. (`[SYSTEM ALERT]`)
    2.  **H2 (Section Title):** `Orbitron` SemiBold. Cyan 강조색과 함께 좌측에 경고 바(Warning Bar)를 삽입하여 섹션을 구분한다.
    3.  **Body Text:** 일반적인 가독성을 위해 약간 더 넓은 간격의 Sans-serif를 사용하되, 배경 위에 미묘한 스캔라인 패턴을 오버레이 한다.

#### 3. 핵심 인터랙션/시각 효과 (The Glitch Protocol v4.0)

모든 위젯과 상호작용 요소는 단순한 애니메이션이 아닌, **'시스템 로직의 실패를 시뮬레이션하는 과정'**처럼 보이게 해야 합니다.

1.  **글리치(Glitch):** 텍스트가 나타나거나 업데이트될 때, 순간적으로 색상이 번지거나(`RGB Shift`), 수평으로 왜곡되는 효과를 부여한다. (강도: 강함)
2.  **스캔라인(Scanline):** 전체 인터페이스 위에 미세한 가로줄 패턴을 오버레이하여 '모니터 화면' 같은 느낌을 유지하고, 아날로그적인 긴장감을 조성한다.
3.  **데이터 흐름 시각화 (Data Stream Visualizer):** 중요한 데이터가 로딩되거나 처리될 때, Cyan 네온 빛의 점(Dot)들이 빠르게 흘러가는 애니메이션을 배경에 지속적으로 적용하여 '실시간으로 무언가가 작동하고 있다'는 착각을 준다.

#### 4. Mockup 컴포넌트 설계 (Mini-LP 및 Report 공통)

**[컴포넌트명: Diagnostic Input Module]**
(이 모듈은 Mini-LP의 핵심 진단 섹션과, Basic Tier 구매 후 결과 보고서의 데이터 입력/확인 부분에 모두 사용되어야 합니다.)

*   **목적:** 사용자로부터 '민감한' 데이터를 신뢰성 있게 수집하는 것. (UX 관점에서 높은 신뢰도와 통제감을 부여)
*   **구조:** 3개의 주요 필드 그룹으로 구성한다.
    1.  **필드 제목:** `[Required] 프로토콜 코드 입력:` (`Neon Cyan` 강조).
    2.  **입력 필드 (Input Field):** 다크 그레이 배경에, 현재 커서가 깜빡이는 애니메이션을 적용한다. (글리치 효과를 미세하게 주어 '전기적' 느낌 부여)
    3.  **유효성 검사(Validation Feedback):**
        *   **정상 입력:** 필드 테두리가 Cyan으로 은은하게 빛난다. (`[PROTOCOL ACCEPTED]`)
        *   **오류 입력 (Red):** 사용자가 잘못된 값을 넣으면, 해당 필드가 **빨간색 경고 블록**(`Crimson Red` 배경)으로 순간 변하며 `[ERROR: PARAMETER OUT OF BOUNDS]` 메시지를 글리치 효과와 함께 띄운다.

**[컴포넌트명: Final System Output Panel (The Button)]**
(Mini-LP의 구매 버튼, Report의 최종 리포트 다운로드 버튼 등 중요한 액션 지점에 사용)

*   **디자인:** 단순한 버튼이 아닌, 시스템 콘솔 창에 박혀 있는 **'강제 실행 명령 프롬프트'**처럼 디자인한다.
*   **텍스트 예시 (Mini-LP):** `INITIATE_PROTOCOL(BASIC_TIER)? [CONFIRM]`
*   **상호작용:** 마우스 오버 시, 버튼 주변에서 Cyan 네온빛의 스캔라인이 흐르며 긴장감을 고조시킨다. 클릭 직전에는 '시스템 과부하' 경고음과 함께 텍스트가 글리치 효과로 빠르게 깜빡여야 한다.
