## 📐 핵심 애니메이션 컴포넌트 디자인 브리프 (3종)

### I. [Hook] 정보 흐름 차단 시스템 (Information Flow Interruption System)
**목표:** 콘텐츠 초반부(T+0:00 ~ T+0:15)에 시청자의 주의를 강제로 붙잡고, 현재 접하는 정보의 신뢰성에 의문을 제기한다. '지금 보고 있는 것이 완벽하지 않다'는 지적 불안감을 극대화한다.
**Funnel 역할:** 문제 인식 (Problem Recognition)

| 요소 | 상세 브리프 | 애니메이션/로직 전제 |
| :--- | :--- | :--- |
| **시각 효과** | **글리치 폭주(Glitch Cascade):** 화면 전체에 걸쳐 데이터 패킷이 강제로 끊어지거나 겹치는 현상. 컬러 채널 분리가 동반된다. | `T+0:01`부터 주기적으로 (0.5초 간격) 발생하며, 최초에는 미세한 노이즈로 시작하여 점차 화면을 가득 메운다. |
| **데이터 변형** | **채널 시프트(Channel Shift):** 텍스트나 주요 그래픽 요소가 RGB 채널별로 순간적으로 분리되어 옆으로 번져 나가는 효과를 적용한다. | 핵심 키워드 등장 시, 해당 단어 주변의 네온 시안(`\#00FFFF`) 경계선이 파랗고(Blue), 마젠타색(Magenta)과(Green)으로 미세하게 찢기며 오버레이된다. |
| **사운드 싱크** | **아키텍처적 왜곡:** 데이터가 끊어질 때마다 짧은 고주파수 노이즈(High-Frequency Noise Burst)와 함께 '삐-' 하는 아날로그적인 오류 경고음(`T+X` 기준). | 사운드가 시각적 글리치 발생 타이밍에 완벽하게 동기화되어, 오감을 동시에 자극한다. |
| **결과물 전제** | 모든 텍스트는 `Orbitron` 계열의 고대비 산세리프체를 사용하며, 일반적인 영상 편집 효과를 넘어선 '데이터 손상'처럼 보이도록 구현해야 한다. | [근거: Designer 개인 메모리 - 글리치 효과 로직]

### II. [Concept Definition] 비선형적 데이터 파편화 시각화 (Non-linear Data Fragmentation)
**목표:** 전문 개념(예: D.I.S., 메타데이터, A-Sync Protocol 등)을 설명할 때 사용한다. 정보가 너무 복잡하여 인간의 일반적인 사고방식으로는 처리 불가능하다는 인상을 주어, '전문가의 도움이 필요하다'는 결론으로 유도한다.
**Funnel 역할:** 전문 개념 정의 (Expert Concept Definition)

| 요소 | 상세 브리프 | 애니메이션/로직 전제 |
| :--- | :--- | :--- |
| **구조적 형태** | **노드 네트워크 붕괴(Node Network Collapse):** 중앙의 핵심 노드에서 파생된 수많은 데이터 라인(SVG 벡터 기반)들이 무질서하게 확장되다가, 갑자기 일부가 끊기거나 잘못된 경로로 연결되는 과정을 보여준다. | `T+X` 시간에 맞춰 다양한 색상(Neon Cyan 외의 낮은 채도 블루/그린 계열 사용)의 선들이 3차원적으로 움직이며 충돌하는 모습을 연출한다. |
| **데이터 표현** | **시간적 불일치성:** 그래프나 파형이 시간 축(`Time Axis`)을 따라 이동하지만, 특정 지점에서 갑자기 시간이 뒤로 가거나(Rewind), 빠르기가 달라지는 비선형적인 흐름을 보여준다. | 시청자에게 '이건 일반적인 데이터 분석 툴로는 볼 수 없는 오류 패턴이다'라는 인식을 심어준다. 그래프 위에 `[ERROR: TIME PARADOX DETECTED]` 경고 메시지가 오버레이된다. |
| **강조 기법** | **데이터 파편화(Data Sharding):** 핵심 개념을 설명하는 텍스트가 한 번에 나타나지 않고, 여러 조각(Shard)으로 분해되어 화면 여기저기에 퍼졌다가 재조립되는 과정을 반복한다. | 각 조각은 무작위 위치에서 진동하며 (Vibration Effect), 시청자의 집중력을 유지시키고 정보 습득의 어려움을 체감하게 한다. |
| **결과물 전제** | 모든 요소는 벡터 기반 애니메이션으로 구현하여, 어떤 크기에서도 선명한 '시스템 내부'를 들여다보는 듯한 느낌을 준다. | [근거: Designer 개인 메모리 - 시스템 오류 경고 인포그래픽 템플릿]

### III. [CTA] 통제실 UI (Control Room Interface)
**목표:** 콘텐츠의 마지막 부분(T+X ~ End)에서, 시청자가 경험한 '불안감'을 해결할 수 있는 유일한 경로가 **외부 서비스/컨설팅**임을 명확히 인지시킨다. 공포 분위기에서 전문적인 해결책 제시로 전환하는 역할을 한다.
**Funnel 역할:** 불안감 증폭 및 전환 (Anxiety Amplification & Conversion)

| 요소 | 상세 브리프 | 애니메이션/로직 전제 |
| :--- | :--- | :--- |
| **전환 장치** | **시스템 리셋(System Reset):** 모든 혼란스러운 글리치와 파편화된 데이터가 일순간에 멈추고, 화면 전체가 깊은 블랙 (`\#0A0A0A`)으로 클리어된다. 마치 시스템이 강제 재부팅되는 느낌이다. | `T+X` 시점에 맞춰 '삐-익' 하는 전력 차단 사운드와 함께 화면의 모든 노이즈가 사라진다. 이 순간에야 비로소 구조화된 UI가 나타난다. |
| **UI 구성** | **대시보드 오버레이:** 좌측 상단에 `[STATUS: CRITICAL]` 경고창을, 우측 하단에 '진단 의도 점수(D.I.S.)'를 계산하는 가상 인터페이스를 배치한다. | UI는 투명한 블랙/다크 그레이 배경과 네온 시안 테두리를 가진 Glassmorphism 스타일로 구현하여 전문성과 신뢰도를 확보한다. [근거: Designer 개인 메모리 - 관제 센터 Dashboard 브리프] |
| **CTA 액션** | **'Audit Required' 강조:** 중앙에 거대한 '진단 의도 점수(D.I.S.) 부족' 경고 문구를 배치하고, 그 아래에 오직 하나의 버튼만 빛나도록 한다. | 이 CTA 버튼은 단순한 클릭 유도가 아니라, **시스템의 필수 결함 수정**처럼 보이게 연출해야 한다. 버튼 활성화 시 미세하게 깜빡이는 (Blinking) 효과를 적용한다. |
| **최종 메시지** | "당신의 데이터는 외부 진단이 필요합니다."와 같은 권위적이고 단정적인 톤으로 마무리하며, 프로필 링크 클릭을 '유일한 해결책'처럼 제시한다. | [근거: Designer 개인 메모리 - 최종 CTA 화면의 Control Room UI 적용]
