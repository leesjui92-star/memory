# Master Thumbnail Visual Specification: Anomaly Loop (Final)

## 🎨 Design System Applied: Neon Cyan / High Contrast
*   **Background:** #000000 (Pure Black)
*   **Primary Accent Color:** #00FFFF (Neon Cyan) - Used for main text and data flow.
*   **Secondary Accent Color:** #FF0000 (Bright Red) - Used for critical warnings.

## 🖼️ Layout & Composition
*   **Aspect Ratio:** 16:9 (Standard YouTube Thumbnail).
*   **Core Visual:** Extreme close-up of a glitching circuit board or abstract data flow visualization, emphasizing visual instability.

## ✍️ Element Placement & Style
1.  **Centerpiece (A):** The main image must convey critical failure. Use digital artifacts and scan lines to enhance the 'Anomaly Loop' feeling.
2.  **Primary Text (B - HOOK):** "당신의 시스템에 경고등이 들어왔다고요?" or "CRITICAL FAILURE".
    *   **Font:** Monospace style (e.g., Orbitron).
    *   **Color:** #00FFFF (Neon Cyan).
    *   **Placement:** Top 25% of the frame, highly visible.
3.  **Warning Elements (C):** Key error codes (e.g., ERROR CODE 404, DATA DRIFT) must be overlaid using **#FF0000 (Red)** outlines or shadows to create immediate high contrast and urgency against the Cyan.
4.  **Background Effect (D):** Subtle, low-opacity cyan grid lines or data streams should flow across the background to reinforce the 'Neon Cyan/High Contrast System' aesthetic.

## 🎯 Final Impression Goal
To immediately trigger a sense of **technical anxiety and urgency**, positioning the content as a vital warning about unseen system flaws.
