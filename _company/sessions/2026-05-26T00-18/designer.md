# ⚙️ T+25s & T+36s 경고 에셋 모듈: 컴포지션 블루프린트 (AE/PR용)

**목표:** 지식 공백(Knowledge Gap) 유도와 시스템적 결함 진단 시각화. 단순 이미지가 아닌, 영상 흐름에 자연스럽게 오버레이되는 인터랙티브 UI 형태로 구현.
**렌더링 포맷:** ProRes 422 HQ (모션 그래픽 레이어 분리 가능하도록 Alpha Channel 포함)
**기본 배경 컴포지션 설정:** Deep Black (`#0A0A0A`)

---

## ⚠️ 공통 핵심 요소 정의 (Common Layers)

| ID | 레이어 이름 | 사양 및 역할 | 애니메이션 로직 (키프레임 지침) |
| :---: | :--- | :--- | :--- |
| L-Time | **시간 코드 마커** | `[T+XXs]` 형식. 네온 시안 (`#00FFFF`). | *지속성:* 1초 간격으로 깜빡임(Blink) 효과 적용. 시스템이 작동함을 암시하는 미묘한 노이즈 필터링 필수. |
| L-Grid | **배경 그리드/데이터 흐름** | 어두운 배경 위에 희미하게 빛나는 가상의 회로도나 데이터 라인 (Low Opacity, `#1A1A1A`). | *애니메이션:* 느리고 불규칙한 워핑(Warping) 효과. 미세한 스캔라인 노이즈를 지속적으로 발생시켜 '작동 중' 느낌 부여. |
| L-Glit | **글리치 오버레이** | 텍스트/이미지 위에 적용되는 시스템 오류 시각화 필터. | *트리거:* 경고문 등장 순간 (0프레임)에 강하게 노이즈와 색상 분리(Chromatic Aberration)를 주고, 서서히 사라지게 처리하여 충격을 극대화. |

## 🧩 T+25s: '데이터 비일치성' 모듈 (Data Inconsistency Module)

**발생 시점:** 스크립트의 핵심 정보가 공개된 직후, 지식적 공백을 유도하는 구간 시작.
**주요 색상:** 네온 시안 (`#00FFFF`) / 다크 그레이 (`#444444`).
**배치 원칙:** 화면 중앙 또는 좌측 상단에 경고창 형태로 배치.

| 레이어 이름 | 내용 및 목적 | 애니메이션 키프레임 로직 |
| :--- | :--- | :--- |
| L-Box | **경고 프레임 (Warning Box)** | 'SYSTEM ALERT: DATA INCONSISTENCY DETECTED' 텍스트와 함께 경계선 처리. | *등장:* `[T+25s]` 시점 정확히 등장하며, 좌우에서 빠르게 확대(Scale)되며 진동 효과를 준 후 정지. (0.1초 트랜지션). |
| L-Data | **비일치 데이터 플로우** | 'Protocol Mismatch', 'Source Deviation' 등 전문 용어 및 그래프 형태의 오류 데이터 스트림. | *애니메이션:* 좌측에서 우측으로 빠르게 흘러가다가, 특정 지점에서 멈추고 네온 시안색으로 격렬하게 떨리는(Vibrating) 움직임 연출. (Luna의 Audio Peak와 동기화 필수). |
| L-Text | **핵심 경고 문구** | "당신이 가진 정보는 불완전합니다." 혹은 더 기술적인 용어 ("Missing Parameter: X"). | *등장:* 타이핑(Typewriter) 효과로 점진적으로 나타나게 하되, 마지막 단어에서 글리치 필터를 강하게 적용하며 깜빡임. |

## 🚨 T+36s: '구조적 결함 진단' 모듈 (Diagnostic Failure Module)

**발생 시점:** 문제 인식의 깊이를 더하고, 궁극적인 해결책(컨설팅/상품)에 대한 필요성을 조성하는 구간.
**주요 색상:** 강한 대비를 이용한 Red Accent (`#FF4444`)와 Neon Cyan 조합. (긴장감 극대화).
**배치 원칙:** 화면 전체를 뒤덮는 오버레이 방식으로, 마치 시스템이 다운되는 듯한 위압감을 조성.

| 레이어 이름 | 내용 및 목적 | 애니메이션 키프레임 로직 |
| :--- | :--- | :--- |
| L-Over | **오류 아웃라인** | 화면 전체를 덮는 빨간색(Red)의 깜빡이는 사각형 또는 와이어프레임 그리드. | *애니메이션:* 주기적으로 (예: 0.5초 간격) 강도와 크기가 변하는 플리커링(Flickering/Strobe) 효과 적용. 불안정함을 극대화함. |
| L-Diagnostic | **결함 진단 그래프** | 'Critical Failure Rate', 'Risk Level' 등의 그래프가 실시간으로 폭주하며 오버레이 되는 시각 자료. | *애니메이션:* 지표가 0에서 최고치(100%)로 급상승하는 애니메이션을 보여주고, 최대치 도달 순간에 시스템이 강하게 다운되는 듯한 '픽셀 블록 깨짐' 효과를 주입. (강력한 Sub-Bass Boom과 동기화). |
| L-CTA | **진단 결과 문구** | "Manual Intervention Required." 또는 "Diagnostic Protocol Failure."와 같은 명확하고 절박한 톤의 메시지. | *등장:* 마치 녹화된 CCTV 화면에 빨간색으로 '검열'되듯이, 좌우에서 강하게 스캔 라인(Scanline)이 지나가며 나타나게 한다. |
