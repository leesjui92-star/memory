CEO님의 지시는 프로젝트의 핵심을 관통하는 요구사항입니다. 단순히 영상을 예쁘게 꾸미는 것을 넘어, **데이터 자체를 시각적 긴장감으로 변환시키는 '디자인 시스템'** 구축이 목표입니다 [근거: CEO의 지시].

## 💡 데이터 기반 핵심 비주얼 모듈 (Dynamic Components) 스펙

### 📐 공통 디자인 가이드라인 (Global Settings)
모든 모듈은 다음의 기본 설정을 따릅니다.

*   **기본 배경:** `#0A0A0A` (Deep Black).
*   **글리치/디지털 노이즈 필터:** 모든 텍스트 및 UI 요소에 미묘한 스캔라인(Scanline)과 글리치(Glitch) 효과를 기본으로 적용합니다. [근거: Designer 검증된 지식]
*   **폰트:** `Orbitron` 또는 `Rajdhani`. (글리치 필터 통과 시뮬레이션).
*   **시간 코드 표기:** 모든 모듈 시작점에는 시간 코드를 강제적으로 삽입합니다. 예: `[T+01:23]`

### 🔴 Module 1: 시스템 경고 및 실패 지표 (Protocol Failure Indicator)

이 모듈은 **데이터 무결성 문제**가 발생했을 때 작동하며, 콘텐츠의 긴장감을 최고조로 끌어올리는 역할을 합니다.
*   **트리거 데이터:** `SchemaValidationError` 발생 또는 특정 위험 지수(예: `Risk_Level > 0.8`) 초과 시. [근거: Writer 스크립트 모듈 2]
*   **주요 기능:** 실패의 심각도에 따라 색상과 빈도를 변화시켜 경고합니다.

| 단계 | 데이터 상태 (조건) | 비주얼 사양 (Visual Spec) | 애니메이션 로직 (Animation Logic) | 지속 시간 (Duration) |
| :--- | :--- | :--- | :--- | :--- |
| **Level 1 (Warning)** | `SchemaValidationError` 발생. 경미한 데이터 불일치 감지. | `#FFCC00` (Amber Yellow)의 깜빡이는 네온 라인과 'WARNING' 텍스트. 글리치 효과는 미세하게 적용. | 좌우로 느리게 움직이며(Horizontal Drift), 주기적으로 밝기가 변하는 플래싱 효과. | 1~2초 |
| **Level 2 (Critical)** | 핵심 데이터 필드(`Core_Payload`) 누락 또는 로직 오류 감지. | `#FF3B30` (Digital Red)을 주조색으로 사용하며, 'CRITICAL ERROR' 문구와 함께 전체 화면에 노이즈/글리치 오버레이 발생. | 빠르게 진동(Rapid Oscillation), 사운드 싱크를 맞춰 강한 펄스 효과(`Pulse Effect`)와 함께 나타남. | 2~3초 (가장 긴) |
| **Level 3 (Collapse)** | 시스템 전체 마비/정보적 공백 연출 필요 시. | 모든 색상 정보 손실, 오직 `[STATIC NOISE]` 패턴만 남음. `#0A0A0A` 배경에 무작위로 빨간색과 cyan의 노이즈 점들이 흩뿌려짐. | 화면 전체가 순간적으로 왜곡되며(Warping), 마치 아날로그 TV 신호 끊김처럼 빠르게 깜빡임(Stutter Effect). | 0.5초 (극단적인 짧음) |

### 🔵 Module 2: 데이터 흐름 추적 및 메타데이터 오버레이 (Data Flow Tracker)

이 모듈은 복잡한 전문 정보를 제시하거나, 시스템 내부 작동 원리를 설명할 때 사용합니다.
*   **트리거 데이터:** `Master Data Schema`의 여러 필드가 순차적으로 참조되거나 처리될 때 (`Payload Processing`). [근거: Designer 개인 메모리]
*   **주요 기능:** 데이터가 마치 전기 신호처럼 흐르고, 중요한 '노드'에서 빛을 발하는 시각적 경험 제공.

| 요소 | 비주얼 사양 (Visual Spec) | 애니메이션 로직 (Animation Logic) | 역할 및 타이밍 |
| :--- | :--- | :--- | :--- |
| **데이터 스트림** | 네온 시안(`#00FFFF`)의 가느다란 빛나는 선(Glowing Line). 마치 광섬유 케이블처럼 보임. | 좌측에서 우측으로 끊김 없이 부드럽게 흐름 (Continuous Flow Motion). 흐르는 속도는 데이터 중요도에 비례하여 조절 가능. | **전환/정보 제시:** 새로운 개념이나 데이터를 설명할 때 화면 하단 또는 중앙을 가로지르며 배경처럼 작동. |
| **데이터 노드** | `#00FFFF`의 작은 원형(Orb)으로 시작, 데이터 처리 완료 시 빛이 강해짐. | `[T+XX:YY]` 시간 코드와 함께 'Node ID'를 표시하며 팝업. 활성화 순간 주변에 짧은 글리치 효과가 발생함. | **중요 포인트:** 전문 용어나 핵심 개념을 설명하는 단어 뒤에 노드를 생성하여 집중도를 높임. |
| **스키마 매칭** | 데이터 스트림 위로 투명한 와이어프레임 박스가 겹쳐지며, 필드 이름(`Field Name: X`)이 하단에서 떠오름. | 와이어프레임은 `[T+XX:YY]`에 맞춰 '스캔'되듯이 지나가며(Scanning Effect), 매칭되는 데이터 노드를 Neon Cyan으로 강하게 강조함. | **전문성 강화:** 청중에게 '우리는 시스템의 작동 원리를 꿰뚫어 본다'는 지적 우위를 제공. |

### ✨ Module 3: 시간 왜곡/현실 균열 효과 (Temporal Glitch)

이 모듈은 극적인 순간(Climax, Reveal)에 사용되며, 현실 자체가 불안정하다는 심리적 공포를 극대화합니다.
*   **트리거 데이터:** 스크립트의 감정적 클라이맥스 지점 또는 핵심 진실 공개 직전 (Script Cue Point). [근거: Writer 개인 메모리]
*   **주요 기능:** 화면 자체에 물리적인 결함이 생긴 듯한 착시 효과를 유도.

| 요소 | 비주얼 사양 (Visual Spec) | 애니메이션 로직 (Animation Logic) | 사용 목적 및 타이밍 |
| :--- | :--- | :--- | :--- |
| **수평 왜곡** | 화면 전체가 가로 방향으로 여러 개의 레이어(Layer)로 분리되는 효과. 각 레이어는 미세하게 색상/위치가 다름 (Chromatic Aberration). | 매우 빠르게, 찰나의 순간에 수평적으로 늘였다 줄이는 애니메이션 (`Stretch & Snap`). 노이즈 필터와 결합하여 '찢어지는' 느낌 강조. | **긴장감 고조:** 중요한 단서가 화면에 나타나기 직전, 시청자의 초점을 산만하게 하여 긴장을 유도. |
| **픽셀화** | 이미지/텍스트가 갑자기 저해상도의 픽셀 블록으로 깨지는 현상 (Pixelation). | `[T+XX:YY]` 지점에서 부드럽게 픽셀 단위로 분해되었다가, 마치 마법처럼 다시 원래의 선명한 형태로 복원됨. | **진실 공개/전환:** '이것은 진짜 정보가 아니다'라고 속였다가(Fake), 갑자기 진실을 폭로하며(Reveal) 사용. |
