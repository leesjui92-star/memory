# ⚙️ 유튜브 쇼츠 마스터 배포 체크리스트 (KPI V5.0)
**(주제: 자가진단만으로는 놓치기 쉬운, 당신 차의 시스템 오류 Top 3)**

## 1. 📝 제목 최적화 (The Hook & Clickbait Structure)
**목표:** 클릭률(CTR) 최대화 및 '궁금증 유발' 기반 이탈 방지.
**원칙:** [질문형/충격 결과 제시 구조]를 따르되, 자동차 정비 불안감을 직접 건드립니다.

| 항목 | 세부 가이드라인 | 예시 제목 (최종 후보) | 데이터 근거 |
| :---: | :---: | :---: | :---: |
| **핵심 후크** | "당신도 모르는/놓치기 쉬운" + [숫자] + [위험 요소] 제시. | 🚨 자가진단만으론 놓치는, 당신 차의 시스템 오류 TOP 3 (경고 신호 체크) | Self-RAG 메모리 - 구체적 목표 / 레오 개인 메모리 |
| **SEO 보강** | 메인 키워드(하이브리드, 진단, 배터리 등)를 제목 초반에 배치. | [필수확인] 하이브리드 차량의 치명적인 시스템 오류 3가지 (배터리/인버터 진단) | Self-RAG 메모리 - 구체적 목표 / 레오 개인 메모리 |
| **최종 선택** | 가장 충격적이면서도 정보성이 높은 버전으로 확정. | **[🚨 경고] 자가진단으로는 절대 알 수 없는, 하이브리드차 시스템 오류 3가지** | (합성) |

## 2. ✍️ 설명란 최적화 (The Funnel Map & SEO Keyword Set)
**목표:** 검색 엔진 유입(SEO) 극대화 및 영상 시청자가 다음 단계(CTA)를 자연스럽게 밟도록 설계.
**원칙:** 상위 3줄에 핵심 키워드를 반복 배치하고, CTA 링크를 노출합니다.

### A. 상단 3줄 (검색엔진 최적화 영역)
1.  **(Hook/질문)** "혹시 이런 경고등이 뜨거나 이상한 소리가 들린 적 있나요? 일반적인 점검으로는 알 수 없는, 차량 시스템의 미세하고 치명적인 오류 신호가 있습니다." [근거: Self-RAG 메모리 - 내레이션]
2.  **(핵심 키워드 반복)** "특히 하이브리드나 전기차는 배터리, 인버터 등 전력 계통에서 '패턴 이탈' 형태의 데이터 오류를 보일 수 있어 전문가 진단이 필수입니다." [근거: Self-RAG 메모리 - 내레이션]
3.  **(CTA 유도)** "✅ **[System Anomaly Diagnostic Report]** : 단순 자가진단을 넘어선 근본 원인 분석 보고서가 필요하다면, 여기를 클릭하세요." (클릭 가능한 링크)

### B. 본문 및 하단 CTA
*   **시간 코드 배치:** 영상의 핵심 정보 구간을 시간 코드로 명시하여 시청자 만족도와 체류 시간을 높입니다. (예: 03:15 - 인버터 전력 패턴 오류 분석 / 06:20 - 배터리 셀 간 데이터 불일치 지점)
*   **CTA 재강조:** "더 전문적이고 깊이 있는 진단 리포트를 원하시면, 아래 링크를 통해 [Diagnostic Report]를 확인하세요. (Limited Time Offer)"

## 3. #️⃣ 최종 태그 묶음 (The Algorithmic Boost Kit)
**목표:** 노출 가능성을 최대화하기 위해 광범위한 키워드(Broad)와 극도로 구체적인 니치 키워드(Niche)를 조합합니다. (최대 개수 활용 권장)

| 유형 | 태그 예시 | 목적 및 근거 |
| :---: | :---: | :---: |
| **🔥 Broad Tags (노출 범위)** | `#자동차정비` `#하이브리드차` `#전기차` `#CarDiagnosis` `#기술지식` | 트래픽 볼륨이 큰 일반 카테고리로 노출 기회 확보. [근거: Self-RAG 메모리 - 구체적 목표] |
| **💡 Niche Tags (전문성/권위)** | `#인버터오류` `#배터리진단` `#SystemAnomaly` `#차량전력계통` `#하이브리드경고등` | 시청자의 '정보 획득 의도'에 맞는 고품질 트래픽 유입. [근거: Self-RAG 메모리 - 모든 구조] |
| **🔗 Long-Tail Tags (검색 최적화)** | `자가진단 방법`, `차량 오류 코드 해석`, `하이브리드 배터리 수명` | 특정 질문을 가진 시청자를 정확히 포획. 낮은 경쟁도, 높은 전환율 목표. |

---
**최종 실행 요약:**
1.  **제목**: 가장 충격적인 제목으로 설정하여 CTR 확보.
2.  **설명란 상단 3줄**: 불안감 조성 → 정보 제공(Keyword) → 상품 구매 유도(CTA). 이 흐름을 절대 깨지 마십시오.
3.  **태그**: 넓은 범위와 깊은 전문성을 동시에 커버하는 조합으로 알고리즘 점수를 최고로 올립니다.
