### II. 개발자 및 디자이너 역할 분담 정리
**🛠️ Developer 필수 구현 사항:**
1.  **Mock API Trigger 관리:** 위 표에 명시된 모든 시간대별 `TRIGGER_XXX`는 단순한 텍스트가 아니라, 영상 편집 엔진 내에서 특정 시점에 **실제 데이터 처리 로직(예: 경고 코드 발동)**을 수행하는 인터랙티브 모듈로 구현되어야 합니다.
2.  **데이터 흐름 API:** '데이터 드리프트'와 관련된 노드 깜빡임 및 연결선 파괴 효과는 단순 VFX가 아닌, 시간 기반의 상태 변화를 가진 데이터 시각화 로직으로 처리해야 합니다.

**🎨 Designer 필수 컴포넌트 (LDIM):**
1.  **Error Code Overlay:** 빨간색/Cyan 조합의 경고문 UI와 플래시 애니메이션을 표준화하고, 크기별(Small, Medium, Large)로 재활용 가능한 애셋으로 구축해야 합니다.
2.  **Data Flow Grapher:** 시스템 노드, 연결선, 그리고 '오류 발생' 시 색상/모양 변화가 일어나는 인터랙티브 그래프 모듈이 필요합니다. 이 모듈은 T=3s부터 지속적으로 사용됩니다.
