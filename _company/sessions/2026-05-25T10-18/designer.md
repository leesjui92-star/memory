## 🛠️ [Master Asset Package Blueprint]
### 주제: 구조적 실패 (Structural Failure) 시각화 시스템

### I. 🔴 에셋 유형 A: '시스템 경고등' - Critical Alert System
**[핵심 메시지]**: 현재 시스템/구조가 임계점에 도달하여 붕괴 직전임을 시각적으로 폭로합니다. (Crisis & Physical Failure)
**[컨셉]**: 고장 난 관제 센터의 대형 디스플레이에 나타나는 경고창 느낌. 기존 Neon Cyan에서 벗어나, 위기감을 높이는 Red/Orange 계열을 주조색으로 사용하되, 글리치 효과는 유지합니다.

| 항목 | 사양 (Specification) | 애니메이션 로직 (Timing & Action) |
| :--- | :--- | :--- |
| **주요 컬러** | 배경: `#0A0A0A` (Deep Black)<br>경고색 1: `#FF4B4B` (Alert Red)<br>강조색/글리치: `#FFFF00` (Warning Yellow) | - |
| **타이포그래피** | `Orbitron` 또는 유사 기하학적 산세리프. 모든 문자는 글리치 필터 적용 필수. | **[T+0s]**: 텍스트가 화면 중앙에서 빨간색의 '스캔라인'과 함께 급격히 나타나며 노이즈로 흔들림. <br>**[T+1~2s]**: 경고 레벨(Level I, II, III)에 따라 크기와 깜빡임 주기가 증가하며 시청자의 주의를 강제적으로 끈다 (Flash Rate: 0.5초 간격). |
| **레이아웃/모듈** | **1. 시스템 상태 표시:** 좌측 상단에 'STATUS: CRITICAL' 배너 배치.<br>**2. 경고 메시지 모듈:** 중앙에 핵심 문구(예: "GLOBAL ENERGY GRID FAILURE DETECTED").<br>**3. 위험 구역 맵 (Heatmap):** 화면 하단에 지도 또는 그래프 형태로 빨간색으로 점진적 확산 애니메이션 적용. | **[T+0s~1s]**: 경고 메시지가 팝업되면서 주변의 배경 노이즈가 증가함.<br>**[T+2s]**: 위험 구역 맵을 따라 `#FF4B4B` 색상의 점들이 빠르게 확산되며, 시청자에게 '어디서부터 잘못되었는지'를 직관적으로 인지시킴. |
| **사용 예시** | 에너지 부족, 물류망 마비 등 물리적 구조의 위기 폭로 구간. |

### II. 👾 에셋 유형 B: '정보 결함' - Knowledge Void Corruptor
**[핵심 메시지]**: 접근하는 데이터 자체가 믿을 수 없거나 정보가 공백 상태임을 보여줍니다. (Suspicion & Digital Failure)
**[컨셉]**: 컴퓨터 시스템의 로직 오류나 메모리 손실(Memory Leak) 느낌. 시각적으로 혼란스러우며, '뭔가 중요한 것을 놓치고 있다'는 불안감을 유발합니다.

| 항목 | 사양 (Specification) | 애니메이션 로직 (Timing & Action) |
| :--- | :--- | :--- |
| **주요 컬러** | 배경: `#0A0A0A` (Deep Black)<br>정보 흐름: `#00FFFF` (Neon Cyan, 기본 유지)<br>결함 강조: `#8888FF` (Broken Blue) | - |
| **타이포그래피** | `Rajdhani` 또는 유사한 디지털 폰트. 텍스트 자체에 글리치(Glitch) 효과를 빈번하게 적용합니다. | **[T+0s]**: 정상적인 데이터 스트림(`Cyan`)을 보여주다가, 갑자기 픽셀화되고 왜곡된 문자열이 폭발적으로 나타남 (데이터 버퍼 오버플로우).<br>**[T+1~3s]**: 글리치 효과가 반복되며 화면 전체에 '노이즈' 레이어가 끼어들어 시청자가 정보를 읽기 어렵게 만듦. |
| **레이아웃/모듈** | **1. 데이터 스트림:** 좌우에서 흐르는 정상적인 텍스트 블록.<br>**2. 결함 모듈:** 핵심 정보가 있어야 할 자리에 빈 공간(Void)이 생기고, 그 주변을 `#8888FF`의 깨진 네온빛이 감쌈. | **[T+0s]**: 완벽하게 정리된 데이터 흐름(`Cyan`) → **[T+0.5s]**: 특정 키워드가 포함된 부분만 갑자기 멈추고, 해당 영역 전체가 `Pixelation/Shredding` 애니메이션을 거치며 정보의 부재를 극대화함.<br>**[T+2s]**: 빈 공간(Void) 위로 "DATA CORRUPTED" 또는 "INFORMATION GAP DETECTED"라는 오류 메시지가 겹쳐서 나타남. |
| **사용 예시** | 특정 통계나 데이터 포인트의 출처가 모호하거나, 기존 지식 체계로는 설명할 수 없는 '정보 공백' 구간. |

### III. 📈 에셋 유형 C: '진단 프로토콜' - Diagnostic Visualization
**[핵심 메시지]**: 문제의 근본 원인과 위험도를 전문적인 관점에서 분석하고, 해결책이 필요함을 납득시킵니다. (Authority & Solution Focus)
**[컨셉]**: 마치 국가 기밀 보고서나 과학 연구소에서 사용하는 정교하고 기능적인 UI/UX 대시보드 느낌입니다. 시각적 신뢰도와 전문성을 최우선으로 합니다.

| 항목 | 사양 (Specification) | 애니메이션 로직 (Timing & Action) |
| :--- | :--- | :--- |
| **주요 컬러** | 배경: `#0A0A0A` (Deep Black)<br>기본 정보: `#AAAAAA` ~ `#CCCCCC` (Neutral Gray, 전문성 확보용)<br>위험 지표: `#FF4B4B` (Alert Red) | - |
| **타이포그래피** | `Rajdhani` 또는 시스템 콘솔 스타일의 모노스페이스 폰트. 수치를 나타낼 때 특히 중요하며, 글리치 효과는 최소화하고 '정밀함'에 초점을 맞춥니다. | **[T+0s]**: 모든 지표가 0에서 시작하여 데이터 포인트별로 깔끔하게 증가(Count Up)하는 애니메이션 적용. (Smooth & Clean transition).<br>**[T+2s]**: 위험도가 높은 특정 그래프 라인만 `#FF4B4B` 색상으로 순간적으로 하이라이트되며, 주변 지표와 대비됨. |
| **레이아웃/모듈** | **1. 핵심 KPI 대시보드:** 상단에 3~4개의 주요 수치(KPI)를 큰 숫자로 배치.<br>**2. 시계열 그래프 (Time Series Chart):** 시간 흐름에 따른 변동성을 보여주는 라인 차트 필수.<br>**3. 원인 분석 트리:** 근본적인 문제의 원인을 나무 구조/순서도로 도식화. | **[T+0s]**: KPI들이 순차적으로(Sequential) 로드되며, 각 수치 아래에 작은 설명 텍스트가 부드럽게 나타남.<br>**[T+1~3s]**: 시계열 그래프의 데이터 포인트가 마치 실시간으로 '수집'되는 것처럼 점진적으로 채워지며 (Data Flow), 특정 구간에서 갑자기 가파른 하강 곡선이 발생하며 위기감을 조성함. |
| **사용 예시** | 에너지 소비 추세 분석, 물류 지연율 통계 보고 등 컨설팅의 근거 자료가 되는 모든 데이터 시각화 단계. |

### 🖼️ 마스터 에셋 패키지 통합 요약 및 실행 가이드

| 구분 | 역할 (Purpose) | 핵심 감성 (Emotion) | 사용 타이밍 (Timing) |
| :--- | :--- | :--- | :--- |
| **A. 경고등** | **(What)** 문제가 발생했음을 공포로 알려준다. | 위협, 절망, 임박한 재난 | 영상 도입부 또는 주제 전환 시점 (T+0s) |
| **B. 정보 결함** | **(Why)** 문제의 원인을 알 수 없게 만들어 불안감을 극대화한다. | 의심, 혼란, 지적 공포 | 핵심 주장 직전, '지식 공백' 구간 (T+2s~T+4s) |
| **C. 진단 프로토콜** | **(How)** 문제의 크기와 전문적인 해결책의 필요성을 논리적으로 증명한다. | 신뢰, 지적 만족감, 구체적 경로 제시 | 영상 중반부 (데이터 분석/문제 심화) 및 결론부 (해결책 예고) |

이 3가지 에셋은 서로를 보완하며 '시스템 오류 → 정보 공백 발생 → 전문 진단 필요'라는 하나의 완벽한 서사 흐름을 구축합니다. Editor에게는 이 세 가지 모듈을 시간 코드에 맞춰 **겹치지 않게 순차적으로(Sequential)** 사용하도록 지시하십시오.
