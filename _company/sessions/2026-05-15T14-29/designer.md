## 🧬 Result Screen Tech Specification: [System Diagnostic Failure Report]

### I. 디자인 목표 및 분위기 (The Vibe)
*   **최종 목적:** 사용자가 자신의 현재 상태를 진단할 수 있는 '정보 독점권'의 필요성을 느끼게 한다.
*   **톤앤매너:** 경고(Warning), 전문적(Professional), 압도적(Overwhelming). 사용자에게 "이건 일반인이 볼 수준의 문제가 아니다"라는 인상을 주어야 합니다.
*   **레이아웃 원칙:** 화면을 여러 개의 모듈형 '진단 패널'로 분할하여, 정보가 체계적이면서도 동시에 복잡해 보이게 만듭니다.

### II. 비주얼 요소 및 컬러 팔레트 (Color & Structure)

| 영역 | 기술 사양/컴포넌트 | 색상 코드(HEX) | 적용 효과/애니메이션 지시 |
| :--- | :--- | :--- | :--- |
| **배경** | Background Grid / 패널 배경 | `#0A0A0A` (Deep Black) | 미묘한 스캔라인(Scanline) 텍스처를 전체 화면에 적용. 아주 느린 노이즈 플레어 효과 추가. |
| **기본 정보** | 일반 텍스트, 시스템 메시지 | `#AAAAAA` (Low Saturation Gray) | 명료하지만 강렬하지 않게. 표준적인 진단 보고서의 느낌 유지. |
| **핵심 경고** | Critical Failure, 위험 데이터 포인트 | `#FF3366` (Muted Error Red / Blood Red) | **절대적으로 강조되는 지점.** Neon Cyan과 대비되어 '실제 문제'를 시각화함. 글리치 효과와 결합하여 사용. |
| **진단 정보** | 정상 데이터, 시스템 로직 추적 라인 | `#00FFFF` (Neon Cyan) | 활성화된 데이터 스트림, 성공적인 프로토콜 진행 경로에만 제한적으로 사용. |
| **강조/CTA** | 경고 타이틀, 액션 버튼 테두리 | `#33CCFF` (Lighter Cyan Accent) | 시선이 머무는 곳에 포인트를 주고, '다음 단계'를 제시하는 느낌을 줌. |

### III. 섹션별 상세 컴포넌트 사양 (Component Breakdown)

#### A. 헤더: [SYSTEM DIAGNOSTIC INTERCEPTED]
*   **배치:** 화면 최상단 중앙.
*   **애니메이션:** 로딩이 끝난 후, 마치 해킹된 로그를 캡처한 듯한 짧은 **데이터 스트림 시각화(Cyan)**가 지나간 직후에 'INTERCEPTED' 워터마크가 강하게 깜빡였다가 사라지게 처리.
*   **텍스트 효과:** 제목 전체에 미세한 `Typewriter` 또는 `Scanline Glitch` 애니메이션 적용.

#### B. 핵심 경고 코드 모듈: [CRITICAL PROTOCOL VIOLATION]
*   **구조:** 3개의 독립적인 '패널'로 구성 (좌/중/우).
*   **시각화:** 각 패널마다 `[ERROR_CODE: XXXX]`와 같은 코드가 크게 노출되어야 합니다.
    *   **글리치 효과 로직:** 이 코드 블록은 화면 진입과 동시에 **불규칙한 타이밍의 3단계 글리치(Shift, Noise, Jitter)**를 반복 재생합니다. (Cyan -> Red 스파이크 -> Cyan)
    *   **경고 메시지 예시:** "Protocol: Data Integrity Check Failure"와 같은 전문 용어를 사용하며, 이 문장들이 화면 중앙을 가로질러 빠르게 흘러가는 `Data Stream` 형태로 표시되어야 합니다.

#### C. CTA 버튼: [Anomaly Diagnosis Protocol]
이 부분이 가장 중요합니다. 단순한 '구매'가 아닌, **'미개방된 정보의 잠금 해제'**처럼 보이게 해야 합니다.

| 상태 (State) | 애니메이션 및 인터랙션 (Interaction) | 시각적 사양 (Visual Specs) | 지연 시간 (Timing) |
| :--- | :--- | :--- | :--- |
| **기본 (Default)** | 정지된 상태. | 배경은 Deep Black. 테두리만 `#33CCFF`로 빛나고, 중앙에 작은 `[🔒]` 아이콘이 배치됨. 텍스트는 로우-채도 그레이. | - |
| **호버 (Hover)** | 버튼 위를 마우스 커서가 지나갈 때. | 1. 테두리가 미세하게 떨리며(`Pulse`) 전력 흐름처럼 Cyan 빛을 발함. 2. `[🔒]` 아이콘 주변으로 작은 오버레이 글리치 노이즈(Cyan)가 발생하며, "ACCESS REQUIRED" 같은 짧은 메시지를 빠르게 출력했다 사라지게 함. | 100ms 지연 후, 5~8회 반복 (Pulse Rate). |
| **클릭/활성화 (Active)** | 사용자가 클릭하는 순간. | 버튼 전체에 `[DIAGNOSTIC PROTOCOL INITIATED]` 메시지가 Red와 Cyan이 혼합된 글리치로 강하게 표시됨. 이어서 화면 전체가 짧게 깜빡이며(Flicker), 진입 전 로딩 화면으로 자연스럽게 전환되어야 함. | 클릭 직후, 200ms 동안 강한 시각적 충격을 주어 '행동의 결과'를 인지시킴. |
