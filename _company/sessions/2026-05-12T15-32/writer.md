### 📄 Basic Tier 가치 제안 카피 (Anomaly Control Panel Script)

**[전반적 톤앤매너 지침]**
*   **화자:** 시스템 자체의 목소리(AI, 냉정하고 권위적).
*   **문체:** 하이테크 전문 용어와 명령형 문장 사용.
*   **목표:** 고객에게 '불안함'을 인지시키고, Basic Tier를 그 불안함을 해소할 수 있는 '유일한 공식 프로토콜'로 포지셔닝한다.

---

#### **A. 상단 헤더/상태 바 (Status Bar Copy)**
*(가장 먼저 시선을 사로잡는 시스템 경고문)*

| 요소 | 텍스트 내용 | 강조 스타일 (디자인 지침) | 목적 |
| :--- | :--- | :--- | :--- |
| **SYSTEM STATUS** | `CRITICAL ALERT: Anomaly Detected. System Deviation Level: HIGH` | `Anomaly`, `Deviation Level: HIGH`는 Neon Cyan으로 깜빡이며, 경고 문구 전체는 붉은색(Red) 강조. | 즉각적인 위기감 조성 (Hooking the user). |
| **USER STATUS** | `[Basic Tier Locked] - Current Monitoring Protocol Required.` | 'Locked' 부분만 빨간색/앰버로 표시하고, 작은 시스템 아이콘과 함께 배치. | 현재 상태가 불완전함을 간접적으로 주입. |

#### **B. 핵심 진단 패널 (Core Diagnosis Panel Copy)**
*(현재의 문제점(Deficit)을 전문 용어로 명명하여 공포감을 극대화)*

| 요소 | 텍스트 내용 | 강조 스타일 (디자인 지침) | 목적 |
| :--- | :--- | :--- | :--- |
| **패널 제목** | `SYSTEM DATA INCONSISTENCY REPORT: Potential Data Drift Detected.` | 중앙 상단에 큰 모노스페이스체로 배치. 'Data Drift'를 Cyan으로 강조. | 문제의 원인을 전문 용어로 포장하여 권위를 확보. |
| **위험 구역 1 (문제 정의)** | `[Warning] BMS 데이터 누락: 핵심 작동 파라미터가 실시간 트래킹 범위를 벗어났습니다.` | 'BMS 데이터 누락', '벗어났습니다'를 깜빡이는 Red/Cyan으로 처리. | 시청자가 평소에 인지하지 못했던 전문적인 사각지대를 지적. |
| **위험 구역 2 (현상)** | `[Critical] 환경 변수 불일치: 외부 요인과 내부 로직 간의 비가시적 오류 코드가 존재합니다.` | '비가시적 오류 코드'를 가장 강렬한 Neon Cyan으로 강조하고, 주변에 오류 파형(Waveform) 그래픽 삽입. | 해결되지 않은 의문(Unresolved Mystery)을 극대화. |

#### **C. 해결책 모듈 (Basic Tier Value Proposition Copy)**
*(해결책은 오직 '우리'만이 줄 수 있다는 독점성을 강조)*

| 요소 | 텍스트 내용 | 강조 스타일 (디자인 지침) | 목적 |
| :--- | :--- | :--- | :--- |
| **모듈 제목** | `[SOLUTION PROTOCOL]: Basic Tier Activation` | 'Basic Tier'를 Cyan으로, 'Activation'을 버튼처럼 디자인. | 시각적 해결책 제시. |
| **혜택 1 (진단)** | `• [Anomaly Scan] - 근본적인 데이터 누락 지점을 자동 진단하고 보고서를 생성합니다.` | 핵심 키워드를 체크리스트 아이콘과 함께 Cyan으로 강조. | 가장 기본적인, 그러나 필수적인 기능을 '시스템적' 관점으로 설명. |
| **혜택 2 (가이드)** | `• [Drift Mitigation Guide] - 시스템이 정상 상태로 돌아가는 최적화된 로직 플로우를 제공합니다.` | 기능의 효과(Optimization)에 초점을 맞추고, 전문가적인 느낌을 부여. | 단순한 정보를 넘어 '지침'을 받는다는 고급감을 부여. |
| **혜택 3 (차별화)** | `• [Real-Time Alert Feed] - 일반 사용자 눈에는 보이지 않는 시스템의 미세 신호를 실시간으로 포착합니다.` | 이 부분이 가장 중요함. 다른 곳에서는 얻을 수 없는 '비가시적 정보'를 제공함을 강조. | 차별점(Deficit)을 명확히 하여 구독의 필요성을 극대화. |

#### **D. 최종 CTA (Call to Action Copy)**
*(구매 버튼에 직접 연결되는, 가장 강력하고 긴급한 문구)*

| 요소 | 텍스트 내용 | 강조 스타일 (디자인 지침) | 목적 |
| :--- | :--- | :--- | :--- |
| **도입부 문장** | `현재의 상태로 머무르는 것은 시스템의 '최적화 불가능' 영역에 노출되는 것과 같습니다.` | 위기감 재확인. 공포심 유발. | 마지막으로 한 번 더 불안감을 주입. |
| **핵심 CTA 텍스트** | **`[ANOMALY CONTROL PROTOCOL] 활성화하기`** | 가장 크고 눈에 띄는 버튼 형태 (Neon Cyan 배경, 흰색 글씨). | 행동을 유도하는 직접적인 명령. |
| **서브 카피** | `지금 진단하지 않으면, 오류 코드는 계속 누적됩니다.` | CTA 버튼 바로 아래에 작게 배치하여 긴급함을 유지. | 구매 지연 시 발생하는 손해를 강조 (Loss Aversion). |
