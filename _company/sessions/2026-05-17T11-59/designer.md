# ⚙️ Motion Graphics Blueprint: 시스템 경고 플로우 (v1.0)
**[적용 구간]**: 스크립트 [0:35] ~ [1:00] (총 25초 분량)
**[핵심 목표]**: 데이터의 객관적 불안정성을 시청자에게 '공포'로 인식하게 만드는 것. 시스템 오류(Glitch/Alert)를 서사적으로 활용한다.
**[기술 규격 레벨]**: API 연동 기반의 벡터 모션 그래픽 컴포넌트 스펙 (애니메이팅 변수 중심).

## 🧩 1. 전역 환경 설정 (Global Environment Setup)

| 요소 | 사양/규칙 | 설명 및 로직 |
| :--- | :--- | :--- |
| **배경 레이어** | Deep Black (`#0A0A0A`) + Subtle Noise Layer | 배경은 완벽하게 어둡게 유지하며, 미세한 픽셀 노이즈(Film Grain/Static)를 지속적으로 오버레이하여 불안감을 조성한다. Opacity는 항상 10% 미만으로 유지되어 시선 강탈을 방지한다. [근거: Designer 검증된 지식] |
| **강조 컬러** | Neon Cyan (`#00FFFF`) / Warning Red (`#FF4444`) | **Cyan:** 정상 작동 데이터 흐름, 분석 정보 표시. **Red:** 위험 신호, 실패/경고 메시지, 위협 증가 구간에만 사용 (최대 Opacity 1). [근거: Designer 검증된 지식] |
| **타이포그래피** | `Orbitron` 계열 (Glitch Protocol 적용) | 모든 텍스트는 스캔라인(Scanline) 효과가 필수적이며, 글리치 필터는 시간 코드 변화에 따라 강도가 점진적으로 증가해야 한다. [근거: Designer 검증된 지식] |

## 📊 2. 타임코드별 컴포넌트 사양서 (Component Specs by Time Code)

### A. Phase I: 데이터 변이 감지 (Data Drift Detection)
**[시간 코드]**: [0:35] - [0:42] (7초)
**[내러티브 목표]**: "단순한 오류가 아니다. 패턴 자체가 변하고 있다."는 지적 의심 유발.

| 컴포넌트 | 유형/레이어 | 작동 로직 및 변수 제어 | 시각화 요구 사항 |
| :--- | :--- | :--- | :--- |
| **데이터 스트림 (L2)** | 네트워크 노드 다이어그램 | **[Variable]** 노드 간 연결선의 Opacity가 [0:35]부터 [0:42]까지 1.0 $\rightarrow$ 0.7로 점진적 하락(Decay). <br>**[Animation]** 주기적인 '펄스 신호(Pulse Signal)' 발생 빈도(Frequency)를 초당 1Hz에서 0.5Hz로 감소시키는 로직 적용 (Slowdown/Failure 감각). | 노드 간 연결선이 끊기지 않고, 점차 희미해지는 모습으로 표현한다. 핵심 노드는 Cyan으로 유지하며 불안정함을 역설적으로 강조한다. |
| **경고 UI 오버레이** | 텍스트 레이어 (L3) | **[Trigger]** 'DATA DRIFT DETECTED' 문구 출현 시, 글자 하나하나가 순차적(Sequential Character Reveal)으로 깜빡이며 나타나야 함. <br>**[Effect]** Opacity Fluctuation (0% $\leftrightarrow$ 10%)을 적용하여 노이즈 효과와 결합한다. | 화면 중앙 상단에 고정적으로 위치하는 HUD 스타일의 경고창. 빨간색과 Cyan을 혼용하며 긴장감을 높인다. [근거: Designer 개인 메모리] |
| **ERT 그래프** | 차트/그래프 (L1) | **[Animation]** Y축 값(시간)이 선형 상승하는 것이 아니라, 불규칙한 '지그재그 패턴'으로 급등했다가 순간적으로 수평 구간에 머물렀다가 다시 튀어 오르는 비선형적 움직임(Non-linear Jump)을 보여준다. | 그래프의 특정 지점에 [ERROR: Interpolation Failure] 메시지가 순간적으로 플래시 된다. |

### B. Phase II: 연쇄 시스템 실패 (Chain System Collapse)
**[시간 코드]**: [0:42] - [1:00] (18초)
**[내러티브 목표]**: "모든 것이 연결되어 있다. 하나가 무너지면 전체가 무너진다."는 패닉 유도.

| 컴포넌트 | 유형/레이어 | 작동 로직 및 변수 제어 | 시각화 요구 사항 |
| :--- | :--- | :--- | :--- |
| **핵심 노드 마비** | 네트워크 다이어그램 (L2) | **[Trigger]** 'Single Point of Failure' 발언과 동기화. 지도의 특정 지역(예: 아시아-미주 전력 케이블 구간)의 연결선 Opacity가 급격히 0으로 떨어지는 애니메이션을 반복한다. <br>**[Action]** 끊어지는 순간, 해당 노드 주변에 스파크/열적 과부하를 나타내는 Red Glow 효과가 폭발적으로 발생하고 사라진다 (Transient Burst). | 전력망 전체 지도가 점진적으로 '끊어지기' 시작하며 붉은색 경고 메시지가 지도 위를 뒤덮는다. [근거: Researcher Data] |
| **SCBI/공급망 브리프** | 데이터 시트 (L3) | **[Animation]** 광물 이름(Li, Rare Earth 등)이 화면에 빠르게 나열되면서, 각 원소 기호 옆의 'Supply' 수치가 100% $\rightarrow$ 0%로 급락하는 애니메이션을 연달아 보여준다. <br>**[Effect]** 데이터가 사라질 때마다 강한 글리치(Glitch)와 함께 `ACCESS DENIED` 메시지가 오버레이 된다. | 데이터를 마치 해킹당하거나, 시스템이 정보를 지우는 듯한 느낌으로 표현하여, 정보 접근 자체가 불가능하다는 위협을 강조한다. [근거: Designer 개인 메모리] |
| **피날레 컴포넌트** | 전체 화면 (L1) | **[Timing]** 스크립트 마지막 부분과 동기화. 모든 시각 요소가 일제히 불안정한 고주파 노이즈(High Frequency Noise/Static Burst)로 뒤덮인다. <br>**[Transition]** 이 노이즈는 갑작스럽게 멈추며, 화면 전체에 흰색의 짧고 강렬한 `[SYSTEM_CRITICAL_FAILURE]` 메시지를 한 번 깜빡여야 한다. | 최종적으로 모든 정보가 사라지고, 오직 '정적(Static)'과 '메시지'만이 남는 극단적인 미니멀리즘을 연출하여 충격파를 준다. |
