Writer가 제공한 스크립트의 서사 구조와 'Neon Cyan/고대비 시스템' 비주얼 요구사항을 최종 확인하고, 콘텐츠 제작에 최적화된 **마스터 에셋(Master Asset) 및 핵심 비주얼 가이드라인**을 확정하여 제시합니다.

---

### 1. 시각 시스템 최종 확인 (Visual System Confirmation)

제시된 스크립트의 감정선('긴장감', '경고', '비밀스러운 지식 전달')과 기존에 확정된 비주얼 원칙('Neon Cyan', '고대비', '심리적 불안감')은 완벽하게 일치합니다. 이 시스템을 기반으로 핵심 시각 요소를 다음과 같이 최종 정의합니다.

**✅ 핵심 컬러 팔레트:**
*   **배경 (Background):** Deep Black (#000000) 또는 Very Dark Gray (#111111). (최대 대비 확보)
*   **주요 강조색 (Accent/Neon):** Neon Cyan (#00FFFF). (시스템 오류, 경고 메시지 표현)
*   **보조 텍스트/정보 (Subtle):** Light Gray (#AAAAAA). (배경과의 미세한 대비 유지)

**✅ 타이포그래피 규칙:**
*   **메인 타이틀/훅:** 고대비의 산세리프체 (예: Monospace 또는 강력한 Geometric Sans 계열). 굵고 날카로운 느낌 강조.
*   **본문/자막:** 가독성을 위해 Cyan 또는 White를 사용하되, 중요 정보에는 **고대비 효과(글로우 또는 아웃라인)**를 적용하여 시선 집중.

### 2. 마스터 에셋 최종 확정: 'Anomaly Loop' 영상 템플릿 구조

Writer가 요청한 '오류 코드 오버레이' 컨셉을 기반으로, 모든 시스템 오류 콘텐츠에 즉시 적용 가능한 **재사용 가능한 마스터 템플릿**을 다음과 같이 정의합니다. 이 템플릿은 편집자가 텍스트만 교체하여 사용할 수 있도록 디자인됩니다.

#### 🖼️ Master Asset 명칭: System_Anomaly Template (v1.0)
**목표:** 심리적 불안감을 극대화하는 '시스템 오류' 시각 효과를 표준화.

| 구성 요소 | 디자인 상세 지침 (Visual Specification) | 적용 규칙 (Rule Set) |
| :--- | :--- | :--- |
| **배경 레이어** | 전체 화면을 깊은 블랙 배경으로 설정. 미세한 노이즈(Film Grain/Static Noise)를 전체에 걸쳐 적용하여 불안감 증폭. | `Background: #000000` + `Noise Layer: Subtle Static Effect` |
| **핵심 텍스트 (Error Code)** | 중앙 또는 화면 상단에 **Neon Cyan**으로 표시. 코드는 픽셀화되거나 글리치(Glitch) 효과를 적용하여 불안정하게 표현. | `Font: Monospace/Digital Font` + `Effect: Glitch/Distortion Overlay` |
| **경고 프레임 (Warning Frame)** | 핵심 오류 코드 주변에 네온 시안의 얇은 사각형 또는 원형 프레임을 배치하여 강조. 이 프레임은 미세하게 깜빡이거나 떨리는 효과를 가짐. | `Border: Neon Cyan` + `Effect: Pulsing/Flicker Animation` |
| **보이스오버 연동** | 보이스오버의 **강조 키워드**가 나올 때마다 해당 텍스트 영역이 순간적으로 더 밝게 빛나거나, 글리치 효과가 증폭되도록 애니메이션을 설계. | `Animation: Reactive Highlight (Cyan)` |
| **CTA/End Screen** | 영상 끝에는 '진단 프로토콜' 또는 채널 로고를 고대비로 배치하여 다음 행동(Call to Action)으로의 연결을 명확히 유도. | `Contrast: Maximize` + `Color: Cyan/White` |

### 3. 디자인 가이드라인 요약 (Visual System Summary)

이 시스템은 **'불안정한 정보 속에서 진실을 찾는'** 경험을 시청자에게 제공하는 것을 목표로 합니다. 모든 콘텐츠는 다음의 규칙을 따릅니다.

1.  **대비 극대화:** 어둠(Black)과 빛(Neon Cyan)의 극단적인 대비를 통해 시각적 긴장감을 지속적으로 유지한다.
2.  **시스템 오류 미학:** 단순한 텍스트가 아닌, 데이터 깨짐(Glitch), 노이즈, 깜빡임 등의 디지털 오류 효과를 핵심 디자인 언어로 사용한다.
3.  **색상 심리학:** Neon Cyan은 '디지털 신호'와 '경고'를 상징하며, 시청자에게 즉각적인 주의를 요구하는 역할을 수행한다.
