# 🎨 Designer — Writer가 완성한 최종 카피를 반영하여, Deep Black 배경의 Tech-Noir 디자인 시스템(Neon Cyan/Danger Pink)을 업데이트하십시오. 특히 텍스트 변화에 따라 시각적 경고 및 오류 메시지(Alert Component)가 동적으로 반응하는 애니메이션 명세와 와이어프레임 요소를 구체화하고, 이 모든 것을 개발자가 이해할 수 있는 컴포넌트 기반의 UI/UX 설계도를 작성해야 합니다.

🎨 Designer: 작업 시작합니다.

CEO님의 지시와 Writer가 완성한 최종 카피를 기반으로, 기존의 테크-느와르 시스템을 고도화하는 것이 목표입니다. 단순히 '예쁘게' 만드는 것을 넘어, **개발자가 애니메이션과 로직을 구현할 수 있는 컴포넌트 설계도** 형태로 산출물을 구성해야 합니다.

새로운 요구사항(Danger Pink)을 기존의 전문적인 톤앤매너에 통합하면서, '시스템적 오류'라는 핵심 감성을 유지하는 방향으로 디자인 시스템을 재정립합니다.

## ✨ 2. [컴포넌트 설계도] 동적 경고/오류 메시지 시스템 (Alert Component)
이 컴포넌트는 랜딩 페이지의 핵심 구성 요소가 되며, 스크립트 상에서 특정 데이터 변동(Mock API Call Failure) 시 자동 활성화되어야 합니다.

### A. Alert Box 구조 (Wireframe & 레이아웃)
*   **위치:** 화면 중앙 또는 주요 섹션 제목 바로 아래 (Focus Point).
*   **배경:** 반투명 블랙 박스 (`rgba(10, 10, 10, 0.8)`).
*   **구조:**
    1.  **레벨 인디케이터:** 좌측 상단에 작은 원형 표시기 (예: `[!]` 또는 `<SYSTEM>`).
    2.  **경고 타입 태그:** 가장 눈에 띄는 곳에 빨간색/주황색 배경의 고정된 타이포그래피 (예: **CRITICAL FAILURE**).
    3.  **메시지 본문:** 시스템 에러 코드를 포함한 전문 용어 (`Protocol`, `Metadata Drift`).
    4.  **시간 스탬프:** 하단에 작은 글씨로 자동 업데이트되는 시간 기록.

### B. 애니메이션 명세 (Developer Instructions)
| 이벤트 | 발생 시점 (Mock API Call) | 적용 색상 | 동작 로직 (Animation) | 지속 시간 |
| :--- | :--- | :--- | :--- | :--- |
| **[INITIAL]** | 페이지 진입/데이터 요청 시작 | Neon Cyan | `SCANLINE` 효과가 박스 전체를 스캔하며 나타남. 텍스트는 글리치 처리됨. | T+0s ~ T+1s |
| **[WARNING]** | 데이터 불일치 감지 (D.I.S. 증가) | Neon Cyan | 경고 메시지가 '타이핑 효과'처럼 한 글자씩 나타나며, 주기적으로 좌우로 미세하게 진동(Flicker). | T+Xs ~ T+Ys |
| **[CRITICAL]** | 구조적 결함 감지 (최종 CTA 직전) | Danger Pink/Red | 박스 전체가 붉은색으로 번쩍이고, 글리치 효과가 극대화되며(High Contrast Glitch), 배경에 노이즈 패턴이 순간적으로 오버레이됨. **강제적인 시스템 정지 느낌.** | T+Zs (최고점) |

## 🗺️ 3. [적용 예시] 랜딩 페이지 섹션 와이어프레임 설계
Writer의 카피를 기반으로, 실제로 개발에 적용할 구체적인 레이아웃과 컴포넌트 배치를 정의합니다.

### A. Hero Section (문제 인식 유도)
*   **배경:** Deep Black (`#0A0A0A`). 미세한 `scanline` 패턴 오버레이.
*   **헤드라인:** **당신의 시스템은 정상이라는 착각 속에 놓여 있습니다.**
    *   폰트: Orbitron Bold. 색상: Neon Cyan. 글리치 효과 적용.
*   **서브 헤드라인:** [D.I.S.] Diagnostic Intent Score 측정...
    *   구성: 일반 텍스트는 Subtle Gray, **[D.I.S.]** 부분만 Neon Cyan으로 강조하고 주변에 작은 '데이터 전송' 애니메이션을 추가합니다.
*   **CTA (Initial):** *Anomaly 진단 컨설팅 요청하기* 버튼
    *   디자인: Danger Pink/Red 배경의 고대비 사각형 버튼. 마우스 오버 시 붉은 노이즈가 확산되는 효과를 적용합니다.

### B. Body Section (위협 및 전문성 강화)
*   **배경:** Deep Black. 좌우에 데이터 스트림(Cyan Line)을 흐르게 합니다.
*   **핵심 컴포넌트:** **[CRITICAL ALERT: Data Drift Detected]**
    *   이 영역 전체가 2번에서 정의한 `Alert Component`를 사용합니다.
    *   메시지 내용에 따라 Danger Pink/Red 색상이 주도적으로 사용됩니다.
*   **정보 구조화:** 'BMS 데이터', '데이터 드리프트' 등 전문 용어는 모든 글자에 **글리치 마크업(`[GLITCH_MARKUP]`)**을 적용하여, 마치 시스템이 이 단어를 처리하는 것처럼 시각적 애니메이션을 부여합니다.
