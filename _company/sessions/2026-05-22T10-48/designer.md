# 🎨 Designer — 최종화된 스크립트와 '구조적 와해/콘솔 UI' 모듈을 기반으로, 영상 전체의 시각적 스토리보드(Time-coded Storyboard)를 완성하십시오. 각 시간대별로 어떤 그래픽이 나와야 하는지($t_0$부터 $t_{final}$까지), 그리고 어떤 텍스트 오버레이가 필요한지를 페이지 단위로 상세하게 설계하여 Editor에게 전달할 '비주얼 통합 브리프'를 작성하십시오.

🎨 Designer: 작업 시작합니다.

CEO님의 지시에 따라, Writer님이 최종화한 스크립트와 기존에 검증된 테크-느와르 비주얼 시스템을 통합하여 '비주얼 통합 브리프'를 작성했습니다. 이 브리프는 Editor가 **절대적인 가이드라인**으로 사용해야 하며, 단순 레퍼런스를 넘어선 *시간 코드 기반의 실행 매뉴얼*입니다.

이 브리프의 핵심은 시각적 불안감(Visual Unease)을 유지하며, 모든 정보가 '시스템 오류'를 통해 전달되는 것처럼 보이도록 설계하는 것입니다.

***

## 📺 [MASTER BRIEF] 시스템 폭로: 데이터 드리프트와 지식 만료화 (Obsolescence Protocol)
**최종 비주얼 통합 브리프 v1.0**

### 1. 프로젝트 개요 및 기술 사양 (System Specs)
*   **목표:** 시청자에게 '현재 알고 있는 정보가 불완전하며, 시스템적으로 결함이 있다'는 지적 불안감을 주입하여 유료 프로토콜(서비스) 구매를 유도한다.
*   **포맷:** 유튜브 쇼츠 (최종 길이: 45초 ~ 60초 권장)
*   **비율:** 9:16 (세로형)
*   **톤앤매너:** 테크-느와르, 고밀도 정보 과부하(Information Overload), 긴급 경고 시스템.

### 2. 디자인 자산 및 원칙 재확인 (Design Pillars)
| 요소 | 상세 규격 | 사용 목적 | 근거 |
| :--- | :--- | :--- | :--- |
| **배경** | Deep Black (`#0A0A0A`) 또는 Dark Gray (`#1A1A1A`). 깊고 어두운 질감 유지. | 정보의 심도 및 위협감 조성. 모든 시각 요소가 전면에 '떠오르도록' 만듦. | [근거: Designer 검증된 지식] |
| **강조색** | Neon Cyan (`#00FFFF`). 데이터 스트림, 경고 메시지, 핵심 단어에만 사용. | 활성화되고, 중요한데 접근할 수 없는(Access Restricted) 정보를 상징. | [근거: Designer 검증된 지식] |
| **경고/위험색** | Red (`#FF004C`) & Yellow (`#FFFF00`). 'CRITICAL' 상태에만 제한적으로 사용. | 생존 위협, 시스템 붕괴를 직관적으로 전달. (최대한 남용 금지) | [근거: Designer 개인 메모리] |
| **폰트** | `Orbitron` 또는 `Rajdhani`. 고대비 산세리프. | 기능성, 기계적 느낌 부여. 모든 텍스트는 글리치/스캔라인 필터가 필수적으로 적용되어야 함. | [근거: Designer 검증된 지식] |
| **효과** | **글리치 (Glitch):** 갑작스러운 노이즈와 색상 분리를 통해 시스템 오류를 시각화한다. <br>**콘솔 UI:** 텍스트 기반의 데이터 플로우, 로그 출력 형태로 정보를 제시한다. | 긴장감 극대화 및 정보의 전문성(Authority) 부여. | [근거: Designer 개인 메모리] |

### 3. 시간 코드별 상세 스토리보드 (Time-Coded Storyboard)
*(Editor는 각 섹션의 전환 효과와 사운드를 가장 중요하게 다루어야 합니다.)*

#### **[Phase I] HOOK - 패러다임 전환 (0초 ~ 3초)**
| Time Code | 스크립트/내레이션 | 비주얼 지침 (Visual Instruction) | 텍스트 오버레이 및 효과 (Text Overlay & FX) | 사운드 지침 (Sound Design) |
| :---: | :--- | :--- | :--- | :--- |
| **0-1.5s** | "혹시 경고등을 보고 '어디가 고장 났나?'만 생각하셨나요?" | **[SHOT A]**: 차량 계기판 클로즈업 (Low Saturation). 다양한 빨간색/주황색 경고등이 깜빡임. 화면에 필름 그레인 및 약간의 노이즈 추가. | *자막:* ⚠️ WHAT IS WRONG? (초반에는 단순한 질문처럼 보이게) | **사운드:** 일반적인 긴장감 유발음(앰비언스). 낮은 주파수의 드론 사운드 시작. |
| **1.5-3s** | "아닙니다. 그건 원인이 아니라... 당신의 지식의 증상일 뿐입니다." | **[SHOT B]**: 찰나의 순간, 화면 전체가 Neon Cyan/Red 글리치 노이즈로 폭발하며 일시 정지(Freeze Frame). 이후, 모든 경고등 이미지 위로 콘솔 UI 프레임워크가 오버레이 되며 깨짐. | **핵심 텍스트:** `[CRITICAL_FAILURE: KNOWLEDGE GAP]` (Neon Cyan으로 글리치 처리) <br> *부제:* 증상이 아닌, 시스템적 결함. (화면 하단 콘솔 로그처럼 작게 출력) | **사운드:** Deep Boom 임팩트 사운드 $\rightarrow$ 노이즈와 함께 고주파의 불안정한 피치가 최고조에 달하며 급상승한다. (BPM 급상승). |

#### **[Phase II] 문제 제기 - 전문 용어 폭격 (3초 ~ 15초)**
| Time Code | 스크립트/내레이션 | 비주얼 지침 (Visual Instruction) | 텍스트 오버레이 및 효과 (Text Overlay & FX) | 사운드 지침 (Sound Design) |
| :---: | :--- | :--- | :--- | :--- |
| **3-7s** | "우리는 정상 작동하는 시스템을 믿습니다. 하지만 진짜 문제는 눈에 보이지 않습니다." | **[SHOT C]**: 추상적이고 복잡한 데이터 플로우 다이어그램 (데이터 노드 간 연결선)이 빠르게 스크롤됨. 일반적인 '시스템'처럼 보이게 연출한다. | *자막:* NORMAL OPERATION // UNSEEN THREATS. <br> (Cyan 폰트, 깔끔하게 정보만 제공하는 느낌). | **사운드:** 긴장감 넘치는 신디사이저 배경 음악 유지. 데이터가 흐르는 듯한 '틱톡' 사운드(Sci-Fi UI Sound) 반복. |
| **7-12s** | "BMS 데이터 누락, 시간이 지나 패턴이 변형되는 '데이터 드리프트(Data Drift)'..." | **[SHOT D]**: 다이어그램의 특정 노드가 갑자기 깜빡이며 색상이 왜곡됨 (Color Shifting/Glitch). 주변 연결선들이 불안하게 진동한다. 전문 용어(`BMS`, `Data Drift`)가 화면 중앙에 팝업 되며 글리치 효과를 강하게 받는다. | **강조:** BMS DATA LOSS: [ERROR] <br> **핵심 키워드:** Data Drift (Red/Cyan 하이라이트). 콘솔 로그 형식으로 원인과 결과를 나열한다. | **사운드:** '삐-익-' 하는 불안정한 고주파 경고음(Alarm Tone)을 Intermittent하게 삽입. 정보 과부하 사운드 텍스처 추가. |
| **12-15s** | "일반적인 점검으로는 절대 파악할 수 없습니다." | **[SHOT E]**: 화면에 'ANALYSIS IMPOSSIBLE'이라는 대형 경고창이 뜬다. 마치 시스템이 잠시 다운되는 듯한 시각 효과를 준다. (모든 움직임 정지). | *자막:* WARNING: STANDARD PROTOCOL INSUFFICIENT. <br> `[ACCESS DENIED]` (가장 큰 글씨로, Neon Cyan/Red 혼합) | **사운드:** 배경 음악이 갑자기 끊기며(Silence), '지지직'하는 전기적 잡음 사운드가 잠시 공간을 채운다. |

#### **[Phase III] 지식 만료화 (Obsolescence Peak) - 클라이맥스 (15초 ~ 30초)**
| Time Code | 스크립트/내레이션 | 비주얼 지침 (Visual Instruction) | 텍스트 오버레이 및 효과 (Text Overlay & FX) | 사운드 지침 (Sound Design) |
| :---: | :--- | :--- | :--- | :--- |
| **15-20s** | "대부분은 '사용법'만 압니다. 하지만 그것이 전부가 아닙니다." | **[SHOT F]**: 화면 분할(Split Screen) 기법을 사용하여 대비를 극대화한다. 한쪽은 깔끔한 매뉴얼/정보 (Past), 다른 쪽은 와해된 데이터 스트림 (Now). | *왼쪽 자막:* USER GUIDE (Static, Low Contrast) <br> *오른쪽 경고:* **PROTOCOL OBSOLETE** (Glitch, Neon Cyan, High Contrast) | **사운드:** 음악의 템포가 다시 상승하지만, 불안정한 느낌이 더 강해진다. (Rising Tension). |
| **20-30s** | "지금 당신이 가진 지식은 이미 구식입니다. 정보는 만료됩니다." | **[SHOT G]**: 화면 중앙에 거대한 'KNOWLEDGE OBSOLESCENCE TIMER'가 등장한다. 카운트다운 타이머 시각화 (디지털 폰트로). 배경에는 데이터 노드들이 무너져 내리거나(Structural Collapse), 와이어프레임이 오류를 일으키는 애니메이션을 지속적으로 보여준다. | **핵심 메시지:** KNOWLEDGE IS TEMPORARY. <br> **강조 타이머:** [TIME LEFT: 00:XX:XX] (가장 크고, 깜빡이는 Neon Cyan) <br> *하단:* You need a new Protocol. | **사운드:** 긴장이 최고조에 달하며(Crescendo), 낮은 주파수의 떨림(Sub-bass Hum)이 지속된다. 웅장하면서도 위협적인 느낌을 유지한다. |

#### **[Phase IV] CTA 및 해결책 제시 (30초 ~ End)**
| Time Code | 스크립트/내레이션 | 비주얼 지침 (Visual Instruction) | 텍스트 오버레이 및 효과 (Text Overlay & FX) | 사운드 지침 (Sound Design) |
| :---: | :--- | :--- | :--- | :--- |
| **30-35s** | "이 Gap을 메울 수 있는 유일한 방법은... 전문가의 진단 프로토콜입니다." | **[SHOT H]**: 화면의 혼란스러운 배경이 갑자기 정리되며, 중앙에 깔끔하지만 미래지향적인 '프리미엄 인터페이스'가 등장한다. 마치 비밀 통로를 열듯 연출한다. | *자막:* THE SOLUTION: PREMIUM DIAGNOSTIC PROTOCOL <br> (폰트가 일시적으로 깨끗하고 안정된 형태로 변함). | **사운드:** 갑작스러운 '해결' 사운드(Resolved Sound)와 함께 앰비언스가 잠시 안정화된다. 하지만 여전히 낮은 긴장감은 유지한다. |
| **35-End** | (CTA 유도 문구 등) | **[SHOT I]**: 화면 하단에 명확한 CTA 버튼이 나타난다. 이 버튼 주변으로 Neon Cyan의 빛을 집중시키고, 다른 모든 요소는 어둡게 배경 처리하여 시선을 오직 버튼으로만 유도한다. | **최종 CTA:** [ACCESS DIAGNOSTIC PROTOCOL NOW] (클릭 가능한 것처럼 보이게) <br> *하단:* Link in Description / 고정 댓글 참조. (UTM 파라미터 강조). | **사운드:** 낮은 톤의 신뢰감을 주는 배경 음악으로 마무리된다. 마지막 '띵'하는 시스템 완료음을 넣는다. |
