# ⚙️ JRock Visual Spec Sheet v2.0
## **프로젝트:** 데이터 드리프트 시대의 시스템 취약성
**목표:** 시청자에게 '시스템 오류'라는 인지적 위협(Cognitive Dread)을 주입하고, 자사만의 전문적인 진단 프로토콜을 해결책으로 포지셔닝한다.
**톤앤매너:** 테크-느와르 (Tech-Noir), 시스템 경고, 지적 불안감.
**기본 배경 톤:** Deep Black (`#0A0A0A`).

## I. [필수 모듈 에셋 프로토콜 정의] (Asset Protocols)
애니메이션 개발에 필요한 재사용 가능한 핵심 기술(Tech Specs)을 정의합니다. 모든 애니메이션은 아래의 파라미터 기반으로 작동해야 합니다.

| Module ID | 명칭 | 용도/기능 | Spec & 효과 상세 |
| :---: | :--- | :--- | :--- |
| **MOD-A01** | **[System Glitch]** | 시스템 오류, 데이터 변조 시각화. (필수) | **효과:** 텍스트나 이미지에 강한 수평/수직 노이즈 왜곡 및 깜빡임(Jitter).<br>**색상:** Neon Cyan (`#00FFFF`)만 활용.<br>**파라미터:** `Glitch_Intensity` (강), `Duration` (50~150ms) 조절. |
| **MOD-A02** | **[Error Code Overlay]** | 경고 메시지, 핵심 불안 요소 강조. (필수) | **효과:** 화면 중앙 또는 모서리에 붉은색/Cyan 네온빛으로 깜빡이는 코드를 오버레이. `ERROR CODE [XXX]` 형식.<br>**폰트:** `Orbitron` Bold. <br>**배치:** 하단에 고정된 UI 요소처럼 보이게 처리. |
| **MOD-A03** | **[Data Stream Flow]** | 데이터의 흐름, 복잡한 정보를 시각화. (필수) | **효과:** Deep Black 배경 위로 Cyan 네온빛의 점(Dot)들이 불규칙하게 움직이는 선형 애니메이션(Particle Trail).<br>**속도:** 초반에는 빠르고 혼란스럽게 $\rightarrow$ 후반부엔 느리고 불안정하게. |
| **MOD-A04** | **[Focus Node Alert]** | 특정 정보/변수 강조. (핵심) | **효과:** Data Stream Flow 위에서, 문제가 되는 노드(Node)가 갑자기 멈추고 `#FF0000`에 가까운 경고색으로 점멸하며 주변이 Cyan 빛으로 아우라를 형성. |

## II. [타임라인별 비주얼 Spec Sheet] (Storyboard Mapping)
Writer의 스크립트를 모듈 단위로 분해하여 시간대별 애니메이션 및 UI 지침을 제공합니다.

### 🟢 1단계: HOOK - 패러다임 전환 (불안감 주입)
**[시간 코드]: [00:00 – 00:12]**
**[전반적 분위기]:** 충격, 위협. 시청자의 안전지대를 무너뜨리는 경험 제공.

| 시간 구간 | 스크립트 카피라이팅 (Script) | 비주얼/애니메이션 모듈 | Spec & 디테일 지침 |
| :---: | :--- | :--- | :--- |
| **[0-3초]** | "잠깐만요. 지금 이 영상을 보고 계시다면... 당신의 시스템에 경고 신호가 있다는 뜻입니다." | **MOD-A02 + (새 모듈) [Impact Flash]** | 1. 화면: `#0A0A0A`에서 시작 $\rightarrow$ 즉시 빨간/Cyan 깜빡임으로 전환. <br>2. 애니메이션: `ERROR CODE 404`가 초고속 플래시(Flash, Duration 0.1s)로 지나감. (Deep Boom 사운드와 완벽 동기화).<br>3. **폰트:** Orbitron Bold, 강렬한 네온 글로우 효과 필수. |
| **[3-8초]** | "우리는 시스템이 '정상'이라고 믿습니다. 하지만 진짜 문제는 눈에 보이지 않습니다. 바로 데이터 드리프트(Data Drift)입니다." | **MOD-A01 + MOD-A03 (Fast)** | 1. 전환: 일반 UI가 `[System Glitch]`로 깨지며 화면 전체가 노이즈 폭발(`MOD-A01` 강도 최대)을 일으킴.<br>2. 배경: `Data Stream Flow` (`MOD-A03`)를 빠르게 지나가게 배치하며, 텍스트(Data Drift)에만 Neon Cyan으로 강조하고 지속적인 글리치 효과 적용. |
| **[8-12초]** | "당신이 지금 보고 있는 이 데이터는, 이미 '시간'이라는 변수에 의해 오염되고 있습니다." | **MOD-A04 + MOD-A03 (Slow)** | 1. 전개: 배경의 `Data Stream Flow`가 급격히 느려지고(Slowdown), 마치 정지된 듯한 느낌을 준다.<br>2. 핵심 강조: 스크립트의 '시간'이라는 단어와 함께, **MOD-A04 [Focus Node Alert]**를 실행하여, 흐름 중 하나의 노드(`TIME VARIABLE`)만 경고색으로 점멸시킨다.<br>3. **최종 효과:** 이 구간 끝에서 사운드를 급격히 낮추며 (Silence), 다음 단계로 넘어가기 위한 시각적 블랙아웃(Blackout)을 준비한다. |

### 🟡 2단계: PROBLEM - 데이터 드리프트의 작동 원리 설명
**[시간 코드]: [00:13 – 00:25]**
**(Writer에게 다음 스크립트가 들어온다고 가정하고, 구조만 정의)**
**[전반적 분위기]:** 지식 전달. 전문성 과시. 시청자에게 '이것을 알아야 한다'는 위협감을 심어줌.

| 시간 구간 | 비주얼/애니메이션 모듈 | Spec & 디테일 지침 |
| :---: | :--- | :--- |
| **[00:13-00:25]** | **MOD-A03 (Structured)** + **UI 아웃포커싱** | 1. 애니메이션은 더 정교한 '시스템 다이어그램' 형태로 전환되어야 함. <br>2. `Data Stream Flow`를 배경에 유지하되, 정보 블록(Information Block)들을 체계적으로 배치한다.<br>3. **핵심:** 개념을 설명하는 텍스트는 반드시 `Orbitron` 계열로 작성하고, 문장의 끝 단어 또는 핵심 키워드에만 Cyan 네온빛으로 글리치 효과를 주입하여 시각적 집중도를 높인다. |

| 시간 구간 | 비주얼/애니메이션 모듈 | Spec & 디테일 지침 |

| **[00:26-End]** | **(새 모듈) [Solution Protocol Display]** + **MOD-A01 (Fade Out)** | 1. 분위기 전환을 위해 Deep Black 배경 위에 '진단 프로토콜'이라는 타이틀을 중앙에 크게 배치하고, 여기에 미세한 글리치 효과(`MOD-A01`)를 적용하여 신뢰감 있는 느낌을 준다.<br>2. 해결책 제시 시에는 경고음 대신, 시스템이 정상화되는 듯한(Stabilizing) 청량한 디지털 사운드와 함께, 모든 UI 요소의 빛과 노이즈가 점차 사라지며 안정화된다. <br>3. **마지막 CTA:** 다음 행동을 유도하는 문구는 다시 `MOD-A02` (경고 코드 형태)를 활용하되, 이번에는 '위험' 대신 '해결책/접속 지점'으로 용도를 변경한다. |
