| 요소 | 상세 정의 | 적용 규칙 | 근거 |
| :--- | :--- | :--- | :--- |
| **메인 컬러 (주조색)** | 네온 시안 (Neon Cyan) | `#00FFFF` 또는 유사한 고채도 시안 계열을 데이터 흐름, 강조선, 경고등에 사용. | Designer 개인 메모리 / Writer 최종 지침 |

## 2. 썸네일 컨셉 3안 (A/B/C)
**목표:** '미스터리와 궁금증'을 유발하며, 전문적인 경고의 느낌을 전달하여 클릭률(CTR)을 극대화한다.

### 🖼️ 컨셉 A: 데이터 해킹/시스템 오류 강조형 (가장 추천)
*   **구도:** 중앙에 거대한 '오류 코드' 또는 '경고등 아이콘'이 네온 시안으로 빛나며, 배경은 깊은 블랙이다.
*   **텍스트 배치:** 메인 텍스트는 크고 강렬하게 배치하며, 아래쪽에 작은 글씨로 핵심 질문을 추가한다.
    *   **메인 텍스트:** "🚨 오류 신호 3가지" (네온 시안/빨간색 조합)
    *   **서브 텍스트:** "당신이 모르는 시스템의 진실" (흰색 또는 연한 시안)
*   **느낌:** 해킹된 화면, 기밀 문서 열람. 높은 긴장감과 전문성 강조.

### 🖼️ 컨셉 B: 인물 심리 강조형
*   **구도:** 어두운 배경 속에서 불안하거나 경고하는 듯한 사람의 클로즈업(눈빛 강조). 시안 색상의 빛이 인물의 얼굴 일부를 비춘다.
*   **텍스트 배치:** 텍스트는 최소화하고, 인물의 표정과 조명으로 감정을 전달한다.
    *   **메인 텍스트:** "숨겨진 오류의 증거" (세련된 산세리프체)
    *   **서브 텍스트:** "하이브리드 차량 시스템 해부학"
*   **느낌:** 개인적인 경고, 심층 분석, 내면의 불안감 자극.

### 🖼️ 컨셉 C: 다이어그램/흐름 강조형
*   **구도:** 화면 전체를 네온 시안 선으로 이루어진 복잡한 데이터 흐름(다이어그램)이 블랙 배경 위를 움직이는 형태.
*   **텍스트 배치:** 중앙에 핵심 키워드를 배치하여 정보의 흐름을 시각화한다.
    *   **메인 텍스트:** "데이터 드리프트: 놓친 시스템 오류"
    *   **서브 텍스트:** "전문 진단 보고서가 필요하다"
*   **느낌:** 복잡한 문제에 대한 명확하고 논리적인 분석 제시.

## 3. 영상 내 텍스트 오버레이 상세 지침 (스크립트 매핑)

내레이션의 흐름에 맞춰 시각적 강조점(Visual Cue)을 배치하여, 정보 전달과 긴장감 유지를 동시에 달성한다.

| 시간대 | 내레이션 핵심 내용 | 비주얼 전략 (Anomaly Loop 적용) | 텍스트 오버레이 상세 지침 |
| :--- | :--- | :--- | :--- |
| **[0:00 - 0:03] HOOK** | "혹시... 당신의 차량 경고등을 대수롭지 않게 여기진 않으셨나요? 아닙니다. 그건 원인이 아니라, **시스템이 보내는 '증상'일 뿐입니다.**" | 화면 전체에 네온 시안 선들이 빠르게 번쩍이며 시작 (Glitch/Flash 효과). 배경은 완전히 어둡다. | 텍스트 없음. 오직 사운드와 빛의 움직임만 존재. |
| **[0:03 - 0:15] 문제 제기** | "우리는 시스템의 '정상 작동'만을 믿습니다. 하지만 진짜 문제는 눈에 보이지 않습니다. BMS 데이터 누락이나, 시간이 흐르며 패턴이 변형되는 **‘데이터 드리프트(Data Drift)’** 같은 사각지대에서 이미 치명적인 오류가 시작되고 있습니다." | 복잡한 하이브리드 차량 시스템 다이어그램이 화면을 채우며 네온 시안 선으로 연결됨. 데이터 라인이 미세하게 흔들림 (Drift 표현). | 키워드 **'데이터 드리프트(Data Drift)'**를 중앙에 강조하며, 주변에 흐릿한 오류 코드들이 빠르게 스크롤되어 지나감. |
| **[0:15 - 0:30] 긴장 고조** | (중략) | 데이터 플로우가 정지했다가 갑자기 특정 지점에 집중되며 강하게 깜빡이는 'Anomaly' 순간 연출. | 핵심 오류 지점(BMS, 센서 등)에 빨간색 경고등 아이콘이 네온 시안으로 번쩍임. |
