# 📄 JRock Shorts: T+15s ~ T+30s 'Knowledge Void' 비주얼 에셋 및 애니메이션 사양서 (v3.0)

**[개요]**
*   **섹션 목표:** 시청자에게 구조적 불안감(Structural Anxiety)을 강제적으로 주입하고, 스스로의 인지적 결핍(Cognitive Deficit)을 자각하게 만들어 외부 진단 서비스 필요성을 극대화한다.
*   **시간 코드:** T+15초 ~ T+30초 (총 15초)
*   **테마:** 시스템 경고/데이터 로그 분석 실패 (System Alert / Data Inconsistency).
*   **톤앤매너:** 긴장감, 정밀함, 지적인 위협 (Tech-Noir, High Stress).

---

### I. 🎨 비주얼 디자인 시스템 원칙 준수
1.  **배경 (Background):** Deep Black (`#0A0A0A`). 배경 전체에 미세한 데이터 노이즈 패턴(Scanline/Grain)을 유지하여 정적이지 않게 한다.
2.  **강조색 (Accent):** Neon Cyan (`#00FFFF`). 오류 코드, 핵심 질문 문구, 경고 표시등 등에만 제한적으로 사용한다.
3.  **타이포그래피:** `Orbitron` 또는 유사 기하학적 Sans-serif. 모든 텍스트는 글리치/스캔라인 필터를 통과한 듯 처리한다.

### II. ⚙️ 시간대별 애니메이션 및 에셋 지침 (Timecode Breakdown)
| Timecode | 내용 구성 (Script Focus) | 시각 효과 (Visual Effect) | 레이아웃 & 액션 가이드 |
| :---: | :---: | :---: | :--- |
| **T+15s ~ T+18s** | **[Phase I: 데이터 흐름 중단]**<br>("이것은 단순한 위기가 아닙니다. 구조적 실패입니다.") | **시스템 아웃(System Out):** 화면 전체에 순간적인 블랙아웃과 함께, 네온 시안의 'DATA CORRUPTION' 또는 'ERROR CODE 407: LOGIC FAILED' 메시지가 플래시 컷처럼 강하게 터진다. | **좌측 상단:** 작은 글씨로 `[STATUS: CRITICAL]` 표시. <br>**중앙:** 가장 큰 글자로 오류 코드를 배치하고, 코드 주변에 빨간색/노란색 경고 패턴을 빠르게 깜빡이게 한다 (⚠️). |
| **T+18s ~ T+25s** | **[Phase II: 지식 공백 유도 및 질문 제시]**<br>(시청자에게 '나만 모르는 것'이라는 의구심 주입)<br>("당신의 OOO은 과연 현재 시스템에 정상적으로 연결되어 있습니까?") | **정보 왜곡/글리치(Glitch Protocol Max):** 화면이 찢어지거나, 영상 데이터가 노이즈로 변하는 듯한 효과를 적용한다. 배경의 미세 노이즈가 갑자기 증폭되며 시야를 방해한다. | **[핵심 레이아웃: Diagnostic Panel]**<br>1. **헤더:** `[DIAGNOSTIC PROTOCOL RUNNING]` (작은 네온 시안 폰트로 상단 고정).<br>2. **메인 질문 영역:** 가장 크고 중앙에 위치하며, '질문 프롬프트'가 글리치 효과와 함께 점진적으로 나타난다. (예: "당신의 OOO는 정상 범위인가요?")<br>3. **참조 데이터:** 화면 하단에 가짜 그래프(Fake Graph) 또는 파라미터 차트(Parameter Chart)를 배치하고, 특정 지점만 붉은색으로 급상승/하락하는 애니메이션을 넣는다 (불안감 유도). |
| **T+25s ~ T+30s** | **[Phase III: 공포의 확정 및 해결책 부재]**<br>("이 질문에 대한 답은, 오직 외부 전문 진단만이 할 수 있습니다.") | **데이터 필터링/차단:** 화면 전체가 순간적으로 'ACCESS DENIED' 메시지와 함께 먹통(Blackout) 상태로 변한다. 이어서 깨끗하고 정돈된 UI (랜딩 페이지 느낌)가 슬로우 모션으로 나타나며, 혼란스러움에서 '해결책'의 실체를 보여준다. | **[Call to Action Prompt]**<br>1. **텍스트:** "진단이 필요합니다." 혹은 "전문 컨설팅 접수" 등 명확한 문구를 배치한다.<br>2. **시각적 요소:** 전문적인 느낌을 주는 '진단 체크리스트' 형태의 UI 모형(Mockup)이 화면에 나타나며, 이 부분을 바라보도록 유도한다 (손가락 포인터 효과). |

---

### III. ✏️ 필수 강조 레이아웃: 질문 프롬프트 설계 지침
1.  **위치:** 화면 중앙의 Diagnostic Panel 내부에 배치하여 시선을 즉시 붙잡는다.
2.  **효과:** 단순히 글자가 나타나는 것이 아니라, 마치 시스템이 '질문을 검색하고 로딩하는' 것처럼 **글리치 애니메이션 + 타이핑 효과(Typewriter Effect)**를 결합한다.
3.  **강조 방식:** 질문 문구 중 시청자의 약점이나 궁금증을 건드리는 핵심 키워드는 Neon Cyan으로 하이라이트 처리하거나, 작은 `[!]` 경고 아이콘을 붙여 전문적인 위협감을 조성해야 한다.
