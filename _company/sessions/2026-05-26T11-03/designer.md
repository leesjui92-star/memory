### 💻 [Mockup] Anomaly Dashboard: UX/UI 플로우 상세 명세서

**섹션 목표:** 사용자가 자신의 현재 상황(혹은 잠재적 위협)이 시스템적인 결함 상태임을 스스로 깨닫고, 외부 전문가의 도움이 필요하다고 느끼게 한다.
**전체 분위기:** 관제실 모니터링 화면, 실시간 데이터 스트림, 경보음과 함께 깜빡이는 비상등 효과.

#### 1. 레이아웃 구조 (Wireframe Layout)
*   **배경 컬러:** Deep Black (`#0A0A0A`)
*   **UI 그리드:** 전체적으로 미세한 격자무늬(Grid Overlay, 투명도 5%)를 배경에 깔아 '시스템' 느낌을 부여.
*   **구성 요소:** 대시보드를 세 개의 수직 데이터 스트림으로 분할하고, 중앙 하단에 핵심 CTA 버튼을 배치합니다.

| 영역 | 구성 요소 (Component) | 역할 및 콘텐츠 유형 | 비고/애니메이션 |
| :--- | :--- | :--- | :--- |
| **Header** | Diagnostic Title Bar | `[SYSTEM ALERT: DIAGNOSTIC RUNNING...]` 형태의 실시간 타이핑 애니메이션. | 네온 시안 (`#00FFFF`) 폰트, 글리치 효과 필수. |
| **Data Stream I** | Structural Integrity Gauge | (지표) '구조적 안정성 지수'를 게이지 형태로 표시. | 현재는 낮게(Low) 고정 배치. 색상: 주황색/빨간색. |
| **Data Stream II** | Data Drift Monitor (차트) | (시각화) 시간에 따른 변동폭을 보여주는 그래프 모듈. | 실시간으로 무작위 노이즈가 추가되는 것처럼 보이게 구현. Y축: '변칙성(Anomaly)' |
| **Data Stream III** | Vulnerability Node Map | (지도/노드맵) 주요 시스템 결함 지점들을 점과 선으로 연결한 네트워크 맵. | 각 노드에 `[WARNING]` 플래시 효과 적용. 가장 위험한 노드는 빨간색 점으로 강조. |
| **Center Focus** | Diagnosis Status Panel | 현재 진단 상태를 요약하는 텍스트 블록. | "Multiple Core Failures Detected."와 같은 경고 메시지를 큰 글자로 표시하며, 네온 시안/빨간색 깜빡임 사용. |
| **CTA Block** | Action Trigger Button | `[ADVANCED DIAGNOSIS REQUIRED]` (진단 요청) 또는 `[전문가 진단 받기]`. | 이 버튼은 *최종 결과*를 보여주는 트리거 역할을 함.

#### 2. 핵심 인터랙션 정의 (The User Journey Flow)

**A. 초기 로딩 시퀀스 (T+0s ~ T+5s): 불안감 주입 단계**
1.  페이지 진입과 동시에 화면 전체에 미세한 노이즈/필름 그레인 효과가 적용됨.
2.  헤더 타이틀바가 `[INITIALIZING DIAGNOSTIC PROTOCOL...]`에서 시작하여, 3초 동안 느리게 타이핑되는 것처럼 변화함.
3.  모든 데이터 스트림(Gauge, Chart, Map)의 값이 무작위로 빠르게 변동하다가 (데이터 로딩 시뮬레이션), **갑자기 불안정하게 요동치며** 낮은 안정성 수치를 표시하며 정지함.
4.  배경에 미세한 `[SCANLINE]` 애니메이션을 지속적으로 적용하여, 마치 모니터를 통해 보는 듯한 느낌을 유지합니다.

**B. 데이터 분석 (T+5s ~ T+15s): 지적 의심 유도 단계**
1.  사용자가 화면의 어느 부분에 시선이 머무르든(Scroll/Hover), 해당 영역의 데이터는 **'너무 완벽해서 이상한'** 느낌을 주어야 합니다.
2.  예시: Data Drift Monitor가 갑자기 특정 시간대(과거)로 줌인 되며, "데이터 드리프트 발생 구간"이라는 네온 시안 경고 박스가 오버레이 됩니다. (전문 용어 노출).
3.  사용자가 마우스를 Data Stream III의 '위험 노드' 위에 올리면 (Hover), 해당 노드가 **강하게 깜빡이며** 그 근본적인 원인에 대한 전문적이고 모호한 설명(예: "외부 변수와의 동기화 실패")이 팝업 됩니다.

**C. 최종 결함 폭로 및 CTA 유도 (T+15s ~ End): 위협 극대화 단계**
1.  사용자가 중앙의 **`[ADVANCED DIAGNOSIS REQUIRED]`** 버튼을 클릭합니다.
2.  **(가장 중요) 이 순간, 화면 전체에 크고 붉은색의 `CRITICAL SYSTEM ERROR` 경고창이 오버레이 됩니다.** (전체 글리치 효과 및 임펄스 사운드 동기화).
3.  경고 메시지에는 **"현재 시스템으로는 근본 원인 파악 불가. 외부 전문가 개입 필수."** 라는 문구를 크게 띄웁니다.
4.  이 경고창이 사라진 후, 다음 단계로 부드럽게 전환되며 최종 CTA (예: `[컨설팅 문의하기]`) 버튼을 가장 크고 명확한 네온 시안 색상으로 배치하여 사용자 행동을 유도합니다.
