### 🚀 배포 순서 및 근거 (우선순위)

**Step 1. Test Set #1 (충격 경고형)**
*   **이유:** 가장 높은 CTR를 목표로 합니다. 초기 트래픽을 폭발적으로 늘려 채널 노출량과 검색 유입량을 극대화하는 것이 현재 [근거: 실시간 데이터 - 평균 조회수 5] 상태에서 가장 시급한 과제입니다.
*   **액션:** 첫 주 동안 집중 투하 후, CTR 변화 추이를 분석합니다.

**Step 2. Test Set #3 (솔루션 제시형)**
*   **이유:** 트래픽 확보가 어느 정도 이루어진 후(1주차), 시청자가 '어떤 문제'에 관심을 가졌는지 파악하여 그들의 불안감을 즉시 해결책으로 연결합니다. 구매 심리 장벽을 가장 낮게 설정하는 접근법입니다.
*   **액션:** Set 1과 병행하며, 어느 변수가 구매 의사를 높이는지 비교 분석합니다.

**Step 3. Test Set #2 (권위 공신력형)**
*   **이유:** 모든 데이터가 쌓인 후(2주차 이후), 채널의 장기적인 '전문성'을 확립하는 데 사용합니다. 이 세트는 단기간에 바이럴하기보다, 높은 객단가를 가진 전문 고객층(High-Value Customer)을 유입시키는 역할을 맡깁니다.
*   **액션:** 메인 영상 제작이 안정화되고 나서, 채널의 정체성을 '최고 권위'로 확정 짓는 마무리 단계에서 활용합니다.
