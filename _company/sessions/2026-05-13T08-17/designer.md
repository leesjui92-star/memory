## 🖼️ 비주얼 시스템: 컨셉 A-1 (데이터 해킹 강조형)

### 1. 색상 팔레트 (Color Palette)
시스템 오류의 느낌과 데이터 흐름을 극대화하기 위해 네온 시안을 주조색으로 사용합니다.

| 역할 | 색상 코드 | 설명 | 적용 범위 |
| :--- | :--- | :--- | :--- |
| **배경 (Background)** | `#0A0A0A` (Deep Black) | 깊은 어둠, 시스템의 심연 표현. | 전체 배경, 주요 컨테이너 |
| **강조색 (Primary Accent)** | `#00FFFF` (Neon Cyan) | 데이터 스트림, 핵심 정보, 글리치 효과 강조. | 타이틀, 핵심 숫자, 경고 표시 |
| **보조 강조색 (Secondary Accent)** | `#00CCFF` (Lighter Cyan) | 네온 시안의 글로우(Glow) 및 활성화된 데이터 라인 표현. | 테두리, 애니메이션 효과 |
| **텍스트/디테일** | `#444444` (Subtle Gray) | 보조 정보, 배경 요소, 시스템 UI 프레임. | 부가 설명 텍스트, 미세한 디테일 |

### 2. 타이포그래피 시스템 (Typography System)
시스템 오류 시각화를 위해 고대비 산세리프체를 사용하며, 글리치 효과를 적용하여 불안감을 조성합니다.

*   **메인 타이틀 (Headline):** `Orbitron` 또는 `Rajdhani`
    *   **스타일:** 매우 굵게(Extra Bold), 대문자, 네온 시안 (`#00FFFF`)
    *   **효과:** 텍스트에 미세한 글리치(Glitch) 및 노이즈 필터 적용. (디지털 오류 시각화)
*   **본문/데이터 (Body/Data):** `Rajdhani` 또는 시스템 기본 Sans-serif
    *   **스타일:** 중간 굵기, 흰색 또는 밝은 회색 (`#FFFFFF`, `#444444`)
    *   **적용:** 정보의 계층 구조를 명확히 구분하며, 데이터 스트림처럼 배치.

### 3. 레이아웃 및 구도 원칙 (Layout & Composition Principles)
'실시간 상황판(Dashboard)'의 개념을 영상 내에 투영하여 몰입감을 극대화합니다.

*   **구도:** **대각선/분할 구도 강조.** 화면을 중앙에서 대칭적으로 나누기보다, 데이터가 쏟아지는 듯한 비정형적인 사선 분할 또는 레이어링을 사용합니다.
*   **핵심 요소 배치:**
    1.  **중앙 집중:** 핵심 정보(예: 실패 모드 지표)는 화면 중앙에 위치시키되, 주변으로 데이터 라인(Cyan Glow)이 폭발하듯 뻗어나가게 합니다.
    2.  **레이어링 (Layering):** 배경 위에 투명한 그리드 또는 회로판(Circuit Board) 오버레이를 배치하여 깊이감(Depth)을 부여합니다.
    3.  **글리치 효과:** 모든 텍스트와 핵심 UI 요소에는 미세하고 주기적인 노이즈/색상 번짐(Chromatic Aberration) 필터를 적용하여 시스템 불안정성을 시각적으로 표현합니다.

### 4. 썸네일 컨셉 A-1 (핵심 비주얼 요약)
**컨셉 명:** The Anomaly Core (이상점의 핵)

*   **주요 구성:** 중앙에 거대한 '시스템 오류' 또는 '데이터 폭발' 형태를 배치하고, 그 중심에 네온 시안으로 강조된 핵심 실패 지표(예: `ERROR: Temporal Gap Detected`)를 배치합니다.
*   **배경 처리:** 깊은 블랙 배경 위에 회로판 패턴을 희미하게 깔고, 중앙 오류 영역만 강렬한 네온 시안 빛이 발산하도록 연출하여 '데이터가 멈추는 순간'의 긴장감을 포착합니다.
*   **텍스트 배치:** 타이틀은 좌측 상단에 `Orbitron`으로 배치하고, 핵심 메시지는 중앙에 크고 강렬하게 배치합니다.
