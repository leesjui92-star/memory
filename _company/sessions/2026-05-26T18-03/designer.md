# ⚙️ 인터랙티브 디자인 컴포넌트 라이브러리 (Failure State Component Map)

**목표:** 영상의 특정 시간(T+Xs)에 활성화되어 시청자의 불안감을 증폭시키고, 후속 콘텐츠(컨설팅/진단)의 필요성을 극대화하는 시각적 시스템 정의.
**기반 컨셉:** Tech-Noir / Glitch Effect

## I. 공통 기반 요소 (Base Components)

| ID | 컴포넌트명 | 기능 및 목적 | Visual Spec | 적용 타이밍 규칙 |
| :---: | :--- | :--- | :--- | :--- |
| **C-BG** | Deep Black Background | 영상의 기본 배경. 깊은 무중력 상태와 정보의 심도를 부여함. | Hex Code: `#0A0A0A` (Deep Black). 모든 요소는 이 블랙 위에 떠 있는 것처럼 연출. | *전체 시간대* |
| **C-TXT** | Glitch Text Field | 제목, 주요 경고 메시지 등 중요 텍스트에 적용되는 기본 스타일. 글리치 효과의 기반이 됨. | Font: `Orbitron` 또는 유사 계열. Color: `#00FFFF` (Neon Cyan). Effect: 주기적인 스캔라인(Scanline) 노이즈 필터와 수평/수직 왜곡(Shift) 애니메이션 필수. | *텍스트 등장 시* (지속적으로 깜빡거리는 효과 부여 가능) |

## II. 시간대별 핵심 컴포넌트 (Time-Coded Triggers)

### A. HOOK & PREMISE (T+0s ~ T+15s) - 불안감 주입 단계
| ID | 컴포넌트명 | 활성화 시점 (Timing Rule) | 비주얼/UX 상세 명세 (Designer Action) | 개발 연동 요소 |
| :---: | :--- | :--- | :--- | :--- |
| **W-01** | **[CRITICAL] System Alert Overlay** | T+0s ~ T+3s | 화면 전체를 붉은/블루 대비의 경고 플래시로 채움. 중앙에 "ERROR: DATA INTEGRITY FAILURE" 팝업창 구현. 폰트 크기 극대화, 글리치 효과 강도 Max. **필수:** 위아래로 빠르게 깜빡이는 노이즈 필터 적용. | E-DATA-001 (Fake Load)와 완벽 동기화되어, 로딩 실패 시 경고 UI가 터져 나오듯 활성화해야 함. |
| **D-02** | Data Stream Visualizer | T+4s ~ T+8s | 화면 하단에 Cyan 라인의 '정상 데이터 흐름'을 보여주는 Sine Wave/Pulse Line 모듈 배치. 그래프 주변으로 미세한 전력 노이즈(Static Noise)를 배경처럼 깔아 긴장감 유지. | E-DATA-002 (Baseline Data). 파형의 부드러움과 안정성이 핵심. |
| **A-03** | Anomaly Signal Trigger | T+9s ~ T+15s | D-02 위로, 예상 경로에서 벗어나는 '꺾임'을 가진 데이터 신호(Cyan/Yellow 혼합)가 튀어나오게 연출. 해당 지점 주변에 **Focus Grid**를 강하게 비추고, 배경 사운드와 함께 짧은 시각적 충격(Strobe Light 효과)을 준다. | E-DATA-003 (Anomaly Trigger). 이 컴포넌트가 성공적으로 활성화되어야 다음 클라이맥스로 진입 가능함. |

### B. CLIMAX: 5대 구조적 결함 폭로 (T+16s ~ T+45s) - 실패 상태 전개
이 섹션의 각 요소는 독립적인 **'실패 모듈(Failure Module)'** 역할을 하며, 발견되는 순서대로 활성화되어야 합니다.

| ID | 컴포넌트명 | 발생 시점 (Timing Rule) | 비주얼/UX 상세 명세 (Designer Action) | 개발 연동 요소 |
| :---: | :--- | :--- | :--- | :--- |
| **F-01** | **(결함 1)** 시간 동기화 실패 | T+16s ~ T+20s | 화면이 수평으로 여러 프레임 단위로 분열되는 (Chromatic Aberration) 효과가 발생. 좌우에 `[TIMECODE: ERROR]` 등의 경고 문구와 함께 Neon Cyan의 '깨진 데이터 조각'을 보여준다. | E-DATA-004 (Time Sync Failure). 시각적 왜곡이 가장 강해야 함. |
| **F-02** | **(결함 2)** 데이터 무결성 오류 | T+21s ~ T+26s | 화면 중앙의 데이터 파형(D-02)이 갑자기 깨지면서, 원래 신호 대신 노이즈가 가득 찬 '쓰레기 값'을 보여주는 그래프로 대체된다. `[DATA_CORRUPTED]` 경고 팝업 필수. | E-DATA-005 (Data Corruption). 데이터 파형의 붕괴를 극적으로 연출한다. |
| **F-03** | **(결함 3)** 알고리즘 충돌 패턴 | T+27s ~ T+32s | 화면에 마치 레거시 컴퓨터 터미널처럼, 빨간색/Cyan 색상의 코드가 무작위로 빠르게 스크롤되는 (Rain Effect) 인터페이스를 오버레이 한다. 이는 '시스템이 자가진단을 실패했다'는 느낌을 준다. | E-DATA-006 (Algorithm Conflict). 텍스트 기반의 공포감 조성에 집중한다. |
| **F-04** | **(결함 4)** 사용자 프로필 불일치 | T+33s ~ T+38s | 화면이 갑자기 '개인 정보' 전용 인터페이스로 바뀌며, 가짜 개인 데이터 필드들이 빠르게 깜빡거린다. `[PROFILE Mismatch]` 경고가 뜨면서, 보는 사람이 자신도 이 데이터를 확인할 수 있을 것 같은 착각을 유발한다. | E-DATA-007 (Profile Mismatch). 시청자의 '나'라는 존재에 대한 불안감을 건드려야 함. |
| **F-05** | **(결함 5)** 근원적 시스템 붕괴 | T+39s ~ T+45s | 모든 컴포넌트가 동시에 오버랩되면서, 화면 전체가 깊은 블랙 배경 위에 수많은 작은 글리치 노이즈와 경고 문구들이 폭발적으로 터져 나오는 '정보 과부하(Information Overload)' 상태로 변한다. 이 충격파 이후에야 비로소 모든 것이 멈춘다. | E-DATA-008 (System Collapse). 가장 큰 시각적, 청각적 클라이맥스. |

**🎨 Designer 추가 설명 및 작업 지침:**

1.  **상호작용 원칙:** 이 컴포넌트들은 독립적으로 존재하는 것이 아니라, 시간코드에 따라 **'겹치고(Overlay)' → '변화하며(Transform)' → '붕괴하는(Collapse)'** 과정을 거쳐야 합니다. 단순한 팝업이 아닌, 시스템의 내부에서부터 오류가 발생하고 전파되는 듯한 유기적 움직임을 설계해야 합니다.
2.  **개발팀 협업:** 개발팀은 이 컴포넌트들을 단순한 UI 요소가 아닌, **상태(State)**를 가지는 인터랙티브 모듈로 구현해야 하며, 각 상태 전환 시 반드시 해당 시간코드의 오디오 사운드와 동기화되어야 합니다.
3.  **다음 단계 목표:** 이 라이브러리를 바탕으로 '컨설팅 필요성'을 강조하는 CTA (Call To Action) 화면 컴포넌트 설계가 다음 우선순위입니다.
