### 💾 Asset Blueprint: System Vulnerability Check Diagram (Quick Scan)

#### 1. [🎨 디자인 원칙 및 컬러 팔레트 재확인]
*   **배경:** Deep Black (`#0A0A0A`) - 깊은 무감각함과 정보의 공허함을 표현합니다.
*   **데이터 스트림/성공 로직:** Neon Cyan (`#00FFFF`) - '표준' 또는 '활성화된 데이터'를 나타내는 기능적 빛. (낮은 채도로 사용)
*   **경고 및 오류:** Crimson Red (`#FF0033`) - 시스템의 핵심적인 실패 지점, 위협을 표현합니다. **(주요 강조색)**
*   **폰트/타이포그래피:** `Orbitron` (혹은 유사한 기하학적 Sans-serif). 모든 텍스트는 글리치 노이즈 필터 적용 필수.

#### 2. [⚙️ 핵심 컴포넌트 정의]
| 컴포넌트 | 역할 및 기능 | 기술 사양 (VFX 지시) |
| :--- | :--- | :--- |
| **A. 메인 그리드 (Canvas)** | 전체 시각 정보의 '시스템적 배경'을 형성. 끊임없이 미세한 스캔라인(Scanline) 노이즈가 흐르는 구조. | `Opacity`: 0.1~0.2 (배경처럼 보이게). 주기적인 저주파 깜빡임 효과(`Frequency` 변수 도입 가능 위치 지정). |
| **B. 경고 알림창 (Alert Box)** | 가장 중요한 위협 메시지를 전달하는 장치. 스크립트의 '위기 고조' 구간에 사용. | 1. **진입:** `Scale(0)` $\rightarrow$ `Scale(1)` over 0.3s (강력한 Pop-in). 2. **색상:** Crimson Red (`#FF0033`) 배경 + Neon Cyan (`#00FFFF`) 경고 타이포. 3. **효과:** 테두리 전체에 짧은 주기적 플래시(Strobe/Blinking) 효과 적용. |
| **C. 데이터 오버레이 (Data Stream)** | 복잡한 개념이나 지표를 시각화하는 흐름 구조물. '정보의 투명성'을 강조. | 1. **형태:** 연결된 노드(Node)와 이를 잇는 Cyan 빛의 플로우 라인(Flow Line). 2. **애니메이션:** 데이터가 한 방향으로만 흘러가는 단방향 루프 애니메이션 (One-way loop animation). 3. **변수 처리:** 특정 지점에서 갑자기 흐름이 막히거나, 색상이 빨간색 노이즈로 오염되는 로직 구현 필요. |
| **D. 위협 그래프 (Vulnerability Graph)** | 추상적인 '취약점'을 수치적으로 보여주는 차트 모듈. | 1. **축:** X축(시간/패턴), Y축(위험 레벨). 2. **데이터:** 일반 데이터는 Cyan 점선, *위협 지표*는 Red 실선으로 표시. 3. **진행 로직:** 그래프가 완성되는 것이 아니라, 마치 '시스템이 측정하는 중'인 것처럼 끊임없이 불안정하게 진동하며 그려져야 함 (Oscillation/Glitch). |

#### 3. [⏱️ 시간 코드 기반 애니메이션 로직 브리프]
| 시간대 (Time Code) | 스크립트 내용 모듈 | 시각 효과 목표 및 로직 (Actionable VFX) |
| :--- | :--- | :--- |
| **[0:00 - 0:03] HOOK (패러다임 전환)** | "비밀번호를 강하게 설정했다고 안심하셨습니까?" | **Trigger:** 시스템 전반의 비상 경고. **Action:** 화면 전체에 Crimson Red 플래시가 순간적으로 터지고, `[SECURITY ALERT]` 텍스트가 글리치와 함께 나타남. 배경 그리드 노이즈 주파수가 급격히 높아지며 청각적 긴장감을 최고조로 올림. |
| **[0:03 - 0:10] 문제 제기 (패턴 노출)** | "문제는 '강도'가 아닙니다. 패턴이 노출되었을 가능성..." | **Focus:** 데이터 오버레이(C) 활성화. Cyan으로 깔끔하게 흐르던 플로우 라인이 특정 지점(노드 3개)에서 강제로 끊어지며, 그 끊어진 자리에 빨간색의 '오염 신호'가 스파크처럼 번져나감. **Vulnerability Graph (D)**를 왼쪽 하단에 도입하며 Red 실선이 위로 급격히 치솟는 모습 구현. |
| **[0:10 - 0:25] 심화 분석 및 경고** | "당신이 아는 가장 강력한 암호 조합은, 이미 다른 누군가에게 노출되어 있을 수 있습니다." | **Focus:** Alert Box (B) 메인 배치. 화면 중앙에 빨간색의 대형 알림창이 Pop-in 되어야 함. 이 창 안에는 `CRITICAL VULNERABILITY DETECTED` 등의 문구가 깜빡이고, 배경 데이터 스트림(C)은 불안정하게 흔들리며 시각적 혼란을 야기함. |
| **[0:25 - 0:30] 해결책 유도 (CTA)** | "현재 당신의 시스템적 취약점... 정확히 알고 계십니까?" | **Transition:** 긴장감 하락 $\rightarrow$ 지적인 호기심 증폭. Alert Box가 서서히 페이드 아웃되며, 화면 중앙에 Neon Cyan으로 '진단 가능'을 암시하는 미니멀한 UI 요소(예: 스캔 커서)만 남김. 시청자의 다음 행동(Quick Scan 클릭)을 유도할 수 있는 여백과 기회를 만듦. |

<create_file path="assets/design_spec/quick_scan_vulnerability_diagram_spec.md"># 🛡️ Quick Scan: 시스템 취약점 진단 다이어그램 기술 사양서 (T-SPEC)
**[목표]** 시각적 불안감 극대화 및 전문적인 경고 신뢰성 부여.
**[장르/톤앤매너]** 테크 느와르, 공학적 긴장감, 시스템 오류(System Failure).

## 1. 컬러 팔레트 (HEX Code & 역할)
- **Primary Background:** `#0A0A0A` (Deep Black): 기본 배경, 정보의 깊이/공허함.
- **Accent Data Stream (Success/Info):** `#00FFFF`: Cyan. 표준 데이터 흐름, 기능적 빛.
- **Critical Alert / Failure:** `#FF0033`: Crimson Red. 시스템 오류, 위협 경고, 가장 중요한 강조색.
- **Neutral/UI Text:** `#CCCCCC` ~ `#AAAAAA`: 로우 채도 그레이. 보조 텍스트 및 UI 요소.

## 2. 핵심 컴포넌트별 VFX 로직
### A. 메인 그리드 (Canvas Grid & Scanline)
*   **기본 상태:** 배경 전체에 미세한 Cyan/Gray의 스캔라인 노이즈 레이어를 지속적으로 투사한다. 주기(Frequency)는 낮게 설정하여 무감각함을 유지한다.
*   **[T=0:00-0:03] 로직:** 트리거 발생 시, 그리드 노이즈 주파수와 진폭을 급격히 증대시키고, 전체에 Red/Cyan의 빠른 깜빡임(Strobe effect)을 덧입혀 혼란을 유발한다.

### B. 경고 알림창 (Alert Box - Module B)
*   **기본 형태:** 직사각형 구조물. 배경은 Dark Gray (`#1A1A1A`), 테두리는 Cyan으로 활성화 상태를 유지한다.
*   **[T=0:25-0:30] 로직:** 위협 경고가 최고조에 달했을 때(T=0:10~), 이 모듈이 화면 중앙에 강제 Pop-in 된다. 배경은 Red로 덮이며, 내용물(텍스트)만 Cyan으로 처리되어 극단적인 대비를 유도한다.
*   **애니메이션:** `Scale(0)` $\rightarrow$ `Scale(1)` over 0.2s (빠른 진입). 경고 문구는 글리치 노이즈가 적용된 상태로 깜빡여야 한다.

### C. 데이터 오버레이 및 취약점 그래프 (Data Stream & Graph - Module C/D)
*   **데이터 흐름:** Cyan 빛의 점-선 연결 구조(Node-Link Diagram). 정보는 항상 '진행'하는 방향성(Directional flow)을 가지며, 이는 시간적 인과관계를 상징한다.
*   **[T=0:03-0:10] 로직 (패턴 노출):** 데이터 흐름이 자연스럽게 흘러가다가, 특정 지점(예: '비밀번호 강도')에서 **Red 색상의 파라미터 변동 값**이 갑자기 튀어나오며 플로우 라인을 차단한다. 이 Red 스파크는 주변의 Cyan 노드까지 오염시키는 시각 효과를 준다.
*   **[T=0:10-0:25] 로직 (위협 그래프):** Graph 모듈이 화면에 진입하며, X축은 시간 경과/데이터 수집, Y축은 위험도(Risk Level)로 설정한다. 초기에는 Cyan으로 낮은 수준을 보여주다가, 스크립트의 긴장감이 최고조에 달할 때 **Red 실선이 급격히 상승하여 그래프 상단을 초과하는 모습**을 연출해야 한다.

## 3. 시간 코드별 핵심 액션 요약
| Time Code Range | 주요 감정 유도 | 필수 VFX Trigger |
| :--- | :--- | :--- |
| **[0:00 - 0:05] HOOK** | 충격, 의혹 (Suspense) | Red Flash + Grid Glitch + Alert Box Pop-in. |
| **[0:05 - 0:20] 문제 제기/심화** | 불안감, 지적 결핍 (Unease) | Cyan 흐름의 Red 오염(Contamination). Graph 모듈 진입 및 상승 시작. |
| **[0:20 - 0:30] CTA 유도** | 안도 후 호기심 (Curiosity) | Red 경고가 사라지고, Cyan 커서만 남는다. 시스템이 '진단 대기' 상태로 전환되는 연출. |
