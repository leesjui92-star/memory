## 🖥️ 2. 글리치 UI 및 시스템 경고 애니메이션 (The Glitch Protocol)

이 효과는 단순한 시각적 꾸밈이 아니라, **'시스템의 오류 발생 순간'**을 명시적으로 보여주는 API 트리거로 작동해야 합니다.

### 🔹 A. 구현 원칙: 시간 코드 기반 트리거
| 모듈명 | 발동 조건 (Trigger) | 애니메이션 로직 (Effect Logic) | 사용 목적 |
| :--- | :--- | :--- | :--- |
| `[TRIGGER_FAIL]` | **(Time Code)** 스크립트 상의 핵심 메시지 전환 또는 '문제 제기' 구간 시작 시. | 1. 화면 전체에 순간적인 *Chrominance Aberration* (빨강/청록 분리) 발생. 2. 사운드적으로 `[BEEP]` 및 노이즈 직진음 삽입. 3. 텍스트가 데이터 패킷처럼 깨지며 재조립되는 시각 효과 (`Glitch Jitter`). | **시스템 오류 경고.** 가장 중요한 개념이나 위협을 제시할 때 사용 (최대 긴장감). |
| `[TRIGGER_DATA]` | **(Script Event)** 복잡한 전문 용어(`Metadata`, `Protocol`)나 데이터 플로우 다이어그램이 등장하는 순간. | 1. 화면의 특정 영역만 일시적으로 *Scanline* 필터가 지나가는 효과. 2. 텍스트에 네온 Cyan 색상의 미세한 **노이즈 떨림** 추가. | **정보 밀도 증가.** 지적 전문성을 강조하며, 시청자가 '보고서'를 보는 듯한 몰입감을 부여. |
| `[TRIGGER_TRANSITION]` | **(Time Code)** 스크립트의 주제가 바뀌거나, 새로운 데이터 출처로 넘어갈 때 (예: 챕터 전환). | 화면 전체에 짧은 시간 동안 *데이터 전송 실패*를 연상시키는 모션 블러와 함께 깜빡이는 Cyan Grid Overlay. 사운드적으로 `[STATIC ZAP]` 효과 적용. | **구조적 분리.** 콘텐츠의 구조를 명확히 하고, 다음에 나올 내용에 대한 기대를 유도. |

## 📊 3. 데이터 비주얼라이제이션 모듈 표준 (Infographic Standard)

단순한 차트가 아닌, '진단 보고서'에 필수적인 시스템 로그 형태로 구현합니다. 모든 그래프는 배경의 Deep Black 위에 Cyan/Red 라인으로 구성되어야 합니다.

### 🔹 A. 주요 모듈 타입 및 규격
| 모듈명 | 역할 / 사용 목적 (The Gap) | 시각적 구조 (Layout & Component) | 데이터 표시 방식 | 근거 출처 |
| :--- | :--- | :--- | :--- | :--- |
| **1. Time-Series Anomaly Plot** | 시간 흐름에 따른 '정상 범위 이탈' 추적. (예: 물류 마비 지수) | X축: 시간(Time Code), Y축: 측정값(Index). 배경은 Grid Pattern. 정상 범위를 나타내는 투명한 Cyan 박스를 그리고, 데이터가 이 밖으로 벗어나는 부분에 **Critical Red** 점선을 사용한다. | 선 그래프 + 영역 하이라이트. (Deviation Zone 강조) | [근거: Researcher ① 핵심 사례] |
| **2. Protocol Flowchart** | 시스템 작동의 논리적 흐름 및 실패 지점 추적. (예: 자격증 제도 변화) | 왼쪽에서 오른쪽으로 진행하는 화살표 기반 플로우차트 구조. 각 단계(Node)는 모서리가 둥근 직사각형이며, 정상 경로는 Cyan 테두리로, **위험 경로**는 Red 테두리 + `[SYSTEM FAIL]` 배지 처리. | 순차적 블록 다이어그램 (Process Mapping). | [근거: Designer 개인 메모리 - Dashboard 브리프] |
| **3. Comparative Gap Matrix** | 현재 상태와 미래 예측 간의 '결함' 비교. (예: 역량 격차 통계) | 2xN 테이블 형태. 가로축은 핵심 요소(지식, 판단력, 시스템 등), 세로축은 [현재] vs [미래]. 차이점(Gap)이 있는 셀에 `[GAP DETECTED]`라는 Cyan/Red 배지를 강제 배치한다. | 비교표 + 강조형 뱃지. (명확한 대비 유도). | [근거: Writer Researcher 데이터 패키지] |

## 🚨 4. 전자기기 오류 코드 오버레이 레이어 시스템 (The Overlay Layer)

이 모듈은 영상 전체에 투사되는 '필터' 역할을 하며, 콘텐츠의 전문성과 몰입도를 높입니다. 모든 정보는 이 필터를 통과한 것처럼 보이게 처리해야 합니다.

### 🔹 A. 규격화된 요소
1. **HUD (Heads-Up Display) Module:** 화면 좌측 상단 또는 우측 하단에 고정 배치되는 가상 디스플레이 패널. 현재 시간(`[T+01:23]`), 진단 모드, 그리고 분석 중인 데이터의 이름(Metadata)을 작은 `Orbitron` 폰트로 표시합니다.
2. **Status Bar:** 화면 상하단을 가로지르는 투명한 바. 여기에 네온 시안색으로 현재 시스템의 전반적인 상태 (예: `STATUS: STABLE`, `WARNING: HIGH LATENCY`)를 문장 형태로 지속적으로 노출시킵니다. 이 Status Bar는 영상 전체에 배경처럼 존재하며, 긴장감을 유지하는 역할을 합니다.
3. **Data Stream Overlay:** 화면 가장자리를 따라 흐르는 미세한 Cyan/Green의 무작위 데이터 코드(Binary Code 느낌) 애니메이션을 배경으로 깔아줍니다. 이는 시청자가 '진짜 시스템 내부를 엿보고 있다'는 착각을 유도합니다.
