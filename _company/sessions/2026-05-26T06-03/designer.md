## 🎯 목표 및 감성 코드
*   **핵심 목표:** 시청자에게 '지금 뭔가 잘못되고 있다'는 지적인 불안감(Intellectual Unease)을 극대화하여, 콘텐츠의 몰입도와 전문성을 동시에 확보한다. [근거: Designer 개인 메모리]
*   **작동 원칙:** API 트리거가 발생함과 동시에 UI가 *완벽하게 작동하는 것이 아니라*, **'오류를 일으키는 과정'을 시각화**하여 불안감을 증폭시킨다. (Failure Simulation) [근거: 자가검증된 지식]
*   **활용 시간:** T+25초, T+36초 (총 10초 간격). 각 경고 발생 시 약 4~5초 동안 화면을 점유한다.

## 🎨 디자인 시스템 브리프 (Visual System Brief)

### 1. 컬러 팔레트
| 요소 | 색상 코드 | 역할 및 적용 원칙 | [근거: 자가검증된 지식] |
| :--- | :--- | :--- | :--- |
| **Background** | `#0A0A0A` (Deep Black) | 기본 배경. 정보의 깊이와 위협감을 조성한다. | `[근거: Designer 검증된 지식]` |
| **Primary Text** | `#CCCCCC` ~ `#AAAAAA` (Low Saturation Gray) | 일반 데이터, 설명 텍스트. 눈에 피로를 주지 않으면서도 정보 전달의 안정성을 확보한다. | `[근거: 자가검증된 지식]` |
| **Accent Color** | `#00FFFF` (Neon Cyan) | *오류 메시지*, 경고 타이틀, 활성화되는 데이터 스트림에만 사용. 빛을 발하는 느낌(Glow Effect) 필수. [근거: Designer 검증된 지식] | `[근거: 자가검증된 지식]` |
| **Danger Color** | `#FF4444` (Soft Red/Orange) | 가장 심각한 오류 발생 시 임시 사용. 네온 시안과 대비되어 긴장감을 최고조로 끌어올린다. | `[근거: Designer 개인 메모리 - 시스템적 위기]` |

### 2. 타이포그래피
*   **메인 폰트:** `Orbitron` 또는 `Rajdhani` 계열 (High Contrast Sans-serif). [근거: 자가검증된 지식]
*   **스타일 적용:** 모든 텍스트는 미묘한 **글리치(Glitch) 노이즈 필터**와 함께 스캔라인(Scanline) 효과를 기본적으로 탑재한다.
    *   *(애니메이션 시)* 글자가 깜빡거리거나, 수평/수직으로 잠시 이탈하는(Pixel Shift) 애니메이션을 반드시 포함해야 한다. [근거: 자가검증된 지식]

### 3. 레이아웃 구조 (The Mockup)
경고 UI는 화면 중앙에 **'시스템 콘솔 창'** 형태의 오버레이 박스로 구현된다. 전체적인 비율은 가로 폭 대비 세로 길이가 길어 몰입감을 높인다.

*   **A. 상단 헤더:** `[SYSTEM ALERT // PROTOCOL VIOLATION]` (Neon Cyan, Glitch 효과)
*   **B. 핵심 경고 메시지:** 가장 큰 폰트 크기로 배치되는 오류 타이틀. 예: **`CORE FUNCTION FAILURE DETECTED.`** (글리치 필터 + 깜빡임 애니메이션).
*   **C. 데이터 로깅 영역:** 시간 코드, API 호출 로그 형태로 하단에 스크롤되며 출력된다.
    *   `[T+25s] :: ERROR_CODE: 403 | Source: MetadataStream | Status: DEGRADED` (Neon Cyan/Gray)

## 🎬 애니메이션 상세 명세서 (Animation Spec Sheet) - T+25s & T+36s
**(Total Duration: ~4.5 seconds per trigger)**

### Step 1: 진입 및 긴장 고조 (T+0.0s ~ T+1.0s)
1.  **시각 효과:** 화면 전체가 짧은 순간(0.1초) 동안 **짙은 노이즈와 블랙 아웃**을 경험한다.
2.  **UI 애니메이션:** 콘솔 창 오버레이가 마치 *데이터 스트림처럼* 가장자리부터 빠르게 펼쳐지듯 등장한다. 배경에 미세한 깜빡임(Flicker) 효과를 부여하여 불안감을 조성한다.
3.  **오디오 동기화 (Luna SFX):** 저주파수의 **웅장하고 지속적인 험 노이즈(Deep Hum)**가 시작되며, 이와 동시에 UI 등장 속도가 빨라진다.

### Step 2: 핵심 경고 발현 및 불안감 증폭 (T+1.0s ~ T+3.0s)
1.  **UI 애니메이션:** 상단 헤더와 핵심 메시지(B)가 **'오류 메시지 폭발'** 방식으로 나타난다. 글자가 한 번에 팝업되는 것이 아니라, 마치 *데이터 패킷이 오작동하며 전송*되는 것처럼 분절적으로 출현한다.
2.  **글리치 로직 실행:** 핵심 경고 메시지 전체에 **패턴화된 글리치(Patterned Glitch)**를 적용한다. (예: 3프레임 간격으로 색상이 옆으로 밀리고, 수평선이 순간적으로 번쩍이는 효과). [근거: Designer 개인 메모리]
3.  **데이터 로깅:** 콘솔 창 하단에 API 호출 실패 로그가 **빠르게 스크롤되며(Fast Scroll)** 쏟아진다. (스크롤 속도 = 불안감의 증폭 정도)

### Step 3: 임계점 도달 및 공백 유도 (T+3.0s ~ T+4.5s)
1.  **UI 애니메이션:** 모든 움직임이 갑자기 **급격하게 느려지며(Deceleration)**, 화면 중앙의 핵심 경고 메시지가 가장 밝은 Neon Cyan으로 빛나면서 멈춘다. (정적이지만 강렬한 시각적 충격).
2.  **오디오 동기화:** Deep Hum 노이즈가 갑자기 **급격히 끊어지거나(Cut-off)**, 대신 짧고 날카로운 디지털 스파이크 사운드(`[BEEP!]`)와 함께 공백이 생긴다. (Luna SFX 활용)
3.  **전환 준비:** 화면 전체에 미세한 노이즈가 남으며 경고 UI가 서서히(Fade Out) 사라지고, 다음 콘텐츠 섹션으로 자연스럽게 전환된다.
