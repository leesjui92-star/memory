## ⚙️ I. 모듈형 컴포넌트 라이브러리 (The Modules)

### A. T+10s: [프로토콜 위반 경고] - '정보의 불일치성' 강조
*   **목표:** 시청자가 스크립트 내용에 대한 첫 번째 의문을 갖게 하는 지점. 전문 용어/데이터의 미묘한 오류를 인지시킴.
*   **비주얼 형태:** 화면 구석에서 팝업 되는 '시스템 경고 (System Alert)' 메시지와 함께 데이터가 무작위로 깜빡이는 글리치 효과.
*   **애니메이션 사양:**
    *   **Start Time/Duration:** T+10s Start / 1.5초 지속.
    *   **글리치 로직:** 네온 시안(`#00FFFF`)으로 "ERROR: Data Stream Mismatch Detected" 또는 "PROTOCOL VIOLATION (Metadata Check)" 등의 문구를 출력. 글자 단위로 짧고 날카로운 노이즈 플래시(Glitch Flash)를 발생시킨다.
    *   **사운드 동기화:** 미세한 고주파수 '지지직' 사운드와 함께 낮은 주파수의 `Sub-Bass Boom`을 0.1초 간격으로 배치하여 물리적 불안감을 조성한다.
*   **활용 지침:** 복잡하고 전문적인 용어(예: Protocol, Metadata)를 언급하는 바로 직후에 사용하며, 시청자의 주의가 '화면의 오류'로 분산되게 한다.

### B. T+25s: [지식 공백 유발] - '진단 필요성' 극대화 (The Core KPI Point)
*   **목표:** 시청자가 자신이 모르는 정보(Knowledge Gap)를 자각하고, 외부 전문가의 진단을 갈망하도록 만드는 최고 강도의 경고. 이 구간에서 이탈률을 측정해야 함.
*   **비주얼 형태:** 화면 전체를 덮는 'Critical Failure' 스타일의 전면 경고창 (Overlay). 시야가 급격히 좁아지는 듯한 왜곡 효과(Distortion/Tunnel Vision) 필수.
*   **애니메이션 사양:**
    *   **Start Time/Duration:** T+25s Start / 최소 4초 이상 유지 권장.
    *   **글리치 로직:** `#FF0000` (Warning Red, 제한적 사용)과 Neon Cyan을 혼합 사용하여 "SYSTEM OVERLOAD" 또는 "**전문 진단이 필요합니다.** [Manual Override Required]"와 같은 경고 문구를 반복적으로 깜빡이게 한다.
    *   **시각적 앵커:** 화면 중앙에 마치 '진단 코드'처럼 보이는 네온 시안의 추상적인 데이터 스트림을 지속적으로 움직여, 시청자의 눈이 특정 지점에 머무르도록 강제한다. (This is the KPI Anchor Point).
    *   **사운드 동기화:** 경고음(Alarm Tone)의 주파수가 점진적으로 올라가며 긴장감을 최고조로 만든 후, 갑자기 뚝 끊어지게 하여 공백을 만들고 다음 CTA를 준비한다.

### C. T+36s: [CTA 전환] - '구매 유도' 클라이맥스
*   **목표:** 불안감이 정점에 달한 직후(T+25s 경고가 끝난 후)의 틈새 시간을 활용하여, 해결책을 제시하고 다음 행동을 강제한다.
*   **비주얼 형태:** '접근 가능한 솔루션'처럼 보이는 하이테크 UI 패널 형태의 Call-To-Action (CTA) 컴포넌트.
*   **애니메이션 사양:**
    *   **Start Time/Duration:** T+36s Start / 5초 이상 노출 유지.
    *   **글리치 로직:** CTA 버튼 주변에 Neon Cyan의 미세한 '전기적 스파크' 효과를 부여하여, 이것이 단순한 광고가 아닌 *필수적인 기술적 인터페이스*처럼 보이게 한다.
    *   **텍스트 구성:** "진단 결과 확인하기 (Click for Analysis)" 또는 "전문 컨설팅 요청 [CODE: JROCK-X]" 등의 전문성을 강조하는 문구를 사용한다.
