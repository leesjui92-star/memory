## 🚨 CTA 클라이맥스 시스템 경고 UI 디자인 브리프 (Master Kit V2.0 확장)

**섹션명:** PROTOCOL\_FAIL: CRITICAL DATA INCONSISTENCY
**예상 시간 구간:** T+0:25 ~ T+0:38 (총 13초)
**주요 목표:** 시청자에게 '현재 자신이 가진 정보로는 부족하다'는 지적 불안감을 극대화하고, 즉각적인 다음 단계(Mini-LP 접속/보고서 다운로드)를 강제한다.

### 🎬 II. 모션 그래프 및 애니메이션 타이밍 (Time Code Based)

#### **[Phase 1: The Trigger & System Shock] (T+0:25 ~ T+0:29)**
*   **목표:** 영상의 흐름을 강제로 끊고, '뭔가 잘못되었다'는 물리적/정보적 충격을 준다.
*   **시각 연출:** 갑작스러운 화면 깜빡임(Flicker) 및 글리치 스파이크.
*   **오디오 연출:** 고주파수 노이즈 폭발음 (High-frequency Noise Spike), 시스템 알람 사운드 (Deep Siren).

| Time Code | 시각 요소 | 텍스트 내용 | 애니메이션/효과 | 색상 로직 |
| :--- | :--- | :--- | :--- | :--- |
| **T+0:25** | 화면 전체 | *(빈 공간)* | Deep Red 플래시 (1프레임). 노이즈 필터 강하게 적용. | 배경 깜빡임 (`#FF3333`) |
| **T+0:26~0:29** | 경고창 패널 등장 | `[PROTOCOL ERROR]: DATA INCONSISTENCY DETECTED` | 텍스트가 글리치 효과와 함께 빠르게 스캔라인으로 출력됨. 좌우로 미세하게 떨림(Jitter). | Cyan (Cyan) + Red (경계선/점멸) |
| **핵심 액션** | 중앙 하단에 작은 빨간색 점멸 사각형 3개가 순차적으로 깜빡인다. | *(텍스트 없음)* | 시청자의 시선을 자연스럽게 아래 CTA 영역으로 유도하는 리듬감 있는 빛의 연출. | Red (`#FF3333`) |

#### **[Phase 2: The Gap & Information Authority] (T+0:30 ~ T+0:34)**
*   **목표:** 시청자가 스스로 '정보적 결핍'을 자각하게 한다. 해결책은 오직 우리가 가지고 있음을 암시한다.
*   **시각 연출:** 전문적인 데이터 분석 화면처럼 보이게 구성 (HUD, Graph).
*   **오디오 연출:** 낮은 톤의 백그라운드 진동음(Sub-bass Hum), 기계가 정보를 처리하는 듯한 '틱' 사운드 반복.

| :--- | :--- | :--- | :--- | :--- |
| **T+0:30~0:32** | 데이터 플로우 패널 (좌측) | `ANALYSIS COMPLETE. GAP IDENTIFIED:` | Cyan 네온 라인이 복잡하게 흐르며, 분석 과정처럼 보임. 마치 데이터를 긁어내는 듯한 효과. | Cyan (`#00FFFF`) |
| **T+0:32~0:34** | 중앙 메인 메시지 (가장 크게) | `YOUR CURRENT DATASET IS INCOMPLETE.` | 매우 크고 강렬하게 글리치하며 나타난다. 폰트 자간이 순간적으로 넓어졌다 좁아지는 효과(Stretching). | Cyan + Red 하이라이트 |

#### **[Phase 3: The Command & Climax CTA] (T+0:35 ~ T+0:38)**
*   **목표:** 행동을 명령하고, 가장 강렬한 클라이맥스 경험을 제공한다.
*   **시각 연출:** '접근 권한 필요'라는 느낌의 인터페이스와 버튼 강조.
*   **오디오 연출:** 웅장하고 긴박한 사운드 스윕(Sound Sweep) 후, 날카로운 시스템 완료/경고음 (Ping!).
