## 1. 전역 시스템 로직 가이드라인 (Global Logic Constraints)
*   **Primary State Transition Trigger:** 시간 코드(`T+HH:MM:SS`)만을 사용한다. 모든 변화는 이 코드를 기준으로 발생해야 한다. [근거: Designer 산출물]
*   **Failure Mode Protocol:** 콘텐츠 내에서 '결함/오류'가 언급될 때, 반드시 빨간색 경고(Warning VFX)를 사용하여 시각적 불안감을 극대화한다. (VFX-Error Code Layer 필수). [근거: 세션 로그]
*   **Success Mode Protocol:** 해결책이나 CTA 제시 순간에는 Neon Cyan (`#00FFFF`)을 사용하며, 강렬한 대비와 함께 안정감 및 권위를 부여한다. [근거: 세션 로그]
