**수신자:** Editor

## 1. 공통 환경 설정 (Global Parameters)

| 항목 | 사양 값 | 비고/설명 |
| :--- | :--- | :--- |
| **캔버스 해상도** | 1920 x 1080 px (Full HD) | 영상 전체 프레임과 일치. 오버레이 요소는 중앙 70% 영역에 집중 배치. |
| **작업 색 공간** | sRGB / YUV (Broadcast Standard) | 모든 색상은 방송 표준을 따르되, Neon Cyan은 디지털 발광 효과를 가정. |
| **기본 배경색** | `#0A0A0A` (Deep Black) | 영상이 어두울 때의 기본 오버레이 배경으로 사용. 전체 레이어에 투명도(Opacity) 적용 필수. |
| **핵심 강조색 (Accent)** | `#00FFFF` (Neon Cyan) | 모든 경고, 데이터 스트림, 활성화된 UI 요소에 제한적으로만 사용. 발광 효과(`Glow Effect`)를 반드시 추가하여 대비 극대화. |
| **타이포그래피** | `Orbitron` 또는 유사 기하학적 Sans-serif (Bold/Medium) | 텍스트가 '디지털 데이터'처럼 보이도록 글리치 필터 및 스캔라인 효과 적용 필수. |

## 2. T+36초 진단 UI 컴포넌트 상세 사양 (Diagnostic UI Module)

이 모듈은 시청자가 스스로 문제를 의심하게 만드는 **강제적인 경고와 결핍**을 유도하는 핵심 전환점입니다.

### A. Diagnostic Alert Bar (경고 배너)
*   **위치:** 영상 화면 하단 약 15% 영역에 걸쳐 중앙 배치.
*   **크기:** 1920 x 60 px.
*   **배경 애니메이션:**
    *   **(Start)**: `[T+36s - 0ms]`에서 `#4A0000` (Dark Crimson) 색상의 짧은 깜빡임(Flicker)으로 시작. Opacity를 10%에서 90%까지 급상승/하강시키는 키프레임 적용.
    *   **(Sustain)**: `[T+36s + 50ms]`부터 `#AA0000` (Deep Red) 계열로 유지. 이 색상은 경고의 지속성을 나타냄.
*   **핵심 요소 (Neon Cyan):** 배너 중앙에 'CRITICAL SYSTEM FAILURE' 등의 문구와 함께 Neon Cyan (`#00FFFF`)으로 **깜빡이는 점멸 효과(Blinking Dot)**를 반복 적용합니다.
    *   *애니메이션:* Opacity 20% $\rightarrow$ 100% $\rightarrow$ 20%. 주기는 150ms.

### B. Data Inconsistency Widget (데이터 불일치 위젯)
*   **위치:** 화면 좌측 상단 또는 우측 하단의 '코너' 영역에 작게 배치.
*   **목적:** 영상 속 데이터가 잘못 측정되었거나, 외부 시스템의 개입이 필요함을 시각적으로 암시.
*   **구현 방법:** 3개의 작은 박스형 그래프 (Placeholder Graph)를 만듭니다. 각 그래프는 실시간으로 **노이즈(Noise)**와 함께 수치를 오르내리며 불안정하게 보이게 합니다.
    *   *키프레임:* Y축 좌표 값에 `Random Oscillation` 효과를 적용하고, 전체적인 노이즈 필터 강도를 30%로 설정합니다.
    *   *하이라이트:* 가장 수치가 '이상 범위'에 있는 지점의 그래프 선만 Neon Cyan으로 빛나게 처리합니다.

## 3. 전반적 시각 효과 기술 사양 (Global Visual FX Protocol)

| 효과 | 적용 대상 | 애니메이션 키프레임/기술 지침 | 색상/강도 가이드 |
| :--- | :--- | :--- | :--- |
| **글리치 (Glitch)** | 모든 텍스트, 데이터 플로우 다이어그램. | **1단계:** 시간 축(Time Axis) 기준으로 갑작스러운 수평 또는 수직 이동 및 왜곡 (`[Keyframe]` 활용). <br>**2단계:** 짧은 순간 동안 색상 채널 분리(RGB Channel Separation) 효과 적용. | 딥 블랙 배경에 Cyan/Magenta 계열의 번개 같은 빛을 추가하여 디지털 오류 느낌 극대화. |
| **스캔라인 (Scanline)** | 영상 전체 프레임 또는 주요 정보 오버레이 영역. | 주기적인 반투명 가로줄 패턴(Horizontal Stripes)을 낮은 Opacity (5-10%)로 배경에 깔아 아날로그/시스템 녹화 느낌 부여. | 색상: 매우 어두운 회색 (`#111111`). 움직임은 미묘한 패닝 효과 적용. |
| **데이터 스트림 (Data Stream)** | 흐름을 보여주는 선형 요소. | 마치 전기가 흐르거나 데이터가 이동하는 것처럼 보이게 합니다. 단순 직선이 아닌, 빛의 궤적(Light Trail) 느낌으로 구현해야 함. | 색상: Neon Cyan (`#00FFFF`). 발광 효과를 반드시 적용하여 깊이를 부여. |
