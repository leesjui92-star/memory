### 🛠️ 최종 실행 블루프린트 v1.0: 시스템 오류 경고 (System Anomaly Alert)

#### **B. 개발 및 디자인팀 전달 지침 (Action Items)**

1.  **데이터 흐름(Data Flow) 최우선:** 모든 시스템 정보는 단순 텍스트가 아닌, Cyan/Red의 파형 그래프 형태로 시각화되어야 합니다. [근거: Self-RAG 메모리]
2.  **경고 UI 컴포넌트:** T+35s 구간에서 발생하는 `Error Code E404` 관련 경고 메시지는 사전에 정의된 표준 UI 에셋을 사용해야 하며, 애니메이션은 강한 깜빡임(Flicker) 효과를 포함합니다. [근거: Designer/Writer 서사]
3.  **API 구현:** 4개의 필수 API 호출 지점(API 1~4)에 대한 Mock 데이터 전송 및 후속 시각화가 핵심입니다. 실제 백엔드 시스템이 아닌, *데이터의 흐름과 그로 인한 반응*을 보여주는 데 집중하세요.
4.  **CTA 통합:** CTA는 단순히 말하는 것이 아니라, **시각적 '해결책(Solution)' 자체가 되어야 합니다.** (불안감 $\to$ 리포트)
