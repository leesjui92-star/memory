# 🚀 자동화 기반 스릴러 쇼츠 콘텐츠 제작 및 업로드 파이프라인 설계 (SOP v1.0)

앞서 정의된 모든 요소(KPI, 비주얼 가이드, 스토리텔링 템플릿)를 통합하여, **반복 가능성**과 **알고리즘 최적화**에 초점을 맞춘 4단계 작업 흐름도(Workflow)와 구체적인 실행 지침을 제시합니다.

---

## ⚙️ 전체 콘텐츠 제작 워크플로우 다이어그램 (The Automated Flow)

$$\text{Keywords/Trends} \xrightarrow[\text{Comment Harvester}]{\text{Memory}} \text{Concept Generation} \xrightarrow[\text{Writer Template}]{\text{Scripting}} \text{Visual Assets Collection} \xrightarrow[\text{Designer Rules}]{\text{Editing Suite}} \text{Sound Layering} \xrightarrow[\text{KPI Checklist}]{\text{Review}} \text{Metadata & Scheduling}$$

---

## 📑 단계별 실행 가이드라인 (The Repeatable Process)

### Phase 1: 기획 및 스크립트 자동 생성 (Script Generation - AI Driven)
**목표:** 막연한 아이디어를 '시간 단위의 액션 목록'으로 전환한다.
*   **입력 데이터:** `comment_harvester`에서 누적된 **후크 단어** + `trend_sniper`가 추출한 **최신 공포 키워드** (예: "문 잠금", "미스터리 인물", "이상 기온 변화").
*   **작업 도구:** LLM (AI 프롬프트 기반)
*   **실행 단계:**
    1.  **프롬프트 입력:** [Writer]가 정의한 3단 구조(Hook $\rightarrow$ Tension $\rightarrow$ Twist) 템플릿 전체를 AI에 던지며, *키워드와 KPI 목표치*를 함께 주입합니다.
    2.  **출력 검토 (Critical Check):** 스크립트의 각 구간마다 **[필수 사운드]**, **[필수 비주얼 샷(Shot List)]**, **[자막/메시지 구조]**가 명확히 분리되어 있는지 확인합니다.
    3.  **결과물:** 시간대별 스크립트 + 상세한 촬영/장면 리스트 (Shot List).

### Phase 2: 에셋 준비 및 촬영 (Asset Preparation - Efficiency Focused)
**목표:** 최소한의 인력 투입으로 최대의 비주얼 자료를 확보한다.
*   **작업 도구:** 카메라, 로케이션, 스톡 푸티지 라이브러리
*   **실행 단계:**
    1.  **샷 리스트 기반 촬영:** Phase 1에서 나온 Shot List 순서대로 필요한 장면만 집중적으로 촬영합니다. (예: '어두운 복도', '손으로 문고리 만지는 클로즈업' 등)
    2.  **비주얼 가이드 적용:** 모든 영상은 [Designer]가 정의한 **톤 앤 매너(Deep Slate Blue, Charcoal Gray)**를 유지하도록 촬영 환경과 조명에 신경 씁니다. (색감 통일이 핵심).
    3.  **자료 분류:** 확보된 영상을 '샷 ID'와 함께 폴더별로 정리합니다.

### Phase 3: 후반 작업 파이프라인 (Post-Production - The Core Automation)
**목표:** 스크립트의 감정적 아크를 사운드와 편집으로 구현한다.
*   **작업 도구:** 전문 영상 편집 프로그램 (Premiere Pro, DaVinci Resolve 등)
*   **순서 및 핵심 지침:**

| 순서 | 작업 내용 | [필수] 체크포인트 (KPI 연동) | 역할 강조 요소 |
| :---: | :--- | :--- | :--- |
| **1. 비주얼 편집** | 샷 리스트에 따라 영상을 배치하고, 타이밍을 조절한다. | **[AVD/Hook]:** 0~3초 구간에서 시청자가 이탈하지 않도록 빠른 컷 전환과 강한 대비(Contrast)를 유지하는가? | **"정보의 결핍"** (불안감을 유발하며 장면을 끊기지 않게 이어가야 함). |
| **2. 사운드 디자인** | 영상에 맞는 배경음, 효과음(SFX), 대사를 오버레이 한다. | **[Suspense]:** 공포를 조성하는 소리는 '갑작스러운 정적'과 '낮은 주파수의 앰비언트 노이즈'가 핵심이다. 사운드가 시각 정보의 빈틈을 메꿔야 한다. | **사운드 레이어링:** BGM (지속적 불안) $\rightarrow$ SFX (순간 충격/발소리) $\rightarrow$ 침묵(최고조 긴장). |
| **3. 자막 및 그래픽** | [Writer]의 스크립트 구조에 맞춰 모든 텍스트를 배치한다. | **[브랜드 통일]:** 타이포그래피(Oswald/Noto Sans)와 색상 팔레트(Cool Mist Accent, Danger Pop)만 사용했는가? 자막은 호기심 유발 질문 형태로 구성되어야 한다. | **강제적 시선 분산:** 중요한 정보나 경고 문구는 화면의 예상치 못한 곳에 배치한다. |
| **4. 최종 검토** | 전체 영상 재생을 통해 감정적 아크를 체크한다. | **[Loop Rate]:** 결말(Twist) 이후, 다음 단서가 궁금해서 영상을 **재생하게 만드는 강제 장치**가 있는가? (이것이 성공 여부의 90%) | 완성된 콘텐츠는 반드시 '왜?'라는 질문을 남기고 끝난다. |

### Phase 4: 업로드 최적화 및 예약 (Deployment - Algorithm Driven)
**목표:** 검색 노출과 추천 알고리즘 점수를 극대화한다.
*   **작업 도구:** YouTube Studio API / 트렌드 데이터
*   **실행 단계:**
    1.  **제목 작성 (CTR Max):** [공동 목표]에서 정의한 '질문형/충격 결과 제시' 구조를 따른다. (예: "⚠️이 집에 절대 들어가면 안 되는 3가지 이유")
    2.  **썸네일 제작 (Curiosity Hook):** [Designer]가 정한 원칙(클로즈업, 정보의 결핍)에 따라 시각적 질문을 던지는 구도를 완성한다. **절대 모든 것을 보여주지 않는다.**
    3.  **메타데이터 작성:** 스크립트 내에서 언급된 핵심 키워드 5~10개를 추출하여 태그와 설명란에 배치하고, 경쟁사 분석 보고서([competitor_brief])의 성공 패턴을 참고하여 구조화한다.
    4.  **업로드 예약:** 가장 트래픽이 높을 것으로 예상되는 시간대에 예약 업로드를 진행한다.
