# 🚀 JRock 콘텐츠 파이프라인 재가동 통합 검증 체크리스트 (v1.0)
**목표:** 안정화된 데이터를 바탕으로, 고신뢰도/고임팩트 콘텐츠를 오류 없이 제작한다.

## 📋 단계 1: 데이터 수집 및 원시 데이터 검증 (Data Acquisition & Raw Validation)
데이터의 신뢰도를 확보하는 가장 중요한 첫 단계입니다.
*   **필요 도구:** `trend_sniper.py` 등 모든 외부 API 호출 모듈
*   **주 담당 에이전트:** 💻 코다리 (개발/엔지니어링)

| 검증 항목 | 최소 요구 사항 (Minimum Requirement) | 확인 여부 | 비고/담당 서명 |
| :--- | :--- | :--- | :--- |
| **① 데이터 무결성** | 모든 필수 필드(Key Data Point)가 누락 없이 수집되었는지? | [ ] 완료 | 코다리 (Dev) |
| **② 시간 표준 통일** | 모든 시계열 데이터가 UTC 표준을 따르며, 지역 시간대 오차가 없는지? | [ ] 완료 | 코다리/Researcher |
| **③ Rate Limit 대응** | 외부 API 호출 실패 시, 재시도 로직(Exponential Backoff)이 정상 작동했는지? | [ ] 완료 | 코다리 (Dev) |
| **④ 데이터 출처 명확화** | 모든 주요 통계 수치에 대한 공신력 있는 원본 출처 링크/문서가 첨부되었는지? | [ ] 완료 | Researcher |

## 📐 단계 2: 구조화 및 스키마 변환 (Structuring & JSON Schema Mapping)
원시 데이터를 콘텐츠 기획자가 바로 사용할 수 있는 논리적 구조로 변환합니다.
*   **필요 도구:** 데이터 매핑 로직, `data_mapper.py` (가칭)
*   **주 담당 에이전트:** 💡 Researcher (정보 분석/자료 정리)

| 검증 항목 | 최소 요구 사항 (Minimum Requirement) | 확인 여부 | 비고/담당 서명 |
| :--- | :--- | :--- | :--- |
| **① 스키마 적합성** | 수집된 데이터가 정의된 JSON Schema에 100% 매핑되었는지? | [ ] 완료 | Researcher (Data) |
| **② 논리적 관계 설정** | 데이터 간의 인과관계(Cause & Effect) 또는 대비점(Contrast Point)이 명확히 추출되었는지? | [ ] 완료 | Researcher (Analyst) |
| **③ 가설 검증 반영** | 데이터를 통해 도출된 '주요 불안감/리스크'에 대한 근거가 충분한지? | [ ] 완료 | Researcher (Lead) |

## 📝 단계 3: 콘텐츠 초안 및 최종 아웃풋 준비 (Content Draft & Final Spec Sheet Generation)
구조화된 스펙을 바탕으로, 영상 제작에 바로 투입할 수 있는 완성도 높은 결과물을 만듭니다.
*   **필요 도구:** Writer의 Prompting Engine, Designer의 Visual Blueprint Kit
*   **주 담당 에이전트:** ✍️ Writer (스크립트 전문), 🎨 Designer (비주얼/UX)

| 검증 항목 | 최소 요구 사항 (Minimum Requirement) | 확인 여부 | 비고/담당 서명 |
| :--- | :--- | :--- | :--- |
| **① Narrative Flow** | 도입(Hook) $\rightarrow$ 불안감 증폭 $\rightarrow$ 해결책 제시(CTA)의 3단계 구조가 명확한지? | [ ] 완료 | Writer (Script) |
| **② Tone & Consistency** | '테크 느와르' 및 '시스템 경고'라는 브랜드 톤이 전체 스크립트에 일관되게 반영되었는지? | [ ] 완료 | Writer/Editor |
