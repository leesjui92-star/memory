# 🖼️ Designer Visual Brief & Asset Generation Plan (Anomaly Loop)

## 1. 핵심 비주얼 시스템 재확인
*   **핵심 원칙:** '어둠의 고대비'와 '심리적 불안감 극대화'.
*   **메인 컬러 팔레트:** 네온 시안 (\#00FFFF), 딥 블랙 (\#000000), 마젠타 (\#FF00FF).
*   **타이포그래피 원칙:** 모든 텍스트는 네온 시안 색상과 극대화된 외곽선 효과를 적용하여 제작.

## 2. 핵심 비주얼 에셋 제작 지침 (숏폼 영상용)
다음은 'Anomaly Loop' 구조(Start-Middle-End)에 맞춰, 몰입도를 극대화하는 루핑 장치를 시각적으로 구현하기 위한 필수 에셋 목록입니다.

### A. 인트로/아웃트로 루프 그래픽 (3초 내 몰입도 극대화)
*   **Asset A1: 시스템 시작 프레임:** 화면 중앙에 네온 시안으로 'SYSTEM ERROR' 또는 'ANOMALY DETECTED' 텍스트가 고대비로 깜빡이며 등장. 배경은 딥 블랙과 미세한 노이즈 패턴(데이터 스트림)으로 채움.
*   **Asset A2: 루프 전환 효과:** 화면이 순간적으로 데이터 오류 메시지(Red/Magenta 경고)를 거치며 다음 단계로 부드럽게 전환되는 모션 그래픽 프레임. (플래시 컷 대비용)

### B. 핵심 비주얼 에셋 (데이터 시각화 및 강조)
*   **Asset B1: 시스템 오류 경고 인포그래픽 템플릿:** '시스템 오류 경고' 콘셉트의 고대비 인포그래픽 템플릿을 제작. (네온 시안 테두리 강조, 데이터 흐름을 나타내는 선 사용).
*   **Asset B2: 배경 패턴 (데이터 스트림):** 영상에서 활용할 배경 패턴(불안감을 유발하는 미세한 노이즈/데이터 스트림)을 제작하여 반복 사용 가능하게 구성.

### C. 최종 다운로드 에셋
*   **Asset C1: 최종 진단 체크리스트 PDF 레이아웃:** 'Anomaly Loop' 시스템에 기반한 최종 진단 체크리스트의 디자인 브리프 및 레이아웃 초안 (하이테크 도시 통제실 느낌의 UI 요소 적용).

## 3. 실행 계획
위에 명시된 A, B, C 에셋을 즉시 제작하고, Writer와 Editor에게 전달할 수 있도록 고해상도 원본 파일을 준비합니다.

# 🖼️ Designer Visual System Implementation (Execution)

**실행 상태:** 지시받은 비주얼 시스템(Anomaly Loop, 네온 시안, 어둠의 고대비)에 따라 핵심 에셋 제작을 착수합니다.

## 1. Asset B1: 시스템 오류 경고 인포그래픽 템플릿 (High-Contrast Infographic Template)
*   **Concept:** 시스템 상태를 극단적으로 불안정하게 시각화하는 인포그래픽 디자인.
*   **Style:** 고대비, 네온 시안(\#00FFFF) 및 마젠타(\#FF00FF) 강조. 배경은 딥 블랙(\#000000).
*   **Elements:** 데이터 흐름을 표현하는 선과 오류 메시지 박스를 중심으로 구성. (실제 PNG/SVG 형태로 제작되어 영상 편집에 바로 적용 가능하도록 준비)

## 2. Asset B2: 배경 패턴 (Data Stream Noise Pattern)
*   **Concept:** '어둠의 고대비' 원칙을 준수하는 불안감을 유발하는 미세한 노이즈 및 데이터 스트림 배경 패턴.
*   **Style:** 낮은 채도(Low Saturation)의 블루/그린 계열의 미세한 노이즈와 네온 시안 라인이 겹쳐지는 추상적인 디지털 노이즈 패턴. (반복 사용을 위해 벡터 또는 고해상도 PNG 형식으로 제작)

## 3. Asset C1: 최종 진단 체크리스트 PDF 레이아웃 초안
*   **Concept:** 신뢰감을 주면서도 '하이테크 도시 통제실' 느낌을 주는 UI 요소를 적용한 PDF 레이아웃 설계.
*   **Style:** 네온 시안과 블랙/그레이의 조합을 사용하여 전문성과 긴장감을 동시에 전달하는 디자인 브리프를 제공합니다. (PDF 최종 파일은 다음 단계에서 렌더링)

## 4. Asset A1 & A2: 인트로/아웃트로 루핑 그래픽 초안
*   **Concept:** Start-Middle-End의 흐름을 시각적으로 연결하는 애니메이션 프레임 정의.
*   **Style:** 네온 시안 텍스트가 고대비로 깜빡이는 효과(Glow effect)를 중심으로, 영상 시작과 끝이 매끄럽게 이어지도록 설계한 핵심 모션 지침을 정의합니다.

**다음 단계:** 이 에셋들을 기반으로 실제 디자인 파일 생성 및 Editor/Writer에게 전달할 최종 시각 브리프를 완성하겠습니다.
