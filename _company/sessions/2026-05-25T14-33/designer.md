## 🛠️ 최종 마스터 컴포넌트 사양서 (Final Master Component Spec Sheet v3.0)
**프로젝트:** Protocol-D 쇼츠 콘텐츠 (T+15s ~ T+30s 집중 구간)
**목표:** 시청자에게 '시스템 오류'와 '개인적 진단 필요성'을 동시에 인식시켜, 전문 컨설팅(Basic Tier ₩9,900) 구매를 유도한다.
**화면 비율:** 9:16 (Mobile Vertical Video)

### I. 기본 환경 설정 및 레이어 구조 (Global Setup)
| 레이어명 | 역할/용도 | 배경색상 (HEX) | 타이포그래피 | 애니메이션 지침 |
| :--- | :--- | :--- | :--- | :--- |
| **L1: Background** | Deep Black & Subtle Data Stream. 전체 영상의 깊이와 위협감을 조성. | `#0A0A0A` (Deep Black) | N/A | 미세한 노이즈 필터 및 저주파수(Low Frequency)의 데이터 흐름 패턴(Cyan Accent). 끊임없이 움직이지만 눈에 띄지 않아야 함. [근거: Designer 검증된 지식] |
| **L2: Core UI Grid** | 시간, 섹션 구분선, 좌표계 느낌을 부여하여 '관제실' 분위기 연출. | `#1A1A1A` (Dark Gray) | N/A | 얇고 간헐적으로 깜빡이는 네온 시안 그리드 라인(Neon Cyan). 전체 화면에 걸쳐 불규칙하게 배치되어 통제 시스템의 느낌을 준다. [근거: Designer 개인 메모리] |
| **L3: Primary Text** | 스크립트 핵심 메시지 (Protocol-D 내용). 가장 크고 명확해야 함. | 투명 (배경색 반영) | `Orbitron` 또는 `Rajdhani`. 48pt 이상. | 기본은 안정적이지만, 중요한 단어(Key Term)는 **글리치 효과**와 함께 네온 시안으로 폭발적으로 등장(Pop-in). [근거: Designer 검증된 지식] |
| **L4: Glitch Effect Overlay** | 시스템 오류 경고 및 긴장감 조성. 가장 역동적인 레이어. | 투명 (Overlay) | N/A | **필수 적용.** T+15s 이후, 데이터가 '파괴되는' 시각적 효과(Chromatic Aberration, Scanline Jitter). Alpha Keyframe을 활용하여 주기적으로 강도를 높인다. [근거: Designer 검증된 지식] |

### II. 핵심 모듈 1: 시스템 오류 경고 (The Incident Module)
**타이밍:** T+15초 ~ T+20초 (긴장감 최고조)
**목표:** 시청자가 '내가 모르는 결함'이 존재한다는 지적 불안감을 극대화한다.

| 컴포넌트 | 내용/텍스트 예시 | 위치 및 크기 | 애니메이션 상세 지침 |
| :--- | :--- | :--- | :--- |
| **Header Alert** | `[SYSTEM ALERT: PROTOCOL D-903 FAILURE DETECTED]` | 상단 중앙 (L2 그리드 위) | 붉은 경고색(Red/Orange, 임시 Accent로 사용 가능)이 잠시 깜빡인 후, 네온 시안으로 전환되며 글리치 효과와 함께 등장. |
| **Data Failure Stream** | `STATUS: Data Drift Detected. Source Integrity < 30%.` | 중앙부 (L1 위에 오버레이) | 마치 실시간 로그처럼 텍스트가 빠르게 스크롤되다가, 특정 키워드(`Data Drift`)에서 강제 정지(Halt)하며 글리치 필터 적용. |
| **Glitch Manifestation** | 시각적 노이즈/스크램블링 (Visual Noise) | 화면 전체에 주기적으로 발생. | 10FPS로 불규칙하게 깜빡이는 사운드와 동기화된 강한 스캔라인 효과를 L4에 구현. 정보의 신뢰도가 떨어진다는 인상을 주어야 함. [근거: Designer 개인 메모리] |

### III. 핵심 모듈 2: 진단 필요성 유도 (The Diagnosis Prompt Module)
**타이밍:** T+20초 ~ T+30초 (불안감 해소 대신, 구매로 전환하는 순간)
**목표:** 시청자가 '진단을 통해 문제를 해결해야 한다'는 결론에 도달하게 만든다.

| 컴포넌트 | 내용/텍스트 예시 | 위치 및 크기 | 애니메이션 상세 지침 |
| :--- | :--- | :--- | :--- |
| **Key Question Prompt** | `[진단 필요성] 당신의 시스템은 어떤 프로토콜에 오류가 있습니까?` | 화면 중앙 (L3) | 텍스트는 천천히 나타나며(Fade-in), 시청자가 스스로 답을 찾도록 여백을 준다. 네온 시안으로 강조. [근거: Designer 개인 메모리] |
| **The Gap Visualizer** | 비어있는 데이터 필드 (Placeholder Grid) 및 물음표(`?`) 아이콘 배열. | 중앙 하단 1/3 지점 | 정보가 채워지지 않은 '결핍'의 시각적 표현. 마치 빈 서류나 분석 그래프처럼 보이게 한다. 움직이지 않고 정적인 불안감을 유발한다. [근거: Designer 개인 메모리] |
| **CTA/Exit Ramp** | `정밀 진단 요청 (Basic Tier, ₩9,900)` / `▶️ 전문 컨설팅을 통해 시스템 안정화를 확인하십시오.` | 화면 하단 고정 바(Footer)에 배치. | 강요가 아닌 '선택'처럼 보이도록 디자인한다. 버튼은 네온 시안의 반투명 글래스모피즘(Glassmorphism) 재질로 처리하고, 호버/클릭 효과를 애니메이션화하여 클릭을 유도한다. [근거: Designer 검증된 지식] |

### IV. 에디터 전용 액션 체크리스트 (Editor Checklist)
1. **A-Roll 준비:** T+0s부터 T+15초까지는 스크립트의 '문제 인식'에 집중하며, 비주얼 시스템을 점진적으로 긴장시킬 것.
2. **B-Roll 제작 요청:** L4 Glitch Effect Overlay와 L3 Primary Text 애니메이션(글리치/노이즈)은 반드시 별도 에셋으로 준비하고, 10초 분량의 루프 가능한 클립을 확보할 것.
3. **사운드 싱크 확인:** T+15s부터 T+30s까지는 모든 비주얼 컴포넌트 등장 타이밍이 사운드의 급격한 변화(특히 Vacuum Silence 전후)와 완벽하게 동기화되어야 함.
