### 4.1. 애니메이션 트리거 원칙 (Animation Trigger Protocol)
| 트리거 유형 | 발생 조건 | 적용 에셋/효과 | 목적 및 효과 |
| :--- | :--- | :--- | :--- |
| **A. 시간 기반 (Time Code)** | 특정 시간 구간 진입 (예: T+01:23~T+01:28) | [SYSTEM_WARNING_POPUP], [DATA_STREAM_OVERLAY] | 서사적 전환점 강조. 시청자에게 다음 정보가 필연적으로 다가옴을 알림. |
| **B. 오디오 기반 (Audio Frequency)** | 배경음악의 주파수 급변 또는 피크 발생 (예: 100Hz <-> 400Hz) | [GLITCH_FILTER], [TITLE_SHAKE] | 긴장감 고조(Tension Build-up). 공포/위협적 분위기를 청각적으로 증폭시켜 시각화. |
| **C. 데이터 기반 (Data Threshold)** | 화면에 제시되는 핵심 수치나 키워드의 임계값 초과 또는 변화 | [ERROR_CODE_FLASH], [API_CONTRACT_FAIL] | 전문성/신뢰도 확보. '데이터가 시스템을 붕괴시키고 있음'을 논리적으로 증명. (가장 중요) |

### 4.2. 에셋 모듈별 동적 로직 정의
모든 에셋은 다음의 매개변수를 포함합니다: `[Trigger Type]`, `[Range/Condition]`, `[Animation Keyframes]`

**1. [SYSTEM_WARNING_POPUP] (경고창)**
*   **Trigger:** 시간 기반 (Time Code) - T+00:30 ~ T+00:45 구간 내 2회 이상 사용 필수.
*   **Condition:** 배경 음향의 볼륨이 갑자기 감소하거나, 낮은 주파수(Sub-bass)가 강조되는 순간.
*   **Animation Keyframes:** `Opacity` (0% -> 100%), `Scale` (95% -> 100%), `Color Shift` (Gray -> Neon Cyan). **필수 요소:** 노이즈/스캔라인 필터(Glitch)가 짧게 깜빡이는 플래시 효과 추가.

**2. [DATA_STREAM_OVERLAY] (데이터 흐름)**
*   **Trigger:** 오디오 기반 (Audio Frequency) - 모든 설명 구간에서 지속적으로 적용.
*   **Condition:** 주파수 대역이 일정하게 유지되는 상태(Steady State).
*   **Animation Keyframes:** 화면 가장자리를 따라 끊임없이 움직이는 미세한 Neon Cyan의 사각형/선형 패턴. 데이터가 '흐르고 있음'을 시각적으로 표현하여 시스템적 생동감 부여.

**3. [GLITCH_FILTER] (글리치 필터)**
*   **Trigger:** 데이터 기반 (Data Threshold) - 핵심 정보(KRS 점수, 전문 용어 등) 공개 직전/직후.
*   **Condition:** 화면 내 텍스트가 고대비로 등장하는 순간.
*   **Animation Keyframes:** RGB 채널 분리(Chromatic Aberration), 짧은 노이즈 스파이크, 수평적 왜곡 효과를 결합. **지속 시간 제어 필수.**
