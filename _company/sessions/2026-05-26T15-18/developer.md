#### 🐛 [오류 및 개선점 명세서]

| 지점 | 발견된 결함 (Issue) | 상세 설명 / 원인 분석 | 요구되는 수정 (Action Item) |
| :--- | :--- | :--- | :--- |
| **T+Xs Deep Boom** | **Sync Drift (시간 동기화 이탈)** | 사운드 자산(Deep Boom, 30Hz Sub-Bass Peak)이 최고조에 달하는 시점보다 API 데이터 호출(`E-DATA-XXX`)의 *시각적 오버레이*가 약 **150ms 지연**되어 발생함. 이는 임팩트의 충격을 현저히 감소시키는 원인입니다. | Mock API 이벤트 트리거를 단순한 시간 코드가 아닌, 특정 사운드 주파수(예: 20Hz 이하 Sub-Bass)의 *Peak 감지*에 종속시켜야 합니다. (Audio Trigger $\rightarrow$ Event). |
| **데이터 처리** | **Schema Mismatch (스키마 불일치)** | API 호출 시 전달되는 핵심 데이터 (`score`: 0.92)가 `float` 타입으로 정상 전송되었으나, 이 값을 받는 UI 컴포넌트(`score_display`)는 이를 **반올림(Rounding)**하여 소수점 첫째 자리만 표시하는 버그를 포함하고 있습니다. | 스코어 바인딩 로직에서 데이터 타입을 `Float`으로 강제하고, 렌더링 시에는 최소 두 자릿수의 정밀도를 유지하도록 수정해야 합니다. (UX/Dev 협업 필요). |
| **전환 구간** | **Buffer Void (버퍼 공백 누락)** | 클라이맥스 직후의 'Vacuum Sound' 이후 다음 장면으로 넘어가는 간격(Transition)에 사운드 및 비주얼 에셋이 0ms로 붙어 버렸습니다. 이는 시청자에게 시스템적 끊김이나 급작스러운 종료 느낌을 줄 수 있습니다. | **최소한의 Transition Buffer (250ms)**를 의도적으로 삽입하고, 이 구간에 짧은 '시스템 전원 차단(Power Down)' 비주얼 효과를 배치하여 다음 구조적 불안감을 암시해야 합니다. |
