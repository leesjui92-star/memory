## 🖥️ Neon Cyan 고대비 시스템 인터페이스 디자인 브리프 (초안)

**목표:** 데이터의 복잡성과 잠재적 위험을 강조하여 '전문가의 전용 프로토콜'이라는 인식을 시각화한다.
**톤앤매너:** 차갑고, 날카로우며, 극도로 대비가 강한 사이버펑크/관제 시스템 스타일 (Cyberpunk / Control Center Aesthetic).

### 1. 핵심 스타일 규칙 (Style Guide)

| 요소 | 설정 값 | 설명 및 의도 |
| :--- | :--- | :--- |
| **배경색 (Background)** | `#0A0A0F` (거의 블랙에 가까운 매우 어두운 네이비/그레이) | 심리적 불안감과 깊이를 조성하며, Cyan 색상이 극대화되도록 대비를 제공한다. |
| **주요 강조색 (Primary Accent)** | `#00FFFF` (Neon Cyan) | 시스템의 활성 상태, 핵심 데이터, 경고 표시 등 가장 중요한 정보에 사용된다. 시각적 충격을 최대화한다. |
| **보조 강조색 (Secondary Accent)** | `#FF3366` (High Contrast Red/Magenta) | 오류, 위험, 사각지대(Gap), 혹은 비정상적인 데이터 흐름을 표시하여 긴급성을 부여한다. Cyan과의 대비를 극대화한다. |
| **텍스트 색상 (Text)** | `#E0FFFF` (밝은 시안) 또는 순백색(`#FFFFFF`) | 주 요소는 Neon Cyan으로 처리하되, 보조 정보(설명 텍스트)는 명확성을 위해 약간 밝은 시안 또는 순백색을 사용한다. |
| **대비 규칙** | **최소 대비 (Minimum Contrast):** 4.5:1 이상 유지 | 모든 요소는 배경과의 극단적인 대비를 통해 '고대비 시스템'의 규칙을 준수해야 한다. |

### 2. 초기 와이어프레임 설계 (Wireframe Concept)

이 인터페이스는 화면 전체가 하나의 '실시간 상황판(Real-time Dashboard)'처럼 구성되어야 합니다.

**레이아웃 구조:** 3단 분할 시스템으로 구성하며, 중앙에 핵심 경고를 배치한다.

| 영역 | 비율 (대략) | 내용 및 시각적 역할 |
| :--- | :--- | :--- |
| **상단 바 (Header Bar)** | 10% 높이 | 시스템 이름 또는 프로토콜 버전 표시 (`[PROTOCOL: A-SYNC v2.1]`). 왼쪽 상단에 상태 표시등(Status Indicator) 배치. |
| **중앙 데이터 필드 (Core Data Field)** | 75% 높이 | 실제 진단 결과나 오류 코드의 핵심 데이터를 표시하는 영역. **가장 많은 Neon Cyan과 Red 경고가 집중되는 곳.** 복잡한 다이어그램이나 데이터 플로우를 시각화한다. |
| **하단 경고/액션 바 (Action/Warning Bar)** | 15% 높이 | 최종적인 위험 수준(Risk Level)을 표시하고, 다음 단계(Next Step / Protocol Bypass)와 같은 CTA 또는 경고 메시지를 배치한다. 이 영역은 보조색(`#FF3366`)을 사용하여 긴급성을 강조한다. |

**시각적 흐름 예시 (스크립트 적용 시점):**

1.  **(0-5초: 문제 재확인)** 화면 전체가 `#0A0A0F` 배경으로 암전되며, 중앙에 거대한 텍스트로 `[UNSEEN FAULT]`가 `#00FFFF`로 플래시백 처리된다.
2.  **(5-15초: 권위 제시)** 복잡한 데이터 다이어그램이 화면을 채우며, 특정 노드(BMS 누락 지점)만 `#FF3366`으로 붉게 깜빡이며 **줌인(Zoom-in)**된다. 이 지점에서 내레이션에 맞춰 해당 노드의 경고가 중앙에 고정되어 시청자의 시선을 강제한다.

### 3. 디자인 규칙 요약 (Execution Checklist)

*   **색상 사용:** 배경은 어둠, 정보는 네온 시안(`#00FFFF`), 위험은 마젠타/레드(`#FF3366`)로 엄격하게 제한한다.
*   **폰트 선택:** 모노스페이스 계열의 산세리프체(예: Fira Code, Space Mono)를 사용하여 기술적이고 기계적인 느낌을 강화한다.
*   **레이아웃:** 모든 요소는 격자(Grid) 기반으로 정렬되어야 하며, 불필요한 장식은 제거하고 기능성만을 강조한다.
