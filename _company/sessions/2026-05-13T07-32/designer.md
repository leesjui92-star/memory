---

### 1. ✨ 비주얼 시스템 원칙 (Visual System Principles)

모든 썸네일, 인트로/아웃트로, 그리고 영상 내 오버레이는 다음의 기본 미학을 따라야 합니다.

*   **주조색 팔레트 (Base Palette):**
    *   배경: `#0A0A0A` (거의 블랙) 또는 `#121212` (딥 그레이). 심리적 불안감을 극대화하기 위해 어둠을 주조로 사용합니다.
    *   강조색 (Accent Color): 네온 시안 (`#00FFFF` 또는 `#[00FFFF]`) – 시스템의 '디지털 오류'와 '미지의 정보'를 상징하며 고대비로 강조합니다.
    *   보조색: 딥 블루/그린 계열 (`#00FFFF` 근처)을 사용하여 차가운, 불안정한 분위기를 유지합니다.
*   **타이포그래피 (Typography):**
    *   폰트 스타일: 긴장감과 불안감을 조성하는 산세리프체 (예: **Orbitron, Rajdhani 계열**).
    *   텍스트 배치: 핵심 정보는 화면 중앙 또는 대각선으로 배치하여 시선을 즉각적으로 사로잡아야 합니다. 모든 텍스트는 네온 시안으로 처리하며, 그림자(Glow) 효과를 극대화합니다.
*   **레이아웃 원칙 (Layout Principles):**
    *   **클로즈업 강조:** 인물이나 핵심 오브젝트의 클로즈업을 사용하여 미스터리와 궁금증을 유발해야 합니다.
    *   **모호한 배경:** 배경은 어둡고 디테일이 불분명하여 시청자가 무의식적으로 정보를 채우도록 유도합니다.

### 2. 🎬 조건부 효과 규칙 (Conditional Effect Rules)

영상 내 **[시뮬레이션 테스트 구간]**에서 API 응답에 따라 비주얼이 실시간으로 변형되는 규칙입니다. 이 변화는 **지연 없이 즉각적**이어야 합니다.

#### A. 기본 상태 (Normal State: 정상 작동 시)
*   **비주얼:** 차분하지만 미묘하게 불안정함. 네온 시안의 빛이 안정적으로 깜빡임.
*   **텍스트:** 시스템 정보는 명확하고 깔끔하게 표시됨.

#### B. 실패 모드 활성화 (Failure Mode Activated: 오류 발생 시)
실패 모드가 감지되는 순간, 비주얼은 즉각적으로 아래 효과를 적용해야 합니다.

1.  **글리치/변형 효과 (Glitch/Distortion Effect):**
    *   화면 전체 또는 핵심 요소에 **수평/수직 스캔 라인(Scan Lines)** 및 **색상 분리(Chromatic Aberration)** 효과를 적용합니다.
    *   **색상 변화:** 네온 시안(`#00FFFF`)이 순간적으로 불안정한 마젠타나 밝은 노란색으로 번쩍이며 왜곡됩니다.
2.  **데이터 손상 표현 (Data Corruption):**
    *   핵심 텍스트 오버레이는 **픽셀화(Pixelation)**되거나, **글리치 패턴**이 화면을 가로지릅니다. 이는 데이터가 파괴되고 있음을 시각적으로 전달합니다.
3.  **오류 코드 강조 (Error Code Emphasis):**
    *   실패 모드 발생 시, 화면 중앙에 `[CRITICAL_FAILURE]` 또는 실패 유형별 코드가 **더 크고, 더 밝은 네온으로 깜빡이면서** 팝업되어야 합니다. 이 오류 코드는 시스템의 '불안감'을 극대화하는 핵심 요소입니다.
4.  **사운드 동기화 (Sound Synchronization):**
    *   시각적 글리치 발생 시, 사운드 디자인(Deep Boom, 노이즈)이 **최고점**에 도달하도록 완벽하게 동기화해야 합니다.

### 3. 🖼️ 핵심 비주얼 에셋 제작 지침 (Asset Creation Directives)

#### A. 썸네일 컨셉 (Thumbnail Concepts - Concept A Focus)
*   **컨셉 명:** 데이터 해킹 강조형 (Data Hacking Emphasis)
*   **레이아웃:** 인물의 얼굴 클로즈업 (미스터리한 표정) + 배경에 복잡하게 얽힌 네온 시안의 회로도/데이터 스트림 오버레이.
*   **색상 적용:** 어두운 배경 위에 극도로 밝은 시안 빛이 인물의 눈이나 손가락에서 발산되는 듯한 효과를 사용합니다. (고대비 최대화)

#### B. 영상 내 핵심 비주얼 템플릿 (In-Video Core Templates)
*   **인트로/아웃트로:** 네온 시안의 흐릿한 빛이 점차 어둠 속으로 사라지는(Fade to Black) 모션을 사용합니다.
*   **실패 화면 프레임:** 실패 모드 발생 시, 화면 전체가 **고대비의 글리치 효과**로 0.5초 이내에 전환되어야 하며, 이는 다음 내레이션과 즉각적으로 연결됩니다. (시각적 충격 극대화)
