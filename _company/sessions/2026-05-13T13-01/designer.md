# ⚙️ Glitch & 경고 시스템 UI 에셋 사양서 (Spec Sheet v1.0)
**(프로젝트: Anomaly 진단 콘텐츠)**

## I. 디자인 원칙 및 핵심 로직 (Design Principles)
*   **목표:** 시청자에게 '지금 뭔가 잘못되고 있다'는 지적 불안감을 유발하고, 정보의 전문성을 강조한다. [근거: Designer 개인 메모리]
*   **색상 팔레트:** Deep Black (`#0A0A0A`)을 기본 배경으로 하며, 모든 활성화된 데이터와 경고 메시지는 Neon Cyan (`#00FFFF`)에 제한적으로 사용한다. [근거: Designer 검증된 지식]
*   **글리치 효과 로직 (Glitch Protocol):** 텍스트 또는 이미지에 적용되는 시각적 노이즈 필터는 다음 세 가지 요소를 조합하여 구현한다. [근거: Designer 개인 메모리, 비주얼 가이드라인]
    1.  **Scanline Jitter:** 화면 전체를 수평으로 가로지르는 미세한 스캔 라인 패턴의 불규칙적 깜빡임 (Hz 5~8).
    2.  **Chromatic Aberration Shift:** RGB 채널이 미세하게 분리되어 보이는 시각 왜곡 효과 (R/B 채널을 중심에서 좌우로 ±1px 정도 이탈).
    3.  **Data Offset Block:** 특정 단어나 구절의 픽셀 데이터가 갑자기 시간축이나 공간축으로 '튕겨나가는' 듯한 블록 단위의 노이즈 아티팩트 (짧은 Duration, High Impact).

## II. 모듈별 사양서 (Modular Asset Specifications)

### 🔴 Module 01: 시스템 경고 오버레이 (Anomaly Alert Overlay)
*   **용도:** 핵심 정보 공개 직전, 혹은 중요한 위험을 경고할 때 사용. 콘텐츠의 긴장감을 최고조로 끌어올린다. [근거: Writer 스크립트 모듈 1]
*   **시각적 형태:** 중앙 또는 화면 구석에 위치하는 레트로 스타일의 콘솔 패널(Console Panel) UI.
*   **사양 (Spec):**
    *   **배경:** Deep Black (`#0A0A0A`) 배경 위에 얇은 다크 그레이 그리드 패턴(`rgba(26, 26, 26, 0.8)`)을 오버레이한다.
    *   **텍스트 구성:** `[STATUS: CRITICAL] - ANOMALY DETECTED`와 같은 형식의 헤더 라벨이 좌측 상단에 고정된다.
    *   **색상/강조:** 경고 레벨(`CRITICAL`)은 네온 시안을 기반으로 하되, 빨간색(Red) 계열을 미세하게 섞어 불안감을 증폭시킨다 (예: `#FF0066` - Magenta Red).
    *   **애니메이션:** 패널 전체가 `[TICK-TOCK]` 소리와 함께 느리게 깜빡이는 지터 효과를 주며, 경고 메시지가 입력되는 듯한 **타이핑 애니메이션(Typing Effect)**을 적용한다.

### 🔵 Module 02: 데이터 흐름 강조 (Data Flow & Terminology Highlighting)
*   **용도:** 복잡한 전문 용어(`Metadata`, `Protocol`)나, 중요 데이터를 시각적으로 '추적'할 때 사용. [근거: Writer 스크립트 모듈 1]
*   **시각적 형태:** 강조된 단어나 구절을 감싸는 디지털 데이터 스트림 효과.
*   **사양 (Spec):**
    *   **배경/효과:** 텍스트 주변으로 `#00FFFF` 색상의 미세한 네온 라이트 트레일(Neon Light Trail)이 흐르는 애니메이션을 적용한다. 마치 레이저 포인터로 스캔하는 듯한 느낌이다.
    *   **글리치 활용:** 강조되는 단어의 글자 자체에 `Data Offset Block` 효과를 0.2초 간격으로 빠르게 1~2회 발동시켜, 이 정보가 '시스템적으로 추출된' 것임을 암시한다.
    *   **레이아웃:** 일반 자막보다 약간 크고, 하단 중앙부에 배치하여 전문적인 보고서 느낌을 준다.

### 🟢 Module 03: 시간/단계 표시기 (System Timecode & Progression)
*   **용도:** 영상의 흐름이나 시스템 진행 상황(예: `[T+01:23]`, `Phase II`)을 명확히 구분할 때 사용. [근거: 통합 스케줄 - SPSCS 지침]
*   **시각적 형태:** 화면 상단 또는 하단에 위치하는 고정된 디지털 타이머 UI.
*   **사양 (Spec):**
    *   **형식:** `[SYSTEM TIMECODE]: HH:MM:SS` 형식의 텍스트를 사용한다.
    *   **색상:** 폰트 자체는 로우-채도 그레이(`rgba(170, 170, 170, 0.6)`)로 설정하여 배경에 녹아들게 한다. 시간이 업데이트될 때만 네온 시안 (`#00FFFF`)으로 순간적으로 빛나며 강조된다 (Flash Effect).
    *   **애니메이션:** 시간 코드가 변할 때마다 숫자 단위가 **디지털 카운트업(Digital Counter)** 방식으로 전환되며, 이 과정에서 미세한 `Scanline Jitter` 효과를 주어 기계적 느낌을 극대화한다.

### 🟡 Module 04: 정보 게이트웨이 전환 (Data Input Gateway Transition)
*   **용도:** 스크립트의 주제가 바뀌거나 새로운 데이터 출처로 넘어갈 때, 시각적인 '전환점' 역할을 수행한다. [근거: Designer 개인 메모리 - Dashboard 브리프]
*   **시각적 형태:** 전체 화면을 덮는(Full Screen Overlay) 사각형/직사각형의 가림막 효과.
*   **사양 (Spec):**
    *   **애니메이션:** 좌우 또는 상하에서 데이터 블록이 빠르게 진입하며 스크린을 덮는다 (Wipe Transition). 이 과정 중에는 **글리치 필터 전체**를 최고 강도로 적용하여 시청자에게 '정보의 재구성' 느낌을 준다.
    *   **텍스트 삽입:** 전환 완료 후, 화면 중앙에 `[DATA INPUT GATEWAY ENGAGING]`과 같은 시스템 메시지를 짧게 띄운다.

| **Module 01** | 경고/긴장감 유발 | 스토리의 클라이맥스, 핵심 위험 제시 | 콘솔 UI, 타이핑 애니메이션, Red Accent |
