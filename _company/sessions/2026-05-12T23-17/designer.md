## 🖼️ 마스터 비주얼 시스템: KPI 강조형 썸네일 프레임워크 (V1.0)

### 1. 핵심 디자인 원칙 (The Core Philosophy)
*   **시스템:** Neon Cyan & High-Contrast System (고대비 시스템).
*   **심리적 효과:** 불안감(Psychological Unease)과 기술적 권위(Technical Authority)의 극대화.
*   **목표:** 단순한 시각적 매력을 넘어, 데이터의 '불안정성'을 즉각적으로 인지시켜 클릭을 유도한다.

### 2. 컬러 팔레트 정의 (Color Palette Definition)
| 역할 | 색상 코드 (Hex) | 설명 | 적용 목적 |
| :--- | :--- | :--- | :--- |
| **배경 (Background)** | `#0A0A14` (거의 블랙/짙은 네이비) | 깊고 어두운 배경으로 심리적 압박감과 고급스러움 부여. | 불안감 조성 및 대비 극대화. |
| **주조 강조색 (Primary Accent)** | `#00FFFF` (Neon Cyan) | 모든 핵심 정보, 데이터 라인, 경고 표시 등에 사용되는 주 색상. | 기술적 권위 및 시각적 중심점. |
| **보조 강조색 (Secondary Accent)** | `#FF4500` (Deep Orange/Red) | 위험(Danger), 오류(Error), 또는 핵심 KPI 실패 지점을 강조하는 데 사용. | 긴급성과 경고 신호 부여. |
| **텍스트/디테일** | `#CCCCCC` (Light Gray) | 보조 정보, 배경 요소의 디테일 표현에 사용. | 세련되고 미니멀한 느낌 유지. |

### 3. 타이포그래피 가이드라인 (Typography Guidelines)
*   **주요 제목 (Headline/KPI):** 고대비의 산세리프체 (예: Montserrat Bold, Orbitron 등). **Neon Cyan** 색상을 필수적으로 적용하며, 크기를 최대화하여 시선 집중.
*   **보조 텍스트 (Subtext/Data):** 명료하고 기술적인 느낌을 주는 산세리프체 (예: Roboto Mono, Fira Code). **Light Gray**를 사용하여 배경과의 대비를 유지.

### 4. 레이아웃 및 프레임워크 (Layout & Framework)
모든 썸네일은 다음의 세 가지 핵심 레이아웃 중 하나를 따르며, **'데이터 불안정성'**을 중심으로 구성되어야 합니다.

#### 📌 컨셉 A: Anomaly Loop (미스터리/클로즈업형) - *가장 권장*
*   **구조:** 인물의 얼굴 또는 핵심 부품의 극단적인 클로즈업(High Detail). 배경은 의도적으로 흐릿하거나 모호하게 처리하여 시청자의 궁금증을 유발.
*   **KPI 강조:** 인물 주변이나 화면 구석에 **Neon Cyan** 라인으로 연결된 데이터 그래프(Waveform, Error Bar)를 오버레이하여 불안정성을 표현.
*   **감성:** 심리적 압박과 미스터리 극대화.

#### 📌 컨셉 B: Dashboard View (시스템/정보형)
*   **구조:** 화면 전체가 데이터 대시보드(Glassmorphism 컨셉 적용 가능) 형태로 구성됨. 핵심 KPI는 중앙에 배치하고 주변을 어두운 배경으로 감쌈.
*   **KPI 강조:** 모든 지표(TSD, ACS 등)를 명확한 Cyan 색상으로 표시하며, 정상 범위와 비정상 범위를 대비색(Cyan vs Orange/Red)으로 구분하여 표시.
*   **감성:** 기술적 권위 및 시스템 안정성에 대한 신뢰 부여.

#### 📌 컨셉 C: Direct Confrontation (직접 대결형)
*   **구조:** 인물(혹은 문제 상황)과 데이터 시각화 요소가 화면을 중앙에서 직접적으로 대치하는 구도.
*   **KPI 강조:** 두 요소 사이에 강력한 대비 라인(Neon Cyan)을 삽입하여, '문제와 해결의 경계'를 시각화.
*   **감성:** 긴장감과 행동 촉구(Call to Action).

### 5. 최종 적용 규칙 (Final Application Rules)
1.  **레이어 순서:** 배경 (`#0A0A14`) → 데이터 오버레이/경고 표시 (Cyan/Orange) → 인물 또는 핵심 주제 → 최종 제목.
2.  **대비 극대화:** 모든 텍스트와 중요한 그래프 선은 **Neon Cyan**으로 처리하고, 나머지 요소는 어두운 배경과 대비를 이루도록 설계하여 시각적 충격을 최대화한다.
3.  **KPI 통합:** 핵심 KPI(예: 안정성 지표)는 일반적인 정보가 아닌, **'경고 표시' 또는 '파형의 비정상 패턴'** 형태로 디자인에 삽입하여 데이터 자체가 스토리텔링의 중심이 되도록 한다.
