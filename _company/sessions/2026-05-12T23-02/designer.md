## ✨ 최종 비주얼 시스템 확정: Anomaly Dashboard Framework

본 프레임워크는 **'기술적 신뢰성(Stability)'**을 기반으로 **'심리적 긴장감(Unease)'**을 극대화하여 타깃 청중(30~40대)의 몰입도를 높이는 것을 목표로 합니다.

### 1. 브랜드 컬러 팔레트 (Color Palette)

| 역할 | 색상 이름 | HEX 코드 | RGB 값 | 사용 목적 및 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary Accent** | Neon Cyan | `#00FFFF` | (0, 255, 255) | 핵심 데이터 강조, 활성 상태 표시, CTA 버튼. 고대비의 핵심 요소. |
| **Background Dark** | Deep Black | `#0A0A0A` | (10, 10, 10) | 전체 배경색. 심리적 불안감과 깊이를 부여하는 주조색. |
| **Secondary Accent**| High Contrast Gray | `#AAAAAA` | (170, 170, 170) | 보조 정보(레이블, 축), 경계선, 비활성 상태 표시. |
| **Warning/Alert** | Error Red | `#FF3333` | (255, 51, 51) | 시스템 오류 지표, 위험 감지 영역. 극도의 대비로 주의 집중 유도. |
| **Text/Label** | Pure White | `#FFFFFF` | (255, 255, 255) | 주 텍스트 및 주요 레이블. 네온 색상과의 최대 명암 대비를 위해 사용. |

### 2. 타이포그래피 시스템 (Typography System)

긴장감과 기술적 권위를 동시에 전달하기 위해 산세리프체 계열을 사용하며, 정보의 위계를 명확히 구분합니다.

| 요소 | 폰트 명 | 스타일/굵기 | 크기 (Base) | 사용 목적 및 규칙 |
| :--- | :--- | :--- | :--- | :--- |
| **Title/Header** | **Monospace / Orbitron** | Bold (700) | 28px - 36px | 대시보드 상단, 핵심 지표 제목. 기술적 권위 강조. |
| **Data Metrics** | **Inter / Roboto Mono** | Medium (500) | 16px - 20px | 실시간 수치(KPI), 시각화된 값. 정보 전달의 정확성 중시. |
| **Labels/Context** | **Inter** | Regular (400) | 14px - 16px | 데이터 항목 설명, 축 레이블 등 보조 정보. |
| **Alert Text** | **Orbitron** | Bold (700) | 14px | 경고 및 오류 메시지. 가장 강한 대비를 위해 사용. |

### 3. 레이아웃 및 컴포넌트 프레임워크 (Layout & Component Framework)

실시간 시각화 결과를 마케팅에 최적화하려면, 복잡한 데이터 흐름을 **'미스터리하고 집중도 높은 단일 비주얼 경험'**으로 압축해야 합니다.

#### A. 전체 레이아웃 원칙 (Overall Layout Principle)
*   **Dark Mode First:** 모든 화면은 Deep Black (`#0A0A0A`) 배경을 기본으로 설정합니다.
*   **Cyan Focus:** 모든 활성 데이터, 그래프 라인, 핵심 지표는 `Neon Cyan`(`#00FFFF`)으로 표현하여 시각적 중심을 잡습니다.
*   **Glassmorphism Layering:** UI 요소(카드, 패널)에는 미세한 투명도와 블러 효과를 적용하여 깊이감과 '관제실' 느낌을 부여합니다.

#### B. 핵심 컴포넌트 디자인 (Key Component Design)

1.  **Status Card (상태 카드):**
    *   **배경:** Deep Black, 낮은 투명도 (`opacity: 0.3`)의 Glassmorphism.
    *   **테두리:** Neon Cyan으로 강조된 얇은 테두리(`border: 1px solid #00FFFF;`).
    *   **핵심 지표 (KPI):** 중앙에 `Data Metrics` 폰트로 표시하며, 수치는 `Neon Cyan`으로 처리합니다.
    *   **상태 표시:** 성공(Success)은 Cyan, 경고(Warning)는 Red(`Error Red`)로 명확히 구분하여 심리적 긴장감을 유지합니다.

2.  **Visualization Area (시각화 영역):**
    *   복잡한 차트보다는 **'Anomaly Loop'의 핵심 지표만을 극단적으로 강조하는 선 그래프(Line Graph)** 또는 **대칭형 게이지(Gauge)** 형태로 단순화하여 시선을 집중시킵니다.
    *   그래프 배경은 거의 투명하게 처리하고, 라인 자체를 `Neon Cyan`으로만 표현합니다.

3.  **CTA Block (행동 유도 영역):**
    *   가장 중요한 전환 지점입니다. CTA 버튼(`Action Button`)은 **Cyan 색상으로 채워진 사각형**이며, 마우스 오버 시 배경이 미세하게 밝아지거나 테두리가 번지는(Glow Effect) 애니메이션을 적용하여 상호작용의 즉각성을 높입니다.

### 4. 초기 비주얼 프레임워크 요약 (Initial Visual Framework Summary)

이 가이드라인은 향후 모든 콘텐츠 제작 시 **스타일 일관성**을 보장하는 마스터 규칙으로 사용됩니다.

*   **톤:** 어둡고, 차갑고, 기술적으로 정밀함.
*   **색상 적용:** Cyan(정보) vs Red(위험). 대비를 통해 정보를 계층화.
*   **형태:** 미니멀한 라인과 각진 프레임을 사용하여 '관제 시스템'의 느낌을 극대화.
