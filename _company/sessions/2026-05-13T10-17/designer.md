## 🖼️ Anomaly Loop - 최종 시각 시스템 블루프린트 (V1.0)

### 1. 색상 및 타이포그래피 규칙 (Global Style Guide)

| 요소 | 설정 값 | 적용 원칙 |
| :--- | :--- | :--- |
| **배경 (Background)** | `#0A0A0A` (Deep Black) 또는 `#1A1A1A` (Dark Gray) | 깊은 블랙을 사용하여 몰입감과 '시스템 오류'의 어두운 분위기 조성. |
| **강조색 (Primary Accent)** | `#00FFFF` (Neon Cyan) / `#00CCFF` (Lighter Cyan) | 시스템의 핵심 정보, 경고, 데이터 흐름을 표현하는 주조색. 빛나는(Glow) 효과 필수 적용. |
| **보조색 (Secondary Accent)** | `#444444` (Subtle Gray) / `#00AACC` (Teal Accent) | 배경의 깊이를 더하고 보조적인 데이터 스트림을 표현. |
| **타이포그래피** | `Orbitron`, `Rajdhani` 계열 | 모든 텍스트(자막, 오버레이)에 글리치/노이즈 필터를 적용하여 시스템 오류 시각화. |

### 2. 핵심 비주얼 에셋 제작 지침

다음은 각 타임코드별로 필요한 핵심 그래픽 요소의 구체적인 디자인 사양입니다.

#### A. [00:00-00:03] 🔥 HOOK: 패러다임 전환 (긴장감 극대화)

*   **에셋:** 오류 코드 오버레이 (`[CRITICAL_FAILURE]`) 및 계기판 클로즈업
*   **디자인 지침:**
    *   **오류 코드:** `#00FFFF` 색상의 픽셀이 순간적으로 폭발하듯 나타나며, 주변으로 미세한 **글리치(Glitch) 노이즈 필터**가 빠르게 번진다. (Duration: 0.5초 이내)
    *   **계기판:** 배경은 어둡게 유지하되, 'Warning' 대신 미지의 문자열이나 불안정한 ASCII 코드가 깜빡이며 나타나야 함. **`Orbitron`** 서체를 사용하여 중앙에 배치하고 네온 시안으로 강조.
    *   **효과:** 화면 전환 시 순간적인 노이즈 스윕(Noise Sweep) 효과를 삽입하여 충격을 극대화.

#### B. [00:03-00:15] 🧠 문제 제기: 지식 격차 자극 (데이터 흐름 연출)

*   **에셋:** 복잡한 데이터 플로우 다이어그램 및 핵심 용어 강조
*   **디자인 지침:**
    *   **다이어그램:** 데이터 노드(Node)들이 끊임없이 생성되고 연결되는 **'Anomaly Loop'의 시각화**. 이 흐름은 정적인 것이 아니라, 네온 시안 라인이 불안정하게 깜빡이며 움직여야 함. (Flow Rate: 빠르고 불규칙하게).
    *   **강조:** 'BMS', 'Data Drift'와 같은 핵심 용어는 일반 텍스트 위에 **`#00CCFF`의 글리치 효과가 적용된 박스**로 오버레이하여, 시청자의 인지 부하를 높이는 방식으로 강조.
    *   **연출:** 데이터 흐름이 화면을 가로지를 때, 미세한 **Scan Line 노이즈**와 함께 움직여야 합니다.

### 3. 비주얼 시스템 적용 최종 점검 (Checklist)

| 항목 | 적용 여부 | 세부 지침 |
| :--- | :--- | :--- |
| **컬러 팔레트 준수** | ✅ | `#0A0A0A` 배경, `#00FFFF`/`#00CCFF` 강조색만 사용. |
| **글리치 효과** | ✅ | 모든 텍스트 및 주요 전환점에 적용하여 시스템 오류의 느낌을 지속적으로 유지. |
| **타이포그래피** | ✅ | `Orbitron`/`Rajdhani` 계열 서체를 사용하여 기술적이고 불안한 분위기 구축. |
| **정보 연출** | ✅ | 데이터 플로우는 '흐름'과 '불안정성'을 통해 시각화하여, 정보의 사각지대를 강조. |
