### 1. 비주얼 시스템 실행 지침 확정 (Visual System Execution Guidelines)

이 지침은 영상 편집 타임라인에 맞춰 모든 그래픽 요소의 배치 및 애니메이션 타이밍을 정의합니다.

| 시각 요소 | 디자인 원칙 | 색상 코드/효과 | 적용 위치 (타임라인 기준) | 목표 감성 |
| :--- | :--- | :--- | :--- | :--- |
| **오류 경고 그래픽** | 고대비, 시스템 오류 폭로 | 배경 `#0A0A0A`, 강조색 `Neon Cyan (#00FFFF)`, Glitch 노이즈 효과 | 인트로 (0:00 - 0:03) 및 주요 실패 지점 표시 | 즉각적인 불안감, 경고 |
| **노드 다이어그램** | 데이터 흐름 시각화 | 선: `Neon Cyan`, 배경: 어두운 그레이. 미세한 Glitch 깜빡임 적용 | 중간 분석 단계 (0:15 - 0:45)의 시스템 연산 과정 | 지적인 복잡성, 통제 불능 |
| **배경 패턴** | 지속적인 불안감 조성 | `#0A0A0A` 배경에 미세한 데이터 스트림(Cyan/Teal 노이즈) 오버레이 | 전체 영상 배경 (Looping) | 지속적인 긴장감, 몰입 유도 |
| **타이포그래피** | 고대비 강조 | 폰트: `Orbitron`/`Rajdhani`, 색상: `Neon Cyan` 또는 흰색. 글리치/노이즈 필터 적용 | 핵심 메시지 및 오류 코드 표시 시점 | 긴박함, 기술적 불안감 |

### 2. 핵심 시각 에셋 제작 착수 지침 (Asset Production Initiation)

Designer는 다음 단계에서 **'Final Visual System Blueprint'**에 기반하여 아래 세 가지 핵심 에셋의 제작을 즉시 착수합니다.

1.  **시스템 오류 경고 인포그래픽 템플릿:**
    *   **요구사항:** `Neon Cyan`과 고대비 디자인 원칙을 적용하여, 시스템이 실패했음을 시각적으로 선언하는 고대비 인포그래픽 레이아웃 제작. (예: 오류 코드와 함께 불안감을 극대화하는 그래픽 요소 배치)
    *   **출력 목표:** 영상의 시작부(인트로)에 삽입될 핵심 시각 프레임셋 확보.

2.  **영상 배경 패턴 에셋:**
    *   **요구사항:** 어두운 배경(`#0A0A0A`) 위에 `Neon Cyan`과 보조 색상(`Teal Accent`)의 미세한 노이즈/데이터 스트림(Glitch 효과)을 오버레이하여, 영상 전체에 적용될 루핑 가능한 배경 패턴 제작.
    *   **출력 목표:** 영상 편집 시 지속적인 불안감을 유지하는 비주얼 텍스처 확보.

3.  **최종 진단 체크리스트 (PDF 레이아웃):**
    *   **요구사항:** 다운로드 가능한 최종 진단 체크리스트를 디자인하며, 네온 시안과 하이테크 도시 통제실 느낌의 UI 요소를 적용하여 전문성과 긴급성을 동시에 전달하는 PDF 레이아웃 확정.
    *   **출력 목표:** 콘텐츠의 실질적인 가치를 담는 에셋 최종 정리.
