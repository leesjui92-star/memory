### ✨ 제작 진입 조건 체크리스트 (Final Gate Check)

**목표:** 기술적 장애 요소 완전 제거 및 창작물 에셋 최종 확정
**진행 상태:** ⚙️ 시스템 구축 완료 $\rightarrow$ 테스트 및 디테일링 필요

#### I. 🛠️ 기술적 검증 단계 (Technical Readiness - Kodari/Researcher 영역)

| 항목 | 내용 | 요구 사항 / 다음 액션 |
| :--- | :--- | :--- |
| **1. 통합 유효성 검사** | `SyncOrchestrator`가 Golden Master JSON 스키마를 완벽하게 해석하는지 테스트해야 합니다. | ➡️ **[필수 실행] 코다리:** `test_synchostrator.py` 파일을 활용하여, 의도적으로 결함을 포함한 Bad Input 데이터셋 전체에 대한 E2E 유닛 테스트 및 결과 보고서를 제출해야 합니다. (오류 처리 로직 검증) |
| **2. 아웃풋 스키마 확정** | 최종 제작물(영상/슬라이드)의 모든 메타데이터 구조가 명확히 정의되어야 합니다. | ➡️ **[검토] 영숙:** `GoldenMaster_Anomaly_Diagnostic_Report_v1.json`을 기반으로, YouTube 및 Instagram 각 플랫폼에 최적화된 최종 출력 포맷(JSON/YAML)을 확정하고 공유해야 합니다. |
| **3. 데이터 플로우 안정성** | 모든 에셋이 하나의 '기술 명세'를 따르도록 파이프라인을 완성합니다. | ➡️ **[검토] 팀 전체:** 콘텐츠 제작 과정에서 발생하는 모든 예외(Error Handling) 시나리오와 그 대응하는 비주얼/오디오 요소를 정의한 매뉴얼 작성이 필요합니다. |

#### II. 🎬 창작물 및 에셋 단계 (Creative Assets - Designer/Writer 영역)

| 항목 | 내용 | 요구 사항 / 다음 액션 |
| :--- | :--- | :--- |
| **1. 최종 스크립트 확정** | 'Anomaly Diagnostic Report'의 원본 스크립트를 기반으로, 영상 내 모든 텍스트 오버레이(Title Card, Warning Message)를 분리하여 재검토해야 합니다. | ➡️ **[수정] Writer:** 스크립트 중 시각화 요소와 반드시 동기화되어야 하는 핵심 문구 (e.g., "책임 주체 미정")의 최종 문장 단위 확정을 요청합니다. |
| **2. 브랜드 에셋 세트** | 글리치, 노이즈, 시스템 경고 모달 등 모든 시각적 요소의 마스터 컴포넌트가 완성되어야 합니다. | ➡️ **[제작] Designer:** `Red/Cyan` 조합을 넘어, 콘텐츠의 감정 변화(불안 $\rightarrow$ 해결책)에 따른 색상 변화를 반영한 에셋 버전을 추가 제작해야 합니다. |
| **3. 플랫폼별 CTA 구조** | 유튜브와 인스타그램 릴스는 최적화된 CTA 배치가 다릅니다. 이 차이를 명확히 분리하여 가이드가 필요합니다. | ➡️ **[최종 확정] 레오/영숙:** '영상 내 시각적 위치'와 '설명(Description)의 문구 구조'를 플랫폼별로 매핑하는 최종 가이드를 만듭니다. |
