## 📊 A/B 테스트 최종 KPI 및 백엔드 추적 로직 정의서 (V1.0)

### 1. 핵심 목표 설정: '진단 서비스 유입' 극대화
*   **최종 목표:** 영상 시청자 → 댓글 참여(전문성 투영) → 랜딩 페이지 방문(정보 탐색) → **Basic Tier 구매 전환.**
*   **측정 원칙:** 각 변수 조합이 어느 단계의 KPI를 가장 강력하게 자극하는지 정의하고, 그에 맞춰 '최적화된 경로'를 설정합니다.

### 2. A/B 테스트 조합 및 예상 목표 지표

| 조합 (Test Group) | 전략적 초점 (Trigger) | 제목 컨셉 예시 (Hook) | 썸네일 컨셉 (Visual) | CTA 문구 기반 (Conversion Focus) |
| :--- | :--- | :--- | :--- | :--- |
| **A. [긴급성]** | **즉각적 위험 경고/최소 개입:** 당장 내가 모르는 치명적인 오류가 있다는 공포 자극. (Basic Tier 유도) | "⚠️ 지금 당신의 OO 시스템에 작동하는 3가지 '보이지 않는' 결함" | 빨간색 경고등, 그래프 급락 애니메이션, 물방울/전력 케이블 이미지 강조. | **[Set 1: Water-Energy Failure]** (가장 쉬운 공포 자극) "당신의 지역은 몇 %의 취약성을 가졌나요? 무료 스캔 받기." |
| **B. [전문성]** | **지적 도전/해결책 제시:** 시청자를 '진단 전문가'로 격상시켜, 더 깊고 복잡한 지식을 요구함. (Standard Tier 유도) | "광물 병목 현상을 우회할 수 있는 대체 기술 3가지 분석 보고서" | 하이테크 블루톤, 복잡하게 연결된 회로/지도를 보여주되, 특정 노드가 빨갛게 깜빡임. | **[Set 2: Mineral Bottleneck]** (해결책을 요구) "당신만 아는 대체 광물 소재가 있다면? 댓글로 논리와 근거를 제시해주세요." |
| **C. [권위/미래]** | **궁극적 시스템의 종말:** 인류 문명 전체의 시스템 붕괴 시나리오를 다루며 최고 수준의 불안감 조성. (Premium Tier 유도) | "문명이 무너질 때, 가장 먼저 먹통이 되는 단 하나의 핵심 자원은?" | 어둡고 웅장한 필름 누아르 톤, 지구 전체 지도 위에 커다란 'X' 표시와 함께 타이머 카운트다운 효과. | **[Set 3: Data Leakage]** (가장 근본적인 질문) "당신의 시스템에서 가장 간과되는 데이터적 위험 신호는 무엇입니까? 전문가의 의견을 들려주세요." |

#### ✨ 예상 KPI 목표 수치 (Baseline Target)
*   **CTR (Click Through Rate):** 12% ~ 18%
    *   A: **최소 15% 이상.** (높은 긴급성이 즉각적인 클릭 유도에 유리)
    *   B: **10% ~ 14%.** (지적 호기심이 깊은 탐색으로 이어져 CTR 자체는 낮으나, 체류 시간이 김.)
    *   C: **8% ~ 12%.** (가장 어려운 전환이지만, 일단 클릭하면 이탈률이 가장 낮은 충성 고객 유입 예상)
*   **댓글 참여율 (Engagement Depth):** 평균 댓글 길이가 최소 3문장 이상이며, [근거: 전문 지식/구체적 사례]를 포함할 확률 20% 이상.

### 3. 필수 백엔드 추적 로직 체크리스트 (Technical KPI Checklist)

이 테스트들을 성공적으로 운영하고 ROI를 측정하려면 단순한 '클릭 수' 이상의 사용자 여정(User Journey)을 파악해야 합니다. 아래 로직은 웹사이트와 영상 플랫폼(YouTube/인스타그램 랜딩 페이지 포함)에 **필수적**으로 구축되어야 합니다.

#### 🛠️ Step 1: 시청 및 이탈 추적 (Video Platform Level)
*   [ ] **View Duration Tracking:** 평균 시청 시간, 그리고 특히 **'2분~3분 구간에서의 이탈 지점(Drop-off Point)'**을 세그먼트별로 측정해야 함. (가설 검증의 핵심 시간대)
*   [ ] **Replay/Loop Rate Pixel:** 영상 종료 후 재시청 여부 및 스크롤링 행동 추적. (KPI: Loop Rate > 70%)
*   [ ] **Heatmap / Time-Stamp Tracking:** 화면 내 특정 지점(예: 경고 그래프가 나타나는 순간, 자막의 핵심 단어)에 대한 사용자의 시선 집중도를 측정하는 로직 필요.

#### 🛠️ Step 2: 참여 및 관심도 추적 (Comment/Social Level)
*   [ ] **Comment Submission Event:** 댓글 작성 시작(Input Focus)부터 제출 완료까지의 모든 이벤트를 추적해야 함.
*   [ ] **Sentiment Analysis API Hook:** 제출된 댓글에 대해 AI를 이용해 '불안감 수준'과 '문제 해결 지향성'을 점수화하여 기록. (단순 참여 횟수보다 가치 높음)
*   [ ] **Keyword Extraction Logic:** 댓글에서 `[근거: 특정 전문 용어/지표 이름]`이 언급될 경우, 해당 사용자를 '고가치 잠재 고객(High-Value Lead)'으로 자동 태그링하는 시스템.

#### 🛠️ Step 3: 전환 경로 및 수익화 추적 (Landing Page & Funnel Level)
*   [ ] **UTM Parameter Tracking:** 모든 CTA 링크는 반드시 조합별로 고유한 UTM 파라미터를 부여하여, 어떤 A/B 조합이 유입되었는지 출처를 명확히 구분해야 함.
    *(예: `?utm_source=youtube&utm_medium=cta&utm_campaign=A_WaterFailure`)*
*   [ ] **Micro-Conversion Event:** 랜딩 페이지 내에서 '무료 PDF 다운로드 버튼 클릭', '가격 정책 섹션 스크롤 완료' 등 구매 직전의 작은 행동(행동 지표)을 모두 카운트해야 함. (KPI: Micro Conversion Rate)
*   [ ] **Funnel Drop-off Point:** Basic Tier 페이지 진입 → 필수 정보 확인 → 결제 유도 메시지 노출 → **실제 장바구니/폼 제출 실패**가 발생하는 정확한 지점을 기록하여, UX 개선 우선순위를 정해야 함.
