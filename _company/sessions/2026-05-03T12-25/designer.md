### 🛠️ ASET KIT: 시스템 불안정 및 정보 노출 (1920x1080 / PNG & SVG)

#### 1. 타이포그래피 애니메이션 에셋 (Typography Animation Assets)
**목표:** 긴장감 고조, 핵심 키워드 강조, 플래시 커트 싱크 포인트 제공.
**폰트:** Space Mono (또는 유사한 Monospace/Tech 느낌의 산세리프체)
**색상 코드:**
*   메인 텍스트: `#00FFFF` (네온 시안)
*   배경 오버레이: 투명도 조절된 블랙 (`rgba(0, 0, 0, 0.6)`)

| 에셋 ID | 유형 | 구성 요소 및 크기 | 애니메이션/사용 지침 (핵심) | 파일 포맷 권장 |
| :--- | :--- | :--- | :--- | :--- |
| **T-WARN-01** | 경고 메시지 팝업 | "WARNING: DATA INTEGRITY BREACH" (2줄), 고정 폭 배너형. | **[Flash Cut 필수]** 화면 좌측 상단에서 빠르게 진입(Scale Up + Cyan Glow) 후, 0.5초간 깜빡임 효과(Blink/Glitch). 문장 끝에 `[ERROR]` 코드를 작은 글씨로 추가하여 싱크 포인트 제공. | PNG (Alpha Channel 지원 필수) / After Effects Project File |
| **T-DATA-02** | 핵심 데이터 노출 | `<CODE> [INPUT_VARIABLE] >` 형식의 박스형 텍스트. | **[Typewriter Effect + Glow]** 네온 시안색으로 빠르게 타이핑되는 효과를 준 후, 문장 전체가 순간적으로 깜빡이며(Flash) 강조됨. 배경에 미세한 노이즈 필터 적용 권장. | SVG (벡터 기반 수정 용이) |
| **T-LOOP-03** | 질문/의문 제기 | "WHY IS IT MISSING?" 등 짧고 강렬한 문구. | **[Stutter Effect]** 텍스트가 화면 중앙에 나타나지만, 마치 신호가 끊긴 것처럼 (Glitch + Skip) 반복적으로 깜빡이는 애니메이션을 적용하여 루프적 불안감을 조성. | PNG / After Effects Project File |

#### 2. 데이터 시각화 에셋 (Data Visualization Assets)
**목표:** 추상적인 개념(불안정성, 패턴)을 직관적이면서도 위협적으로 표현.

| 에셋 ID | 유형 | 구성 요소 및 크기 | 애니메이션/사용 지침 (핵심) | 파일 포맷 권장 |
| :--- | :--- | :--- | :--- | :--- |
| **D-CHART-01** | 시스템 상태 차트 | 3개의 Y축(Metric A, B, C), X축은 시간 흐름. (빈 그래프 형태) | **[Anomaly Growth]** 정상 범위(Cyan 구간)에서 시작하여, 특정 지점부터 갑자기 빨간색/주황색으로 치솟는 '비정상 데이터 패턴'을 시각화합니다. 차트 라인 주변에 미세한 노이즈와 글리치 효과를 오버레이합니다. | SVG (데이터 값 수정 가능하도록) |
| **D-GRID-02** | 배경/정보 필터 | 화면 전체 또는 특정 구역을 덮는 격자(Grid) 패턴과 스캔라인. | **[Scanline & Pulse]** 주기적으로 수평선(Scanlines)이 움직이며, 이 Grid 위로 핵심 정보가 '스캔'되듯이 나타나게 합니다. 배경의 고대비와 네온 시안색을 유지하는 데 필수적입니다. | PNG (Seamless Tileable Pattern) |
| **D-NODE-03** | 연결 패턴/분석망 | 중앙 노드(핵심 의문점)에서 주변으로 뻗어 나가는 점선 연결 구조. | **[Pulse Connection]** 모든 선과 노드가 한 번에 나타나는 것이 아니라, 마치 전기 신호처럼 (Cyan Pulse) 순차적으로 연결되면서 분석의 깊이를 보여줍니다. 가장 중요한 연결고리(패턴)는 두꺼운 Cyan 라인으로 처리합니다. | SVG / After Effects Project File |

**목표:** 영상에 '내가 시스템을 해킹하고 있다' 혹은 '이건 비밀 정보다'라는 느낌 부여.

| 에셋 ID | 유형 | 구성 요소 및 크기 | 애니메이션/사용 지침 (핵심) | 파일 포맷 권장 |
| :--- | :--- | :--- | :--- | :--- |
| **U-CONSOLE-01** | 콘솔 메시지 창 | 화면 하단 1/6 영역을 차지하는 가상의 터미널 창. | **[Typewriter & Glitch]** 마치 커서가 깜빡이면서 명령어를 입력하는 것처럼 (커서 애니메이션 필수), 결과 메시지가 출력되는 효과를 반복적으로 사용합니다. 배경은 Deep Charcoal, 텍스트는 Cyan으로 고정됩니다. | PNG / After Effects Project File |
| **U-FILTER-02** | 시점 왜곡 필터 | 화면 전체에 적용되어 미묘하게 색상이나 선명도를 떨어뜨리는 효과. | **[VHS/CRT Effect]** 영상 중간에 특정 순간(전환부)에 사용하며, 신호 간섭(Interference) 느낌을 주어 심리적 불안감을 극대화합니다. 노이즈와 함께 네온 시안색의 가로줄 패턴이 주기적으로 나타나게 합니다. | PNG (Full Screen Overlay) |

**요약 및 디렉터 전달 지침:**
1.  **일관성 유지:** 모든 에셋은 배경 `#0A0A15`와 대비되는 네온 시안색을 중심으로 구성되어야 하며, 정보가 노출될 때만 강렬한 빛(Glow) 효과를 주어야 합니다.
2.  **애니메이션 우선:** 각 에셋의 **'애니메이션/사용 지침 (핵심)'** 항목이 곧 편집 가이드라인이며, 이를 기반으로 Motion Graphic 디자이너에게 전달해야 합니다.
3.  **포맷 분리:** SVG는 구조 변경이 필요한 데이터(차트)에, PNG는 배경 및 효과(노이즈, 팝업)에 활용합니다.
