2.  **Pacing:** 플래시 커트를 이용한 긴장감 유지와 데이터 노출 시의 리듬 조절.
3.  **Looping:** 결론에서 명확한 '해결되지 않은 의문'을 던져 재반복 비율(Loop Rate) 극대화.

## 🎞️ Anomaly Loop: 테스트 영상 편집 디렉션 시트 (16:9, 4K/풀 HD 권장)

### 💡 사운드 및 전체 분위기 지침
*   **BGM:** 지속적으로 낮은 주파수의 진동음(Drone Sound)을 깔아 심리적 압박감을 유지합니다.
*   **사운드 디자인:** 모든 컷 전환 시점에 `[Glitch Noise]`, `[Data Corruption Sound]` 효과를 필수적으로 삽입하여 시스템 오류 느낌을 극대화합니다.
*   **VOICE OVER (V.O.):** 속삭이거나, 무미건조하고 기계적인(Monotone/Synthesized) 톤을 유지하며, 문장의 끝에 항상 숨겨진 의미가 있는 것처럼 처리합니다.

### I. 도입부: The Hook (0:00 – 0:03)
*(목표: 시청자가 스크롤을 멈추고 '이게 뭐지?'라고 생각하게 만듦)*

| Time Code | 액션 종류 | 비주얼 디렉션 및 에셋 사용 | 사운드 디자인 & 자막 지침 |
| :--- | :--- | :--- | :--- |
| **0:00 – 0:01** | **[폭발적 시작]** | 화면 전체가 흰색 노이즈 또는 무작위 데이터 스트림으로 가득 참. (빠른 플래시) | `[Loud Glitch Sound]` + `[Static Noise]` 최대 볼륨. 자막 없음. |
| **0:01 – 0:02** | **[정보 충격]** | 배경이 암전되고, 갑자기 깨끗한 화면에 경고 메시지 등장. (T-WARN-01 사용) | `V.O.:` "경고. 데이터 무결성 손상 감지." (빠르고 단호하게). 자막: **빨간색/네온 시안**으로 깜빡임 효과 부여. |
| **0:02 – 0:03** | **[루프 유도]** | 화면이 극도로 빠르게 플래시하며, 핵심 질문만 남김. (T-LOOP-03 사용) | `V.O.:` "하지만... 이것은 패턴입니다. 왜 빠진 거죠?" 자막: **"WHY IS IT MISSING? [ERROR]"** 텍스트가 끊기듯이 깜빡임(Stutter Effect). 사운드에 *Up-Swing* 효과를 주어 다음 정보를 기대하게 만듦. |

### II. 본론: The Anomaly Loop 구축 (0:03 – ~1:25)
*(목표: 시청자에게 '패턴'을 발견하는 과정의 지적 만족감을 제공하며 몰입도를 높임)*

| Time Code | 액션 종류 | 비주얼 디렉션 및 에셋 사용 | 사운드 디자인 & 자막 지침 |
| :--- | :--- | :--- | :--- |
| **0:03 – 0:15** | **[문제 제기]** | (원본 소스 A) 일반적인 금융 그래프/뉴스 화면을 보여주며, 특정 구간만 어둡게 처리. | `V.O.:` "당신은 이 패턴을 보고 지나쳤습니다." 사운드는 진동음 유지. 자막: 배경 위에 네온 시안의 'OVERLAY'를 얇게 깔아 불안감을 조성. |
| **0:15 – 0:35** | **[데이터 노출]** | (원본 소스 B) 관련 데이터를 자료화하여 제시. 시스템 에셋 T-DATA-02 집중 활용. | `V.O.:` "모든 거래는 이 변수에 의해 통제됩니다." 자막: `<CODE> [INPUT_VARIABLE] >` 패턴으로 데이터를 *빠르게 타이핑*하며 보여줌. 각 데이터 노출마다 `[Beep Sound]` 효과 필수 삽입. |
| **0:35 – 1:00** | **[패턴 발견]** | (원본 소스 C) 여러 개의 무작위 이미지를 나열하되, 특정 이미지 그룹이 동일한 배열을 이루는 순간 포착(B-roll 활용). | **컷 리듬:** 2~3초 간격으로 컷 전환. 시청자가 '패턴'을 인식하는 지점에서는 모든 소스를 잠시 정지시키고, 오직 `[System Hum]` 사운드와 함께 화면 중앙에 네온 시안의 패턴 화살표만 깜빡이게 함 (T-DATA-02 변형). |
| **1:00 – 1:25** | **[심층 분석]** | 논리적으로 비약하는 듯한 설명과 복잡한 그래픽 자료를 빠르게 교차 편집. | `V.O.:` "이 시스템은 당신의 행동을 예측합니다." 자막: 핵심 키워드(예: '취약성', '통제', '변수')가 나올 때마다 **글리치 효과**와 함께 팝업됨 (T-WARN-01 변형). |

### III. 결론: The Loop Reinforcement (1:25 – End)
*(목표: 절대 답을 주지 않고, 다음 영상에서 해결할 '더 큰 의문'을 심어주며 마무리)*

| Time Code | 액션 종류 | 비주얼 디렉션 및 에셋 사용 | 사운드 디자인 & 자막 지침 |
| :--- | :--- | :--- | :--- |
| **1:25 – 1:30** | **[결론 회피]** | 화면이 급격히 어두워지며(암전), 모든 데이터 스트림이 끊기는 듯한 효과. | `V.O.:` (속삭임) "하지만 이 시스템의 *근원*을 본 적은 없습니다." 사운드: 진동음이 갑자기 멈추고, 무거운 정적만이 남음. |
| **1:30 – 1:35** | **[마지막 경고]** | 배경에 미세한 노이즈가 깔리고, 마지막 충격적인 문구가 등장. (T-WARN-01 사용) | 자막: "당신이 모르는 진실이 있습니다." (깜빡임/글리치 효과). `V.O.:` (경고음과 함께) "다음 시간에도 계속됩니다." |
| **1:35 – End** | **[아웃트로]** | 검은 화면 + 채널 로고 노출. | 음악이 점진적으로 페이드 아웃 되며, 미세한 `[Humming Sound]`만 남김. 영상 끝에 '구독'을 유도하는 텍스트는 최대한 단순하고 기술적인 느낌으로 처리 (예: "SYSTEM CONTINUES"). |
