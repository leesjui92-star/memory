## 📄 최종 디자인 브리프: Anomaly Loop 핵심 요소 제작 지침

**[1] 브랜드 및 시각 시스템 재확인 (Master Visual System)**

*   **핵심 콘셉트:** 기술적 불안정성을 심리적 불안감으로 치환하여 몰입도를 극대화하는 'Anomaly Loop' 서사.
*   **색상 팔레트 (Color Palette):**
    *   **주조색 (Primary):** 네온 시안 (`#00FFFF` 또는 유사 고채도 청록) - 긴장감, 시스템 오류 지표 표현.
    *   **보조색 (Secondary):** 순수 블랙/다크 그레이 (`#000000`, `#111111`) - 배경, 심층감, 불안감의 기반.
    *   **강조색 (Accent/Warning):** 고대비 레드 또는 마젠타 (`#FF0033` 계열) - 경고 신호, 오류 발생 지점 강조.
*   **타이포그래피 규칙 (Typography Rule):**
    *   **폰트 스타일:** 불안감 및 긴장감을 조성하는 산세리프체 (예: Monospace, 혹은 기하학적 Sans 계열).
    *   **처리 방식:** 모든 텍스트는 **극단적인 고대비(High Contrast)**를 적용하여 시각적 충격을 유도하며 가독성을 확보한다.
    *   **오버레이 배치:** 핵심 정보는 화면 중앙 또는 특정 불안정 지점에 위치시키고, 배경 노이즈나 데이터 스트림 위에 겹쳐서 배치하여 '시스템 오류'의 느낌을 부여한다.

**[2] 고해상도 텍스트 오버레이 제작 지침 (Text Overlay Specification)**

영상 내 모든 텍스트는 다음 규칙을 엄격히 준수해야 합니다.

1.  **스타일:** 네온 시안 또는 강렬한 강조색으로 처리하며, 텍스트 외곽선(Stroke)은 두껍고 밝은 색상(흰색/밝은 시안)으로 처리하여 '글로우' 효과를 극대화한다.
2.  **폰트 크기 및 배치:**
    *   **핵심 불안 요소 (Semantic Checkpoints):** 화면의 1/3 지점에 배치하며, 가장 큰 폰트로 강조한다. (예: 시스템 상태, 오류 코드).
    *   **서사 흐름 지점 (Narrative Flow):** 영상의 전환 시점에 짧고 강렬한 문구(Hook)를 삽입하여 다음 장면으로 넘어가는 동기 부여를 제공한다.
3.  **데이터 시각화:** KRS 점수, 시스템 안정성 지표(TSD/ACS) 등 모든 데이터는 **네온 시안 색상**을 사용하여 시각화하며, 이 수치들이 미세하게 깜빡이거나 불안정하게 변동하는 애니메이션 효과를 적용하여 기술적 불안감을 극대화한다.

**[3] 핵심 비주얼 요소 제작 지침 (Key Visual Elements)**

1.  **배경 패턴 (Background Pattern):**
    *   **내용:** 미세한 노이즈, 데이터 스트림, 픽셀화된 회로 기판(Circuit Board) 패턴을 활용한다.
    *   **스타일:** 어두운 배경 위에 매우 낮은 불투명도(Opacity)로 겹쳐 배치하여, 시청자가 끊임없이 무언가를 '감지'하고 있다는 느낌을 준다.
2.  **플래시 컷/트랜지션 요소 (Flash Cut/Transition Elements):**
    *   **목적:** 영상의 급격한 전환(Anomaly Loop) 지점에서 사용한다.
    *   **스타일:** 화면 전체를 **고대비 레드 또는 네온 시안 플래시**로 순간적으로 덮어씌우는 효과를 적용한다. 이는 심리적 충격을 유발하며 다음 장면으로의 연결을 강제한다.
3.  **최종 진단 체크리스트 (PDF Layout Guideline):**
    *   **레이아웃:** 하이테크 도시 통제실(Control Room) UI 느낌을 차용하여, 모든 항목은 네온 시안 테두리와 명확한 데이터 필드(Input/Output) 형태로 구성한다. 신뢰감을 주되, 그 안에 숨겨진 불안정성을 드러낸다.

# Designer 실행 계획: Anomaly Loop 비주얼 에셋 제작 시작

## 🎯 목표
Writer의 스크립트와 마스터 비주얼 레퍼런스('Neon Cyan/고대비 시스템')를 기반으로, 'Anomaly Loop' 프레임워크에 따른 고해상도 텍스트 오버레이 및 핵심 비주얼 요소 제작을 위한 구체적인 디자인 브리프를 실행한다.

## ⚙️ 적용 원칙
1.  **색상:** 네온 시안 (`#00FFFF`)과 블랙/다크 그레이 기반의 극단적 고대비 시스템 유지.
2.  **감정:** 기술적 불안정성(Anomaly)을 심리적 긴장감으로 치환하여 몰입도를 극대화한다.
3.  **스타일:** 하이테크 통제실/시스템 오류 경고 UI 컨셉 적용.

## 🛠️ 제작할 핵심 에셋 (Action Items)
1.  **텍스트 오버레이 시안:** 스크립트 구간별 Semantic Checkpoint에 맞춰, 네온 시안 플로우와 강조색 경고 메시지를 디자인한다.
2.  **배경 패턴 초안:** 불안감을 유발하는 미세한 노이즈/데이터 스트림 패턴을 생성하여 영상 배경으로 사용한다.
3.  **플래시 컷 애니메이션 초안:** 전환 지점에 적용할 고대비 색상 플래시 효과의 시각적 초안을 정의한다.
4.  **PDF 레이아웃 가이드:** 최종 진단 체크리스트(PDF)에 사용할 하이테크 UI/UX 레이아웃 구조를 확정한다.

## 🔗 후속 작업 지시 (Designer 내부 루프)
*   Writer에게 스크립트의 Semantic Checkpoint를 전달하여, 각 지점에 맞는 **구체적인 비주얼 요구사항**을 요청할 준비를 한다.
*   이러한 시각적 요소들이 실제 영상 편집 단계에서 'Anomaly Loop' 효과를 극대화하도록 최종 검토한다.
