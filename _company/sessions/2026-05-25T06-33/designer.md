# 🚨 Visual Shockwave: T+5s 경고 오버레이 에셋 기술 사양서 (v1.0)

**목표:** 시청자에게 '정보의 결함' 및 '위험한 지식 공백(Knowledge Void)'을 경험하게 하여, 콘텐츠에 대한 전문 컨설팅 필요성(Need for Consultation)을 극대화한다.
**적용 시간 코드:** T+5초 ~ T+10초 (최소 3~4초 구간 동안 점진적으로 경고 강도 상승 후 최대치 도달).

*   **Red/Cyan 비율 제어:** T+5초에서 Neon Red가 Cyan보다 점진적으로 우세해지는 '불균형'을 연출하는 것이 핵심이다.

## 2. 애니메이션 루프 및 타이밍 (Animation Loop & Timing Protocol)

Visual Shockwave는 세 단계의 누적된 긴장감(Tension Build-up)으로 구성되어야 하며, 총 재생 시간은 최소 3초가 권장된다.

| 시간대 (Relative Time) | 시각적 이벤트 | 애니메이션 로직 및 루프 | 효과 강도/변수 |
| :--- | :--- | :--- | :--- |
| **T+0s ~ T+1s** (Pre-Shock) | **Subtle Glitch Trigger** | 전체 화면에 미세한 픽셀 노이즈(Scanline Filter)가 무작위로 발생하며, Cyan 데이터 스트림 위에 짧은 글리치 패턴(`[<GLITCH>]`)이 반복적으로 삽입된다. | 강도: Low. 주파수: 빠름. 목적: 시청자에게 '뭔가 이상하다'는 초기 의심 유발. |
| **T+1s ~ T+2.5s** (Corrupting Data) | **Semantic Drift / Code Corruption** | 배경의 Cyan 데이터 스트림이 갑자기 파열되는(Bursting) 애니메이션을 보여준다. 깨진 데이터 조각들 사이로 Neon Red의 경고 프레임(`[ALERT: DATA CORRUPTION]`)이 팝업되며, 화면 전체에 짧은 *화면 깜빡임 (Flicker)* 효과가 동기화된다. | 강도: Medium. 패턴: 무작위 노이즈 + 구조적 파열. 목적: 시스템 오류의 시각적 증거 제시. |
| **T+2.5s ~ T+3.5s** (Knowledge Void Peak) | **System Overload / Red Alert** | 화면 전체를 덮는 가장 강렬한 경고 오버레이가 발생한다. 네온 레드(`#FF2222`) 색상으로 된 거대한 경고 프레임이 중심을 차지하며, `[WARNING: KNOWLEDGE VOID DETECTED]` 같은 문구가 반복적으로 깜빡인다(Blink). 이와 동시에 모든 텍스트에 *디스토션(Distortion)* 효과가 극대화된다. | 강도: High (최고점). 지속 시간: 짧지만 강력한 충격. 목적: 지식 공백을 '시스템적 결함'으로 인식시키며 불안감을 최고조로 끌어올림. |

## 3. 기술 사양 및 해상도 지침 (Technical Specification & Resolution)

*   **최종 포맷:** PNG Sequence 또는 ProRes 422 HQ (애니메이션의 부드러운 변화를 위해 프레임 단위 작업 필수).
*   **해상도:** 1080 x 1920 px (9:16 비율, 쇼츠 표준).
*   **파일 크기 제약:** 오버레이 에셋이므로, 전체 영상의 시각적 무게감을 해치지 않도록 투명 배경(Alpha Channel)을 유지하며 제작한다.
*   **삽입 지침:** T+5초 경고 구간은 **비디오 트랙 레이어 3 (Overlay Layer)**에 배치되어야 하며, 아래층의 주 콘텐츠와 강하게 대비되면서도 이질적이지 않게 보이도록 '필터' 개념으로 접근해야 한다.
