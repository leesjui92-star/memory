# ⚙️ JRock: Anomaly 진단 프로토콜 - 마스터 모션 그래픽 기술 사양서 (Master Spec Sheet)

**프로젝트:** 시스템적 리스크 분석 기반 도입부 시퀀스
**길이 목표:** 30초
**테마:** 지식의 만료화 / 구조적 불안감 유발 (System Failure & Data Overload)
**핵심 원칙:** 모든 비주얼 로직은 오디오 이벤트(Sound Event)에 반응하는 '반응형 아키텍처'를 따른다.

## 1. 글로벌 디자인 시스템 파라미터 (Global Parameters)

| 요소 | 규격/값 | 기술적 지침 및 애니메이션 규칙 |
| :--- | :--- | :--- |
| **배경 (BG)** | Deep Black (`#0A0A0A`) | 모든 배경은 어둠을 유지하며, 조명 효과는 미세한 노이즈(Film Grain)로 표현한다. 절대 순수 블랙으로 처리하지 않는다. |
| **메인 컬러** | Neon Cyan (`#00FFFF`) | 활성화된 데이터, 정보 플로우, 경고 프레임에 사용. 모든 텍스트의 기본 Glow 효과 색상이다. (Opacity: $15\% \sim 90\%$ 사이에서 변동) |
| **경고 컬러** | Crimson Red (`#FF004C`) | 위기 발생, 데이터 불일치(Anomaly), 핵심 결론 제시 시 사용. Cyan과 대비를 이루며 깜빡임(Blinking Opacity) 로직을 적용한다. |
| **폰트 (Typography)** | `Orbitron` 또는 `Rajdhani` 계열 | 모든 텍스트에 디지털 노이즈/글리치 효과 필터를 필수적으로 오버레이 한다. 글자 하나하나가 떨어지거나(Pixel Drop), 색상이 번지는 듯한(Chromatic Aberration) 애니메이션을 기본으로 적용한다. |
| **효과 (Effect)** | Glitch Protocol | 텍스트나 이미지가 화면에 나타날 때, 좌우로 빠르게 떨리며($X$-축/ $Y$-축의 미세 진동), 일시적으로 색상 코드가 튀는(Color Shift) 현상을 거친 후 최종 위치에 안착한다. |

## 2. 시간 코드 기반 애니메이션 시퀀스 (Time-Coded Sequence Flow)

아래 표는 Time Code를 기준으로 비주얼 로직, 사운드 이벤트, 그리고 필수 키프레임 동작(Keyframe Action)을 정의합니다. **모든 값은 프레임/시간 단위로 엄격히 준수해야 합니다.**

| Time Code | 시간 (초) | 오디오 이벤트 (Sound Event) | 비주얼 로직 및 목적 | 핵심 애니메이션 사양 (Animators' Notes) |
| :--- | :--- | :--- | :--- | :--- |
| **T+00:00** | 0.0 - 0.5s | **[Deep Sub-Bass Boom]** 시작 (LFE 최대치). | **Intro Hook / 시스템 초기화 실패.** 화면 전체에 강한 진동과 함께 노이즈가 폭주한다. | **1. Impact:** 배경 전체에 `#FF004C`의 펄스(Pulse)와 미세한 글리치가 발생하며, Opacity가 $0\% \rightarrow 100\%$로 급증했다가 순간적으로 $20\%$까지 떨어졌다 재상승하는 로직을 구현한다. **2. Text:** 중앙에 'SYSTEM ALERT' 텍스트가 Glitch Protocol과 함께 강제로 나타난다. |
| **T+00:01** | 0.5 - 3.0s | 짧은 고주파의 *Warning Tone* (삐-익). 데이터 스트림 시작. | **진단 프로토콜 개시.** '현재 시스템 상태'를 보여주는 가짜 콘솔 인터페이스가 나타난다. | **1. Structure:** 화면이 분할(Split Screen)되고, 상하/좌우로 Cyan 기반의 복잡한 그리드 패턴과 데이터 스트림(`[DATA_STREAM: OK]`, `[PROTOCOL: ACTIVE]`)이 끊임없이 흘러간다. **2. Keyframe:** 텍스트는 $10 \text{ms}$ 간격으로 깜빡이며(Blinking), Opacity가 $60\% \rightarrow 85\%$로 변동하는 루프 애니메이션을 적용한다. |
| **T+03:01** | 3.0 - 7.0s | (Whisper) 차분한 나레이션 시작. '지식의 만료화' 키워드 강조. | **핵심 문제 제기 / 데이터 오버로드.** 초기 안정 상태였던 데이터 스트림에 오류가 감지되며 불안감이 고조된다. | **1. Transition:** Cyan 그리드가 갑자기 느려지고, `#AAAAAA` (Neutral Gray) 계열의 '데이터 불일치 경고(DATA MISMATCH)' 메시지가 화면을 가득 채우며 나타난다. **2. Action:** 텍스트가 출현하는 순간마다 미세하게 스케일이 커졌다 작아지는($Scale: 105\% \rightarrow 100\%$) 진동 효과를 적용한다. |
| **T+07:01** | 7.0 - 14.0s | 배경 음악의 리듬 변화 (점점 빨라지고 불협화음 증가). | **시스템 오류 발생 (Anomaly Detection).** 문제 지표가 폭주하며 '위험' 상태로 전환된다. Red/Cyan 대비 극대화 구간이다. | **1. Color Shift:** 화면 전체의 주조색이 Cyan에서 Crimson Red (`#FF004C`)으로 급격히 치우치기 시작한다 (Color Grading). **2. Glitch Intensity:** 글리치 효과가 가장 강해진다. 텍스트는 Opacity와 함께 빠르게 깜빡이며, 일부 데이터 블록은 마치 전력이 끊긴 것처럼 일시적으로 사라졌다가(Opacity $0\% \rightarrow 10\%$ $\rightarrow 50\%$) 돌아오는 로직을 반복한다. |
| **T+14:01** | 14.0 - 22.0s | (Dramatic Pause) 나레이션의 절정. 공포감을 유발하는 침묵 구간(Silence Dip). | **결론 도출 직전의 공백.** 모든 데이터가 잠시 '멈춘' 상태를 연출하여 긴장감을 극대화한다. | **1. Visual Void:** 화면이 깊은 Black (`#0A0A0A`)으로 돌아간다. Cyan/Red 강조색을 사용한 오버레이 그래픽은 완전히 제거된다. 오직 배경에만 미세하고 느린 노이즈 필터가 작동하여 '무엇인가가 숨겨져 있다'는 느낌을 준다. **2. Timing:** 이 구간의 길이는 사운드의 공백 시간(Silence Dip)과 정확히 일치해야 한다. |
| **T+22:01** | 22.0 - 30.0s | (Climax) 해결책 제시 / CTA 유도. 긴장감이 해소되며 결론을 전달하는 사운드 이벤트. | **진단 보고서 및 행동 촉구.** 불안감을 해결할 수 있는 '지식'의 가치를 시각적으로 각인시킨다. | **1. Structure:** 화면에 간결한 템플릿(Dashboard Mockup)이 나타난다. (Cyan/Red 조합 사용). 핵심 키워드(`Vulnerability`, `Diagnosis`)가 큰 글씨로, 정교하게 애니메이션 되어 나타나야 한다. **2. Final Action:** 마지막 CTA 메시지("지금 진단하세요")는 가장 밝고 선명한 Neon Cyan을 사용하여 화면 중앙에 고정 배치하며, 폰트 사이즈를 최대화한다. |

### 구현 지침 요약 (Action Items for Animator)

1.  **시간 동기화 최우선:** 모든 비주얼 변화는 오디오 이벤트의 시작/끝 시간 코드와 **$\pm 50 \text{ms}$ 이내**로 완벽하게 일치해야 합니다.
2.  **키프레임 필수 사용:** Opacity, Scale, Position 등 모든 변수는 '갑자기' 바뀌지 않고, 최소 $1-3$ 프레임에 걸쳐 변화하는 키프레임 애니메이션을 반드시 적용합니다.
3.  **반응형 로직 구현:** Red/Cyan 깜빡임은 독립적인 타이머가 아니라, 사운드 이벤트의 주파수(Frequency)와 진폭(Amplitude)에 비례하여 강도가 조절되는 '반응형' 방식으로 설계되어야 합니다.
