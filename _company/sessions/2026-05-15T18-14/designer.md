## 목표: 시각적 권위 확보 및 전문성 주입
단순히 '깨진 화면'을 보여주는 것이 아니라, **실제로 존재할 것 같은 가상의 공학 장비/시스템의 오류**를 재현하여 시청자에게 지적인 불안감과 신뢰감을 동시에 부여하는 것을 목표로 합니다.

---

### ⚙️ 에셋 1: 블랙박스 데이터 흐름 시뮬레이션 (The Black Box Data Flow)
가장 먼저, 일반인이 접근할 수 없는 '깊은 곳'의 데이터를 보여줌으로써 문제의 심각성을 정의합니다.

**[상징하는 것]** : 시스템 내부의 비밀 정보 / 원인 규명 불가능성.
**[활용 시점]** : 스크립트 초반부 (0:30 - 1:25) '문제 정의' 단계.
**[비주얼 구성 요소]**
1.  **배경:** Deep Black (`#0A0A0A`) 배경 위에 희미한 Grid 패턴(레이저 격자망)을 깔아줍니다.
2.  **데이터 스트림 (Primary):** Neon Cyan (`#00FFFF`) 색상의 텍스트와 숫자가 초당 수백 개의 속도로 좌우로 흐르는 모습 (Matrix 코드 형태가 아닌, 정밀한 데이터 패킷 전송 느낌).
3.  **오류 발생 지점 (Accent):** 스트림 중간에 `[ERROR: DATA_INTEGRITY_FAIL]`과 같은 경고 코드가 붉은색(Deep Red `#FF0000`)으로 오버레이됩니다. 이 에러 코드 주변의 데이터 흐름만 일시적으로 왜곡(Glitch)되거나 정지합니다.
4.  **애니메이션 로직:**
    *   **흐름 속도:** 90%의 시간은 빠르고 규칙적입니다.
    *   **문제 발생 시:** 특정 패턴(예: `[PROTOCOL_XYZ]`)이 감지되면, 흐르는 데이터 스트림 전체가 순간적으로 **패턴화된 노이즈와 함께 정체**하며, 해당 코드 주변만 붉고 불안정한 깜빡임(Flicker)을 보입니다.
**[기술적 요구사항]** : 모든 데이터는 가독성이 있지만, 오류 코드는 고의로 의미를 알 수 없는 전문 약어 조합으로 구성되어야 합니다.

### 🧬 에셋 2: 구조적 결함 시각화 (The Structural Defect Visualizer)
문제점을 단순히 '오류'라고 말하는 것을 넘어, 시스템의 근본적인 설계 결함을 보여줍니다. 가장 강력한 권위감을 부여합니다.

**[상징하는 것]** : 시스템의 물리적/논리적 기반 붕괴 / 구조적 무력감.
**[활용 시점]** : 스크립트 중반부 (1:25 - 2:30) '불안감 증폭' 단계.
**[비주얼 구성 요소]**
1.  **기본 패턴:** 완벽하게 정렬된 기하학적 격자(Lattice Grid) 또는 복잡한 파동 그래프(Waveform Graph)를 화면 중앙에 배치합니다. (완벽함의 상징).
2.  **결함 발생:** 시간 경과와 함께, 이 완벽한 패턴에서 **눈에 보이지 않는 '균열선(Fault Line)'**을 따라 픽셀이 분리되거나 파동 그래프가 급격하게 왜곡되는 애니메이션이 시작됩니다.
3.  **시각화 로직:**
    *   **1단계 (미세):** 패턴의 일부 점들이 미묘하게 떨리거나(Jitter) 색상 채널에 노이즈가 끼어듭니다 (Cyan/Magenta 분리).
    *   **2단계 (진행):** 균열선이 가시화되며, 이 선을 중심으로 픽셀 간격과 강도가 비정상적으로 변합니다. 마치 고해상도 현미경으로 본 '파괴된 물질'처럼 보이게 합니다.
    *   **3단계 (위협 최대):** 결함 부위의 배경이 깊은 Black Hole 같은 블랙으로 흡수되거나, 시스템 전체가 일시적으로 빨간색 경고 플래시로 뒤덮입니다.
**[기술적 요구사항]** : 이 에셋은 '패턴'과 '파괴'라는 명확한 대비를 통해 시각적 충격을 극대화해야 합니다.

### 💻 에셋 3: 진단 프로토콜 UI (The Diagnostic Protocol Interface)
유료 서비스(CTA)로의 전환을 위한 최종 게이트웨이입니다. 이 인터페이스는 '진단을 거부할 수 없게' 만듭니다.

**[상징하는 것]** : 전문적인 해결책 / 유일한 진단 경로.
**[활용 시점]** : 스크립트 후반부 (2:30 이후) CTA 직전.
**[비주얼 구성 요소]**
1.  **화면 구조:** 전형적인 관제실(Control Room) 대시보드 형태를 취합니다. 여러 개의 데이터 패널과 그래프가 배치됩니다. (Glassmorphism 컨셉 적용).
2.  **핵심 애니메이션: 스캔 라인 (The Scan Line):** 화면 전체를 가로지르는 초록색/Cyan의 고속 스캐닝 레이저(Scan Line)가 쉴 새 없이 지나갑니다. 이 스캐너는 시스템을 '검사'하는 듯한 느낌을 주어 전문성을 극대화합니다.
3.  **결과 표시:** 스캔 라인이 통과할 때마다, 특정 데이터 영역에 **[ANOMALY DETECTED: Protocol ID 74B]** 와 같이 구체적인 코드가 오버레이됩니다. (이것이 무료 진단으로 발견한 '증거'입니다.)
4.  **CTA 버튼:** 화면 하단에는 마치 시스템이 강제하는 듯한, 크고 명료하며 **`[Diagnostic Protocol Initiate]`** 문구가 적힌 버튼이 배치되어야 합니다. 이 버튼은 다른 모든 요소보다 더 높은 대비와 애니메이션(예: 지속적인 전력 충전 효과)을 가져야 합니다.
