**타겟 불안감:** 돈과 미래에 대한 통제력 상실, 남들보다 뒤처진다는 전문적 위기감.
**길이:** 45~60초 (숏폼 기준)

| 구성 | 시간 코드 | 내레이션 / 스크립트 | 비주얼/사운드 지시문 (System Alert Protocol v2.0 적용) |

### 🎬 스크립트 2: 데이터 알고리즘 편 (The Filter Bubble Trap)

**주제:** 인공지능과 검색 엔진이 만드는 '개인화된 환상' 속의 지식적 결핍 진단
**타겟 불안감:** 자신이 세상을 객관적으로 이해하고 있다는 믿음의 붕괴, 정보 접근권에 대한 위기감.
**길이:** 40~55초 (숏폼 기준)

| 구성 | 시간 코드 | 내레이션 / 스크립트 | 비주얼/사운드 지시문 (System Alert Protocol v2.0 적용) |
| :--- | :--- | :--- | :--- |
| **[🔴 HOOK] 패러다임 전환** | **0-5초** | (빠르고, 의심하는 듯한 톤) "당신이 오늘 본 정보는... 당신에게 가장 *안전하도록* 설계된 진실일 뿐입니다. 객관적 사실이 아닙니다." | 스마트폰 화면을 클로즈업하며, 일반적인 뉴스 기사들이 지나가다가 갑자기 네온 빛의 오류 코드가 덮어씌워지는 효과 (Visual Glitch). **사운드:** 시스템 부팅음과 함께 급격한 노이즈 사운드 발생. |
| **[🟡 문제 정의] 불안감 증폭** | 5-25초 | 우리는 '필터 버블(Filter Bubble)'이라는 완벽하게 통제된 환경에 살고 있습니다. 당신의 검색 기록, 시청 이력이 알고리즘에 의해 재단되어 들어옵니다. 이 과정에서 **정보적 사각지대**가 생기고, 근본적인 질문 자체가 사라지는 치명적 오류가 발생합니다. | 수많은 정보 조각(데이터 파편)들이 지나가다가 특정 경로로만 좁혀지는 애니메이션 (터널링 효과). 중앙에 'Algorithmic Bias'라는 전문 용어가 깜빡이며 경고 표시됨. |
| **[🟢 CTA] 진단권 유도** | 25-55초 | 스스로의 인식 구조를 객관적으로 평가할 방법이 없습니다. 어떤 정보가 당신에게 의도적으로 가려지고 있는지, 그 '정보 흐름 오류'를 전문적으로진단해야 합니다. 저희는 단순한 정보 습득을 넘어, 당신의 지적 시스템 자체에 결함을 진단합니다. 지금 바로 **[지식 구조 정밀진단 리포트]**를 요청하여, 진짜 세상을 보세요. | 화면 전체가 데이터 분석 UI처럼 변하며 복잡한 그래프들이 나타남. 최종적으로 'Diagnostic Protocol'라는 단어와 함께 명확하고 신뢰감 있는 Cyan 톤의 CTA 박스가 전면 배치됨. **사운드:** 긴장감이 해소되면서 지적 만족감을 주는 사운드로 마무리. |

### 🎬 스크립트 3: 바이오-시스템 오류편 (The Silent Decay)

**주제:** 만성 피로와 건강 문제를 '개인의 노력 부족'으로 치부하는 현대 의학의 한계 진단
**타겟 불안감:** 자신의 몸에 문제가 있다는 막연한 느낌을 과학적이고 구체적인 시스템 결함으로 인식시키기. (가장 공포스럽고 긴급하게 느껴지는 영역).
**길이:** 50~65초 (숏폼 기준)

| 구성 | 시간 코드 | 내레이션 / 스크립트 | 비주얼/사운드 지시문 (System Alert Protocol v2.0 적용) |
| :--- | :--- | :--- | :--- |
| **[🔴 HOOK] 패러다임 전환** | **0-7초** | (공감하는 척하다가 갑자기 차갑게 변조된 목소리) "혹시 만성 피로를 '나태함' 때문이라고 자책하셨습니까? 아닙니다. 그것은 당신의 의지가 아닌, 몸이라는 시스템 자체에 발생한 **[미토콘드리아 기능 저하]**라는 치명적인 오류입니다." | 사람의 신체 내부 단면을 묘사하는 고화질 시뮬레이션 영상 (Sci-Fi 메디컬 느낌). 정상 작동하던 세포가 느리게 깜빡이며 어두워지는 애니메이션. **사운드:** 불안정한 심박동 소리와 함께 경고음이 반복됨. |
| **[🟡 문제 정의] 불안감 증폭** | 7-30초 | 단순히 잠을 더 자거나 운동을 하면 해결되지 않습니다. 문제는 체내의 '만성 염증 마커(Chronic Inflammation Marker)'가 과부하를 일으키며, 핵심 에너지원인 미토콘드리아의 효율성이 점진적으로 떨어지는 **시스템적 퇴행**에 있습니다. 이 오류는 증상으로만 나타날 뿐, 본질을 파악하기 어렵습니다. | 인체 내부 시스템도가 복잡하게 표시됨. 특정 기관(예: 간, 뇌) 주변에서 염증 반응을 상징하는 빨간색 데이터가 새어 나오는 애니메이션 (`[SYSTEM_OVERLOAD]`). '데이터 드리프트'를 생물학적 관점으로 치환하여 설명. |
| **[🟢 CTA] 진단권 유도** | 30-65초 | 일반적인 검진은 표면의 수치만 읽을 뿐, 시스템 깊숙한 곳에 자리 잡은 근본 원인을 포착하지 못합니다. 당신에게 필요한 것은 단순 치료가 아닌, 전신 시스템의 작동 메커니즘을 재설정하는 **전문 진단 프로토콜**입니다. 지금 바로 '메타볼릭 밸런스 체크'를 통해, 몸의 오류 코드를 확인하고 근본적인 해결책에 접근하십시오. | 의료 장비나 데이터 분석 UI가 전면에 등장하며 복잡한 수치들을 읽어내는 듯한 효과. 최종적으로 'Diagnostic Right'라는 개념이 강조되며 구매 버튼이 깜빡임. **사운드:** 신뢰감을 주는 톤으로 전환, 의학적 권위를 보여주는 사운드로 마무리. |
