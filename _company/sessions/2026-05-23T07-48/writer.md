# [최종 배포 스크립트] 시스템 오류 경고 (Root Cause 기반)

**✅ 목표:** 50초 쇼츠 영상 스크립트 확정 및 연출 가이드라인 제공.
**👤 담당:** Voice Over / Visual Director
**🛠️ 버전:** v3.0 - Root Cause 통합
---
## 🎥 시나리오 상세 (Timeline & Script)

### [0-3초] HOOK: 패러다임 전환
*   **내레이션:** (속삭이듯, 긴장감 있게) 잠깐만요. 지금 이 영상을 보고 계시다면... 당신의 시스템에 뭔가 '이상'하다는 뜻입니다. 단순한 고장이 아닙니다.
*   **비주얼:** 화면 암전 $\rightarrow$ 빨간색/Cyan 깜빡이는 오류 코드 오버레이 (`[CRITICAL_FAILURE]`). 차량 계기판 클로즈업, 경고등이 여러 개 동시에 켜짐.
*   **사운드:** **Deep Boom 임팩트 사운드.** BPM 급상승 시작.

### [3-12초] Root Cause 1: 시간 코드 불일치 (Temporal Gap)
*   **내레이션:** 가장 흔한 실수? '시간의 공백'입니다. 시스템은 A 지점에서 B 지점으로 논리적으로 연결되어야 하는데, 이 중간에... *공백*이 생기면 어떻게 될까요?
*   **비주얼:** 복잡한 데이터 플로우 다이어그램 등장. 정상 흐름(A $\rightarrow$ B)이 빨간색 '단절점'으로 끊어짐. 시각적 공백 구간을 보여주며 붉은 경고 깜빡임.

### [12-23초] Root Cause 2: 데이터 드리프트 (Data Drift)
*   **내레이션:** 더 치명한 건 눈에 보이지 않습니다. 시간이 지날수록 패턴이 변하는 '데이터 드리프트'. 시스템은 정상이라고 착각하지만, 이미 핵심 데이터가 미세하게 왜곡되고 있습니다.
*   **비주얼:** 그래프 형태의 추이 분석 차트. 한 선(Line)이 점진적으로 다른 방향으로 휘어짐 (Data Drift 시각화). 배경에 녹슨 금속 질감 효과 추가.

### [23-35초] Root Cause 3: 상태 전이 오류 (State Transition Failure)
*   **내레이션:** 그리고 가장 위험합니다. '상태 전이(State Transition)' 실패. 시스템은 A에서 B로 넘어가야 하는데, 중간 단계가 아예 누락된 겁니다. 논리적 사각지대!
*   **비주얼:** 복잡한 기계 장치 내부 회로도. 특정 연결 부위(Transition Zone)에 스파크가 튀고 연기가 나는 VFX 처리. 빨간색 경고 문구: `[TRANSITION FAILURE]` 강조.

### [35-45초] Climax & 진단 제시
*   **내레이션:** 이 세 가지 오류는 일반 점검으로는 절대 발견할 수 없습니다. 당신의 시스템적 결함을 찾아내려면, 전문가가 직접 구조를 재조명해야 합니다.
*   **비주얼:** 화면이 갑자기 정리되면서 Clean Cyan 톤의 UI(진단 보고서 형태)가 나타남. 오류 코드가 체계적인 JSON 포맷으로 변환되는 애니메이션 효과.

### [45-50초] CTA: 행동 유도 (판매 전환)
*   **내레이션:** 단순 점검으로는 안 됩니다. 저희가 수립한 전문 '진단 프로토콜'을 통해, 당신 시스템의 근본적인 오류 코드를 찾아내세요. 지금 바로 [Anomaly 진단 체크리스트]를 받고, 다음 단계로 나아가십시오!
*   **비주얼:** 3가지 티어 패키지 정보가 명확하게 분할되어 표시됨. 구매 버튼 깜빡임 애니메이션 효과.
