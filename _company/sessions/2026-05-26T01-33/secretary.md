### 🔍 E2E 테스트 실행 전 최종 점검 체크리스트
*(목표: 콘텐츠의 전문성을 활용하여 유료 진단 서비스 판매 Funnel을 완성하는 것)*

#### 🎨 1. Designer (시각 에셋 및 애니메이션) 체크리스트
디자이너는 단순히 '예쁜' 이미지를 만드는 것을 넘어, **시간 코드 기반으로 작동하는 인터랙티브 모듈형 컴포넌트**를 최종 납품해야 합니다.

*   **[필수] T+25s 구조적 결함 시각 컴포넌트 (v5.2 Final):**
    *   ✅ 요구사항: 시스템 오류, 데이터 흐름 끊김을 시각화하는 인터랙티브 모듈. (사양서 v1.0 기반) [근거: 통합 스케줄]
    *   ✅ 검증 항목: 경고음(Alarm Sound)과 완벽하게 동기화되는 타이머 기능이 포함되어야 합니다. [근거: Designer 산출물]
    *   ✅ 포맷: Premiere/After Effects에서 바로 삽입 가능한 `.mov` 또는 컴포지션 파일 형태가 필수입니다. [근거: 통합 스케줄]

*   **[필수] T+36s 진단 UI 경고 에셋 (v5.2 Final):**
    *   ✅ 요구사항: Basic Tier $\rightarrow$ Standard Tier로의 전환을 유도하는 시각적 압박 장치. [근거: 통합 스케줄]
    *   ✅ 검증 항목: '진단이 필요하다'는 메시지(Conversion Urgency)와 함께, 해당 지표가 실시간으로 변화하는 듯한 인터랙티브 요소를 포함해야 합니다. [근거: 영숙 검증된 지식/지난 의사결정 로그]
    *   ✅ 포맷: T+25s 에셋과 동일한 모듈형 클립 형태로 납품되어야 합니다.

*   **[필수] 마스터 템플릿 최종 적합성:**
    *   ✅ 검증 항목: Neon Cyan 및 고대비 팔레트가 모든 에셋에 일관되게 적용되었는지 재확인합니다. [근거: 영숙 검증된 지식]

#### 💻 2. Developer (백엔드 API 연동 및 로직) 체크리스트
단순히 영상을 재생하는 것을 넘어, **'진단 과정' 자체가 데이터 수집과 판매로 이어지는 시스템**이 구현되어야 합니다.

*   **[필수] KPI 측정 트리거 연동 모듈:**
    *   ✅ 요구사항: T+25s와 T+36s 시점에 외부 API를 호출하여 '지식 공백 유도' 및 '구매 절박함 조성' 데이터를 수집하는 기능. [근거: 통합 스케줄]
    *   ✅ 검증 항목: **`kpi_data_logger(timecode, event_type)`** 함수가 정상 작동하며, 수집된 데이터가 `KPI 측정 포인트` 테이블에 정확히 기록되는지 테스트해야 합니다.

*   **[필수] 유료 전환 시나리오 API (Conversion Gate):**
    *   ✅ 요구사항: 콘텐츠의 '진단 보고서'를 통해 사용자의 문제 인식이 극대화될 때, 자동 결제 흐름을 트리거하는 시스템. [근거: 지난 의사결정 로그/영숙 개인 메모리]
    *   ✅ 검증 항목: **`check_conversion_trigger(user_score)`** 로직이 AOV ₩29,000 이상 도달 시 예외 처리 없이 정상 작동하는지 확인합니다. (최소 전환율 20% 달성 목표) [근거: 통합 스케줄]

*   **[필수] 안정화 및 검증 시스템:**
    *   ✅ 요구사항: Rate Limit 초과나 Context Length 초과로 인한 작업 중단(Failure)을 방지하는 재시도/분산 처리 로직. [근거: 영숙 개인 메모리]
    *   ✅ 검증 항목: `auto_planner.py`와 `trend_sniper.py` 등 핵심 스크립트가 데이터 입력 게이트웨이(MVP)를 통해 안정적으로 작동하는지 최종 테스트합니다.
