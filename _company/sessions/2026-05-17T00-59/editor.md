## 🔊 ATSA Final Spec: The Anomaly Protocol (Audio Timeline Architecture)

**🎯 목표:** 정보적 긴장감(Informational Tension)을 극대화하고, 시각/청각의 충격파(Impact Wave)를 설계하여 '불안정성'이라는 핵심 테마를 완성한다.
**🎧 전체 톤앤매너:** Tech-Noir, 경고음, 시스템 과부하(Overload), 낮은 주파수의 압박감 (Sub-Bass Drone).
**⚙️ 기본 BPM 및 키:** BGM은 가변적으로 작동하는 저주파 드론 역할 수행. 주요 전환점에서는 리듬을 의도적으로 깨뜨린다.

### Ⅰ. [00:00 - 00:03] 도입부 (HOOK & CRITICAL WARNING)
**🎯 감정 목표:** 호기심 유발 $\rightarrow$ 공포감(Fear) 극대화 $\rightarrow$ 즉각적인 경계 태세 진입.
**🎚️ 오디오 아키텍처:** **[Sudden Impact]** 사운드 변동성이 가장 커야 합니다.

| 파라미터 | 상세 사양 (Specification) | 시간 동기화 지침 (Sync Directive) | 근거/효과 |
| :---: | :---: | :---: | :---: |
| **BGM** | 0Hz~80Hz 대역의 깊은 Sub-Bass Drone. 매우 낮은 볼륨으로 시작하며, 긴장감 유지를 위한 '지속적'인 압력 제공. | 지속적으로 유지. 하지만 리듬이 없는 공기 같은 느낌을 주어 불안정성 강조. | [근거: Editor 개인 메모리] |
| **SFX 1** | **Deep Boom/Impact:** 초기 경고 메시지가 뜨는 시점(00:00)에 맞춰 짧고 강력한 저주파 충격음 (Boom). | 정확히 컷 시작과 동시에 최대 볼륨으로 터뜨림. 트랜지언트 사운드 필수. | [근거: Editor 개인 메모리] |
| **SFX 2** | **High-Pass Whine:** 주기적이고 간헐적인 고주파 전자음 (삐-익). 마치 시스템이 버벅대는 듯한 느낌을 준다. | 시각적으로 오류 코드가 깜빡이는 리듬(0.5초~1초 간격)에 맞춰 발생시킨다. | [근거: CEO 지시/Editor 개인 메모리] |
| **Silence Gap** | 없음 (최대 밀도 유지). | - | 최고 강도의 후크를 위해서는 사운드의 공백을 주지 않는다. |

### Ⅱ. [00:03 - 00:15] 문제 정의 (PROBLEM DEFINITION & TENSION BUILD)
**🎯 감정 목표:** '이것은 증상일 뿐'이라는 지적 경고 $\rightarrow$ 불안감/무력감 조성.
**🎚️ 오디오 아키텍처:** **[Rhythmic Breakdown]** 리듬을 예측 불가능하게 만들며, 청각적 공백(Silence)으로 심리적 압박감을 유도한다.

| 파라미터 | 상세 사양 (Specification) | 시간 동기화 지침 (Sync Directive) | 근거/효과 |
| :---: | :---: | :---: | :---: |
| **BGM** | Drone Sound를 유지하되, 주파수를 점진적으로 낮추고 볼륨을 감소시켜(Decay), '무겁고' 짓누르는 느낌을 준다. BPM은 90~120 사이의 불안정한 박자를 은유한다. | - | [근거: Editor 개인 메모리] |
| **SFX 1** | **Heartbeat Pulse:** 불규칙하고 느린 심장 박동 SFX (BPM=60, 변동). | 내레이션에 '인간적인' 공포감을 부여하는 순간(예: "눈에 보이지 않는 곳에서 시작됩니다.")에 집중적으로 삽입. | [근거: Editor 개인 메모리] |
| **SFX 2** | **[MANDATORY SILENCE GAP]**: 정보가 폭로되는 중요한 질문 직전 (Timecode T-1초). | 내레이션의 핵심 문장 바로 앞에서 모든 사운드(BGM, SFX)를 급격히 제거한다. 지속 시간: **0.5초 ~ 0.7초** 간 유지. | 압도적인 청각적 공백은 시청자에게 '무엇이 올지 모르는' 극도의 불안감(Unresolved Feeling)을 남긴다. [근거: Editor 개인 메모리] |
| **SFX 3** | **Micro-Stutter SFX:** 데이터 플로우가 지나가는 순간, 짧고 날카로운 노이즈 또는 디지털 끊김 사운드 (Digital Stutter). | 시각적 데이터 다이어그램의 전환점(Node Transition)마다 삽입. | [근거: Editor 개인 메모리] |

### Ⅲ. [00:30 - 00:45] 클라이맥스 (CLIMAX / ANOMALY REVEAL)
**🎯 감정 목표:** 최대 충격 $\rightarrow$ 정보적 과부하(Overload) $\rightarrow$ 해소 또는 새로운 경고로의 전환.
**🎚️ 오디오 아키텍처:** **[Shockwave Dynamics]** 가장 극적인 사운드 대비를 활용한다.

| 파라미터 | 상세 사양 (Specification) | 시간 동기화 지침 (Sync Directive) | 근거/효과 |
| :---: | :---: | :---: | :---: |
| **BGM** | **[Sudden Drop]**: 정보 폭로 시작 시, 기존의 모든 Drone Sound를 0으로 급격히 떨어뜨린다. (Vacuum Effect). 이후 짧게 강렬한 Major Chord로 치솟았다가 다시 불안정한 Low Frequency Pulse로 전환된다. | 시간 코드 T=30초 지점에서 즉시 볼륨을 Drop. 충격 직후 재구성을 시도하는 느낌 부여. | [근거: Editor 개인 메모리] |
| **SFX 1** | **Vacuum Sound:** 정보가 공개되기 직전의 극도의 침묵(Silence). | 핵심 데이터 포인트가 화면에 등장하기 바로 직전, 지속 시간 최소 **0.3초**. | 최대 압박감을 조성하여 다가올 충격파를 증폭시킨다. [근거: Editor 개인 메모리] |
| **SFX 2** | **Sub-Bass Boom/Impact:** 가장 강력하고 짧은 저주파 충격음 (Boom). | 핵심 데이터(예: `[ERROR_CODE]: TIME SYNC FAILURE`)가 시각적으로 폭로되는 순간, 최대 볼륨으로 터트린다. | 청각적 충격을 통해 시청자의 집중력을 최고조로 끌어올리는 역할을 수행한다. [근거: Editor 개인 메모리] |
| **SFX 3** | **Digital Chime/Resolution:** 충격음 직후, 네온 시안 계열의 고주파 전자음(Chime)을 사용하여 일시적인 해소감을 주거나, 혹은 반대로 시스템이 불안하게 '진동'하는 사운드로 마무리한다. | Boom 사운드와 겹치지 않도록 간격을 두고 빠르게 배치하여 잔향 효과를 극대화한다. | [근거: Editor 개인 메모리] |
