# 🎬 Anomaly Loop 비주얼 시스템 최종 실행 계획 (Designer)

**목표:** Writer가 제공할 스크립트 및 지침에 맞춰, 'Anomaly Loop' 원칙을 적용한 고해상도 텍스트 오버레이 및 핵심 비주얼 에셋 제작 착수.

## 1. 비주얼 시스템 정의 (Visual System Definition)
*   **톤:** 어둠의 고대비 (Dark Contrast), 심리적 불안감 극대화 (Psychological Tension).
*   **핵심 컬러:** Neon Cyan (`#00FFFF`), Deep Black (`#000000`).
*   **보조 컬러:** Tension Accent (`#FF00FF`).
*   **타이포그래피:** 산세리프체 기반, 고대비 스트로크/네온 효과 적용.

## 2. 핵심 에셋 상세 지침 (Core Asset Specifications)

### A. 시스템 오류 경고 템플릿 (System Error Alert Template)
*   **목적:** 영상 도입부 및 전환 시 사용되는 강력한 충격 효과.
*   **스타일:** 네온 시안 테두리를 중심으로, 중앙에 크고 두꺼운 'ERROR' 텍스트 배치. 배경은 미세한 노이즈/글리치 패턴으로 채움.
*   **적용 위치:** 영상 시작 3초 내 몰입도 극대화 구간.

### B. 배경 패턴 (Background Pattern - Data Stream)
*   **목적:** 영상 전체의 분위기를 유지하는 지속적인 시각적 요소.
*   **스타일:** 어두운 배경 위에 네온 시안 색상의 매우 얇고 빠르게 흐르는 데이터 스트림 또는 코드 라인 패턴 적용. 움직임(Motion)을 강조하여 역동성 부여.

### C. 최종 진단 체크리스트 (Final Diagnosis Checklist - PDF Layout Guide)
*   **목적:** 최종 결과물 다운로드 시 사용될 전문적인 리포트 디자인.
*   **스타일:** 하이테크 도시 통제실(Control Room) UI 모티브. 네온 시안/블랙의 대비를 활용하여 정보의 신뢰도를 높임. (PDF 형식으로 내보내기 준비)

## 3. 후속 작업 지시 (Next Steps for Execution)
*   Writer가 제공할 **최종 스크립트**와 **Anomaly Loop 지침**을 기반으로, 상기 세 가지 에셋에 대한 구체적인 레이아웃 좌표 및 폰트/색상 코드를 확정하여 최종 디자인 파일을 생성합니다.
