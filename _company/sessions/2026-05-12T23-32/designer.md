# 💎 마스터 비주얼 시스템 최종 확정: Neon Cyan & High Contrast Framework

이 프레임워크는 모든 콘텐츠, 랜딩 페이지, 대시보드에 일관되게 적용되어야 하는 핵심 규칙과 디자인 토큰을 정의합니다.

## 1. 브랜드 컬러 및 대비 시스템 (The Core System)

핵심은 **고대비(High Contrast)**와 **네온 시안(Neon Cyan)**의 명확한 분리입니다. 이는 시청자에게 즉각적인 정보 전달력과 기술적 권위를 부여합니다.

| 요소 | 역할 | 색상 코드 (Hex) | 설명 및 용도 |
| :--- | :--- | :--- | :--- |
| **Primary Accent (Neon Cyan)** | 핵심 데이터, CTA, 강조선 | `#00FFFF` | 시스템 안정성 지표(KPI), 핵심 결과 값, 활성화된 상태 표시. 시각적 긴장감 유도. |
| **Background (Dark Mode Base)** | 주 배경색 | `#0A0A14` | 깊은 어둠을 표현하여 네온 색상의 대비 효과를 극대화하고 몰입감을 제공합니다. |
| **Primary Text/Elements** | 기본 텍스트, 주요 레이블 | `#FFFFFF` | 높은 가독성을 위해 순백색을 사용하며, 배경과의 대비를 최대화합니다. |
| **Secondary Contrast (Warning)** | 위험 지표, 경고 메시지 | `#FF007F` | 불안정성(Risk)이나 심각한 결함을 시각적으로 강조하는 데 사용됩니다. 네온 시안과 가장 강한 대비를 이룹니다. |
| **Neutral/Subtle** | 보조 배경, 구분선 | `#1A1A2E` | 메인 배경보다 약간 밝은 톤으로 깊이를 주어 Glassmorphism 효과의 기반이 됩니다. |

## 2. 타이포그래피 시스템 (Typography System)

긴장감과 기술적 정확성을 동시에 전달하는 산세리프체(Sans-serif)를 사용합니다.

| 요소 | 역할 | 폰트 명 (Family) | 스타일링 규칙 |
| :--- | :--- | :--- | :--- |
| **Headline/KPI** | 핵심 수치, 제목 | `Inter` 또는 `Orbitron` (강력 추천) | **굵게(Bold)**, 네온 시안(`#00FFFF`) 적용. 크기는 상대적으로 크게 설정하여 강조합니다. |
| **Body Text** | 설명, 상세 내용 | `Roboto Mono` 또는 `Space Mono` | 고정폭(Monospace) 폰트를 사용하여 코드나 데이터의 정확성을 표현하며 가독성을 확보합니다. |
| **System Labels** | 레이블, 범례 | `Inter` (Regular) | 흰색(`FFFFFF`)으로 설정하고, `Neutral/Subtle` 배경 위에 배치하여 시각적 계층을 만듭니다. |

## 3. 비주얼 시스템 프레임워크 (Visual System Framework)

모든 디자인 에셋(썸네일, 랜딩 페이지, 대시보드)에 적용될 레이아웃 원칙입니다.

### A. 썸네일 컨셉 표준화 (Thumbnail Concept Standardization)

**목표:** 기술적 신뢰성 + 심리적 불안감 극대화.

| 컨셉 | 핵심 레이아웃 원칙 | 색상 적용 규칙 |
| :--- | :--- | :--- |
| **Concept 1: The Anomaly Loop (불안정성 강조)** | 중앙에 가장 중요한 KPI(예: TSD, ACS)를 거대하게 배치. 배경은 어둡게 처리하고, KPI 주변에 `Secondary Contrast`(`FF007F`)의 미세한 깜박임 효과를 적용하여 불안감을 조성합니다. | Background: `#0A0A14`. KPI 강조: `#00FFFF`. |
| **Concept 2: The Command Center (권위 강조)** | 중앙에 시스템 다이어그램(와이어프레임의 핵심 요소)을 Glassmorphism 카드 형태로 배치. 전체적인 레이아웃은 대칭적이며, 네온 시안 테두리로 프레임을 정의합니다. | Background: `#1A1A2E` (Glassmorphism). 강조선: `#00FFFF`. |
| **Concept 3: The Sprint Result (결과 강조)** | 왼쪽에는 러너(인물)의 클로즈업을 배치하고, 오른쪽에는 측정된 데이터 시각화 영역을 대비시켜 배치합니다. 속도감 있는 대각선 구도를 활용합니다. | 대비 극대화. 텍스트는 `Roboto Mono`를 사용하여 데이터 느낌 강조. |

### B. 랜딩 페이지/대시보드 구조 (Landing Page / Dashboard Structure)

**목표:** 사용자가 시스템의 '내부'에 접속한 듯한 몰입감 제공.

1.  **Navigation Bar:** 배경은 완전히 어두운 색(`Background: #0A0A14`). 네비게이션 아이콘과 텍스트는 `Neon Cyan`으로 처리하여 시선을 즉시 유도합니다.
2.  **Data Visualization Area (핵심):** 모든 실시간 데이터(KPIs)는 **Glassmorphism 카드** 형태로 구현됩니다.
    *   카드 배경: `Neutral/Subtle` (`#1A1A2E`).
    *   테두리: 얇고 선명한 `Neon Cyan`(`#00FFFF`)으로 설정하여, 데이터가 빛나는 듯한 효과를 연출합니다.
3.  **Action Buttons (CTA):** 가장 중요한 CTA 버튼은 `Primary Accent` 색상(`Neon Cyan`)을 채우고, 마우스 오버 시 미세하게 밝아지는 애니메이션(Glow Effect)을 적용하여 클릭 유도를 극대화합니다.

## 4. 최종 비주얼 가이드라인 요약 (Design Guideline Summary)

**핵심 원칙:** **기술적 불안정성 (KPI) $\rightarrow$ 시각적 긴장감 (Neon Cyan) $\rightarrow$ 신뢰 기반의 행동 유도 (CTA)**

1.  **색상 사용:** `Neon Cyan`은 '정보'와 '시스템 활성화'를, `Secondary Contrast`는 '위험/문제'를 나타내는 용도로만 제한적으로 사용합니다.
2.  **레이아웃:** 모든 주요 정보 블록은 **Glassmorphism 카드** 안에 담아 시각적 깊이와 기술적 권위를 동시에 확보합니다.
3.  **폰트 활용:** 데이터와 코드의 정확성을 위해 `Roboto Mono`를 주력으로 사용하고, 제목에는 `Inter/Orbitron`을 사용하여 대비 효과를 극대화합니다.
