# 🛠️ Anomaly Loop: 프로덕션 & 배포 마스터 플랜 (Master Timeline)

**📌 핵심 목표:** 시청자에게 '미세한 데이터 누출'의 공포를 심어주고, 오직 유료 진단 보고서(Standard Report)만이 해결책임을 인지시키는 것.
**🎬 포맷:** 9:16 세로형 (숏폼 최적화). 전체 길이 목표: 45~60초.

## ⚙️ Part 2. KPI 기반 최종 검증 체크리스트 (Pre-Publishing QA)

업로드 직전, 다음 세 가지 비즈니스 목표(KPI) 달성 여부를 반드시 점검해야 합니다. 이것이 단순 영상 제작 과정에서 가장 중요한 단계입니다.

✅ **1. Hook Impact Check (도입부 3초 이탈률 < 5% 검증)**
*   [ ] 사운드 동기화: 도입부 3초 내에 배경음악의 볼륨 변화와 충격 SFX가 완벽하게 일치하는가?
*   [ ] 시각적 자극: 첫 프레임에서 빨간색/Cyan 경고 코드가 너무 빠르게 지나가지 않고, 시청자가 '멈춰서 읽을 만한' 충분한 시간을 제공하는가?
*   [ ] 내러티브 질문: 3초 시점에 던지는 질문이 '개인의 불안감(나에게 무슨 문제가 있을까?)'에 직접적으로 호소하는가?

✅ **2. CTA Clarity Check (Standard Report 클릭률 > 15% 검증)**
*   [ ] 논리적 연결고리: 클라이맥스([16-30초])에서 느낀 불안감과, 해결책(Report)의 필요성이 끊어짐 없이 매끄럽게 이어지는가? (단순히 상품을 보여주는 것이 아님).
*   [ ] 시각적 강조: 보고서 Mockup이 등장할 때, '권위'와 '전문성'이 느껴지도록 비주얼 디자인 요소(예: 데이터 그래프의 복잡도)를 최대치로 끌어올렸는가?
*   [ ] 앵커링 문구 반복: "더 자세한 분석이 필요합니다", "진단 보고서" 등의 핵심 키워드가 최소 3회 이상, 다른 방식으로 노출되는가?

✅ **3. SEO & Distribution Check (검색 유입 및 재반복율 검증)**
*   [ ] 제목/썸네일 일치성: 최종 확정된 제목과 썸네일의 콘셉트(질문형/충격)가 영상 내용 전체를 대표하고 있는가? (너무 넓은 주제로 포괄하지 않도록 주의).
*   [ ] Description SEO: 설명란 상위 3줄에 "데이터 오류", "시스템 점검", "하이브리드 배터리 진단" 등 핵심 키워드를 자연스럽게 포함했는가?
*   [ ] Loop 완성도: 마지막 프레임의 시각적/내러티브 연결이 첫 프레임과 유사하여, 시청자가 무의식적으로 영상을 처음부터 다시 보게 만드는 구조를 갖추었는가?
