### 🎬 최종 영상 내러티브 스크립트: Anomaly Loop (60초 기준)
**테마:** 시스템의 구조적 실패와 지식 만료화
**톤앤매너:** 테크 느와르, 긴장감 넘치는 경고(Urgent Authority), 전문가적 공포
**KPI 목표:** 시청자가 '미니 진단 데이터 누출'에 놀라 Standard Report 구매를 고려하게 만들기.

| Time Code | 감정 곡선 (Tension) | 내레이션 (Script - 속삭이듯, 단호하게) | 비주얼 지침 (Visual Direction - Designer 필수 반영) |
| :---: | :---: | :--- | :--- |
| **[0-3초] HOOK: 패러다임 전환** | 🔴 급상승 (Shock/Disruption) | 당신의 시스템 경고등을 보고 '어디가 고장 났나?'만 생각하셨나요? 아닙니다. 그것은 원인이 아니라, **시스템이 지금 보여주는 증상일 뿐입니다.** | 화면 암전 $\rightarrow$ 빨간색/Cyan 깜빡이는 오류 코드 오버레이 (`[CRITICAL_ERROR]`). 차량 계기판에 미지의 문자열(ERROR CODE) 클로즈업 샷. 강한 저음의 임팩트 사운드 (Deep Boom). **텍스트:** WARNING IS NOT THE PROBLEM. |
| **[4-15초] 문제 제기: 불안감 증폭** | 🟠 상승 유지 (Suspense/Doubt) | 우리는 정상 작동하는 시스템을 믿습니다. 하지만 진짜 문제는 눈에 보이지 않습니다. 시간의 흐름, 데이터가 변형되는 '데이터 드리프트'와 같이, 우리 인지 영역 밖에 치명적인 오류들이 이미 진화하고 있습니다. | 복잡한 데이터 플로우 다이어그램이 빠르게 지나감 (하이테크 네온 스타일). 특정 노드(Node)가 깜빡이며 빨간색 경고 표시됨. 자막에 'BMS Data Leakage', 'Data Drift' 등 전문 용어 강조. 배경 음악의 긴장감이 점진적으로 고조됨. |
| **[16-30초] 미니 진단 데이터 누출 (The Leak)** | 🟡 절정 준비 (Compulsion/Curiosity) | 문제는 눈에 보이는 오류가 아닙니다. 더 깊은 곳, 시스템 핵심 로직의 '시간 동기화' 영역에서 발생하는 아주 작은 *비일관성*입니다. **(잠시 정지 - 호흡 조절)** 이 미세한 지점의 데이터 간 격차를 일반 점검으로는 절대로 포착할 수 없습니다. | 화면에 복잡하고 이해하기 어려운 그래프와 숫자가 빠르게 오버레이 됨. 특정 좌표(X, Y)의 값이 아주 미묘하게 벗어나는 순간을 극도로 클로즈업 (Zoom In). **사운드:** 데이터 처리 과정에서 발생하는 기계음 노이즈가 갑자기 끼어들며 청각적 불안감을 유발. |
| **[31-45초] 해결책 제시: 강제성 확보** | 🟢 하강 후 반전 (Authority/Solution) | 이처럼 구조적인 결함은, 오직 시스템 전체를 아우르는 **전문 진단 프로토콜(Diagnostic Protocol)**을 통해서만 포착되고 수치화될 수 있습니다. 지금의 '불편함'으로 치부할 단계가 아닙니다. | 배경의 오류 코드가 일순간 정리되면서 'SOLUTION REQUIRED'라는 단어와 함께 Clean Cyan 톤의 UI가 나타남. 진단 프로세스를 보여주는 듯한 인터페이스 그래픽. **내레이션 톤:** 전문가적 확신과 권위적인 목소리로 전환. |
| **[46-60초] CTA: 행동 유도 (판매)** | ✨ 최고점 (Urgency/Action) | 당신의 시스템 안정성을 확보하려면, 최소한 저희가 수립한 전문 진단 체크리스트를 통해 결함 지점을 확인해야 합니다. 단순 점검은 의미 없습니다. **지금 바로 'Anomaly 진단 프로토콜'을 받아보십시오.** 더 깊고 근본적인 해결책이 필요하다면, 표준 보고서(Standard Report)로 접근할 수 있습니다. | 화면 하단에 세 가지 티어의 패키지 정보가 명확하게 분할되어 표시됨 (Basic / **Standard** / Premium). Standard 버튼이 깜빡이는 애니메이션 효과를 주며 시선 집중 유도. 배경 음악이 단호하고 확신에 찬 톤으로 마무리. |
