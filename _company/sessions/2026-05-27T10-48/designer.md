## ⚙️ 애니메이션 컴포넌트 디자인 브리프 (V1.0)

### 공통 가이드라인
*   **테마:** 시스템 오류 경고(System Alert) 및 데이터 진단(Diagnostic Scan).
*   **주요 컬러 팔레트:**
    *   `Background`: Deep Black (`#0A0A0A`) - 모든 배경. 정보의 깊이와 위협감 조성.
    *   `Primary Accent (Active)`: Neon Cyan (`#00FFFF`) - 활성화된 데이터, 성공적인 진단 요소, 주 UI 텍스트.
    *   `Warning/Error`: Crimson Red (`#CC0000`) - **오직** 'Critical Failure' 메시지 또는 경고가 발생할 때만 극히 제한적으로 사용. (시각적 충격 최대화).
    *   `Neutral`: Muted Gray/Cyan Gradient (`#1A2B3C` ~ `#4D6A85`) - 데이터 흐름이나 배경 그리드에 사용하여 깊이감 부여.
*   **타이포그래피:** `Orbitron` 또는 `Rajdhani` (High Contrast Sans-serif). 모든 텍스트는 미묘한 글리치/스캔라인 필터를 적용하여 시스템 출력물처럼 보이게 처리한다.

### 1. 정보 흐름 차단 / Glitch Effect (The Data Interruption)
**[적용 구간]: T+0:36 ~ T+0:42**
*   **목표:** 시청자가 보고 있는 '정상적인' 정보가 사실은 오류이거나 불완전함을 감각적으로 각인시킨다.
*   **움직임 (Animation Logic):**
    1.  **(Start - T+0:36)** 배경에 표시되던 모든 텍스트 및 데이터 포인트들이 갑자기 미세하게 떨리며(Jitter Effect) 노이즈가 끼인다.
    2.  **(Glitch Protocol):** 특정 단어나 문장 단위로 화면 전체에 가로지르는 **RGB 분해 효과 (Chromatic Aberration)**와 함께 강한 Glitch 효과를 적용한다. 마치 비디오 신호가 깨진 것처럼 보인다.
    3.  **(Blocking):** '데이터 드리프트(Data Drift)'라는 키워드가 지나갈 때, 해당 단어 주변의 정보 흐름이 순간적으로 멈추고 (Freeze Frame), 화면에 **[ERROR: DATA INTEGRITY FAILURE]** 와 같은 Cyan/Red 경고 문구가 오버레이된다.
    4.  **(Duration):** Glitch는 짧게, 불규칙하게(Random Burst) 발생하여 긴장감을 최고조로 끌어올리는 것이 핵심이다.

### 2. 비선형적 데이터 파편화 시각화 (Non-Linear Fragmentation)
**[적용 구간]: T+0:36 ~ T+0:45 (Glitch와 병행)**
*   **목표:** 정보가 너무 방대하고 복잡하여 인간의 인지 능력으로는 절대 따라갈 수 없다는 '무력감'을 시각화한다.
*   **움직임 (Animation Logic):**
    1.  **(Source):** 화면 중앙에 거대한, 그러나 불안정해 보이는 3D 좌표계 그리드(Grid System)가 전개된다. 이 그리드는 정상적인 데이터 구조를 상징한다.
    2.  **(Fragmentation Start - T+0:38):** 스크립트에서 언급되는 'Gap'이나 'Drift'와 관련된 개념이 시각화될 때, 좌표계의 특정 영역(예: 쿼드런트)에 있던 데이터 포인트들이 강한 탄성 애니메이션과 함께 **수많은 작은 파편(Particles)**으로 폭발하듯 흩어진다.
    3.  **(Non-Linear Flow):** 이 파편들은 무작위로 떠다니기보다는, 마치 '시간적 비동기화'가 일어난 것처럼 서로 다른 속도와 방향으로 움직이며 화면을 가득 채운다.
    4.  **(Visualization Detail):** 배경에 낮은 주파수의 **스캐닝 라인(Scanline)**이 끊임없이 지나가면서, 파편들을 필터링하거나 '추적'하는 듯한 느낌을 준다.

### 3. 최종 CTA: 통제실 (Control Room) UI (The Anomaly Diagnostic Protocol)
**[적용 구간]: T+0:45 ~ T+1:00**
*   **목표:** 공포 상태에서 벗어나, '이 문제를 해결할 수 있는 전문적인 방법'이라는 강한 안도감과 함께 행동을 유발한다. (공포 → 해소/행동)
*   **움직임 (Animation Logic):**
    1.  **(Transition - T+0:45):** 혼란스러웠던 모든 데이터와 노이즈가 갑자기 멈추고(Instant Stop), 화면 전체의 색상이 Deep Black에서 미묘하게 어두운 Cyan/Blue 계열로 정화된다. (긴장이 풀리는 듯한 착각 유도).
    2.  **(UI Reveal):** 중앙에 완벽하게 기능하는, 하이테크적인 '진단 인터페이스(Diagnostic Interface)'가 점진적으로 **오버레이 되어 나타난다.** 이 UI는 마치 콘솔 패널처럼 격자무늬와 수많은 작은 LED 라이트들로 구성된다.
    3.  **(CTA Focus):** 가장 중요한 요소인 `Anomaly Diagnostic Protocol` 버튼과 설명 텍스트에만 네온 시안(`Neon Cyan`)의 강한 빛이 집중적으로 깜빡인다(Pulsing Glow). 이 빛은 단순한 강조가 아니라, **'지금 당장 여기를 눌러야 한다'**는 물리적인 압박감을 전달해야 한다.
    4.  **(Interactivity):** 버튼을 누르는 시뮬레이션 과정에서, UI의 주변 데이터 스트림들이 잠시 빨간 경고 신호(Critical Alert)로 깜빡이다가 다시 Cyan 톤으로 돌아오면서 "진단이 시작되었습니다"라는 안도감과 기대감을 동시에 준다.
