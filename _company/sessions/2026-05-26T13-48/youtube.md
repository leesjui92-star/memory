# ⚙️ 통합 마스터 실행 블루프린트 v3.0: 시스템 연결성의 결함 (Interdependency Failure)

**[프로젝트 개요]**
*   **콘텐츠 목표:** 시청자에게 '일반 점검으로는 알 수 없는, 구조적/데이터적 오류'에 대한 전문적인 공포감을 심어주고, 유료 진단 보고서(Diagnostic Report)의 필요성을 각인시킨다. [근거: Self-RAG 메모리 - 최종 CTA]
*   **톤앤매너:** 학술적 위협감 / 최고 권위자의 속삭임 (Authority & Urgency).
*   **필수 포맷:** 9:16 쇼츠 (최소 해상도 1080p, 프레임 레이트 30fps).

---

## ⏱️ [타임라인 및 액션 매핑]

### 🔴 Phase 1: HOOK - 패러다임 전환 (T+0s ~ T+3s)
*   **목표:** 시선 장악. 높은 긴장감으로 이탈률 최소화.
*   **[Visual Designer 명세]**
    *   **T+0s:** 화면 암전 $\rightarrow$ 주변 사물(기계, 노드 등) 클로즈업 (정상 작동 샷). 색감: 차분한 푸른 계열 (Cyan/Blue).
    *   **T+1.5s:** 갑작스러운 **[Edge Failure Effect]**: 영상이 물리적으로 뒤틀리거나 거꾸로 재생되는 듯한 구조적 진동(Structural Shake)을 적용. 연결된 노드 중 무작위 3개가 빨간색 경고등으로 폭발하듯 깜빡여야 함.
    *   **T+3s:** 화면 전체에 **[System Glitch]**: 픽셀 단위의 노이즈가 짧게 끼는(Flickering) 효과를 주며, 다음 세그먼트로 전환되는 시각적 신호 역할을 수행.
*   **[Audio Editor 명세]**
    *   **T+0s:** 배경음악(BGM) 시작: 낮은 서브 베이스(Sub-Bass)의 지속적인 웅장함 유지 (약 40Hz).
    *   **T+1s:** **[SFX: Deep Boom/Impact]**: 임팩트 사운드를 활용하여 구조적 진동과 동기화. BPM을 급격히 상승시키며 불안감을 조성.
    *   **T+3s:** BGM 볼륨을 일시적으로 컷(Cut)하고, 고주파의 날카로운 **[High-Frequency Sine Wave]**를 짧게 넣어 청각적 쇼크 효과 극대화.
*   **[Developer Logic 명세]**
    *   **API 호출:** 없음 (순수 시각/청각 자극).

### 🔵 Phase 2: 문제 제기 - 상호 의존성 증폭 (T+3s ~ T+15s)
*   **목표:** 전문 용어를 사용하여 지식의 우월감과 불안감을 결합.
*   **[Visual Designer 명세]**
    *   **T+4s~T+10s:** 복잡한 시스템 다이어그램(Network Graph)을 화면 중앙에 배치. 노드와 연결선(Edge)은 Cyan 계열로 표현하며 안정성을 유지함. 전문 용어('Interdependency', 'Systemic Flaw')는 시각적으로 하이라이트 처리되어야 함.
    *   **T+12s:** **[Failure Visualization]**: 특정 가상 연결점 $C$ (노드 간의 Edge)가 끊어지는 순간, 해당 선을 따라 데이터 스트림(Cyan $\rightarrow$ Red)이 폭주하며 흩날리는 시각 효과를 연출.
    *   **T+15s:** 화면 구도를 빠르게 클로즈업하여, '결함의 시발점'처럼 보이는 미세하고 추상적인 지점에 집중시킴.
*   **[Audio Editor 명세]**
    *   **BGM 변화:** 서브 베이스 톤을 유지하되, 배경에 **[데이터 폭주 사운드/White Noise]**를 오버레이하여 정보의 과부하 상태(Overload)처럼 들리게 함.
    *   **T+12s:** 연결선이 끊어지는 순간, 노이즈 사운드의 볼륨을 급격히 높인 후, 날카로운 **[Staccato Alert Sound]**로 전환하여 청각적 긴장감을 최고조로 만듦.
*   **[Developer Logic 명세]**
    *   **API 호출:** `simulate_data_flow(node_A, node_B, time_elapsed)` 함수를 구현하여, 노드 A와 B 간의 데이터 흐름을 시뮬레이션하고, 실패 지점 $C$에서 **`E-DATA-001: Interdependency Failure Detected`**라는 가상의 에러 메시지를 화면에 띄우는 로직을 추가해야 함. (이 데이터를 통해 신뢰성 확보)

### 🟡 Phase 3: 클라이맥스 - 오류 폭로 (T+15s ~ T+30s)
*   **목표:** 불안감을 최고조로 끌어올리고, 자가진단만으로는 불가능함을 입증. (판매 퍼널의 핵심).
*   **[Visual Designer 명세]**
    *   **T+16s~T+25s:** 화면에 **[Waveform Graph]**를 전면 배치. 정상 상태는 부드러운 Cyan 파형으로, 오류 발생 가능 지점은 노이즈가 섞인 불안정한 Yellow-Red 스파이크로 표현해야 함.
    *   **T+27s (최대 공포 시점):** 그래프 상에 가장 높고 날카로운 'Anomaly Peak'를 구현하고, 이와 동시에 화면 전체에 **[데이터 왜곡 필터]**를 걸어 비현실적이고 전문적인 느낌을 극대화.
    *   **T+30s:** 모든 복잡한 시각 정보를 급격히 빼고(Fade Out), 단 하나의 텍스트 메시지("전문 진단 보고서가 필요합니다.")만을 중앙에 명료하게 남김.
*   **[Audio Editor 명세]**
    *   **BGM 변화:** T+15s에서 T+27s까지 BGM을 급격히 낮춰(Drop), 거의 배경 소음 수준으로 줄여 침묵의 공포를 만듦.
    *   **T+28s:** "이 오류는 육안으로 판단할 수 없습니다"라는 내레이션 직후, **[Sub-Bass Drop]**와 함께 일시적인 '무(無) 사운드' 상태를 만들어 시청자의 청각적 대비 효과를 극대화.
*   **[Developer Logic 명세]**
    *   **API 호출:** `fetch_diagnostic_report(system_model, time_series_data)` Mock API 호출을 트리거해야 함. 이 호출은 성공적으로 '결함'을 발견했다는 가상의 데이터를 반환하며, 화면에 **`Diagnostic Report: Status=Critical (Code E-DATA-001)`**와 같은 전문적인 결과를 띄워야 합니다.

### 🟢 Phase 4: CTA - 해결책 제시 및 루프 트리거 (T+30s ~ End)
*   **목표:** 공포를 '해결할 기회'로 전환하여 다음 액션(CTA) 유도.
*   **[Visual Designer 명세]**
    *   **T+31s:** 화면 톤을 급격히 밝고 신뢰감 있는 색상(Professional Blue/Gold)으로 전환. 복잡한 그래프가 사라지고, 깔끔한 UI 모달 형태의 '진단 보고서' 레이아웃이 등장해야 함.
    *   **T+35s:** CTA 메시지("더 자세한 분석이 필요하다면...")와 프로필 링크/웹사이트 주소가 화면 하단에 **반복적(Looping)**으로, 그러나 자연스럽게 깜빡이며 노출되어야 합니다.
    *   **End:** 마지막 프레임은 T+0s의 '정상 작동 샷'과 동일한 구도와 색감을 가져가며 마무리 (루프 트igger).
*   **[Audio Editor 명세]**
    *   **BGM 변화:** 긴장감 넘치던 BGM을 갑자기 **[희망적/권위적 피아노 코드]**로 전환. 톤은 유지하되, 심리적으로 안도감을 느끼게 하는 방향으로 급격히 반전시켜야 합니다 (Emotional Reversal).
    *   **End:** 내레이션의 마지막 문장(질문형)과 함께 사운드를 '여운'을 남기는 잔향(Reverb Tail) 효과로 끝냄.
*   **[Developer Logic 명세]**
    *   **API 호출:** 없음 (UI/UX적 마무리).
