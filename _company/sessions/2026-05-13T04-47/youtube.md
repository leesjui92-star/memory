<create_file path="~/Documents/Project_Anomaly_Loop/Final_Production_Blueprint.md"># 🎬 최종 콘텐츠 제작 블루프린트: Anomaly Loop (하이브리드 차량 진단)

**[프로젝트 개요]**
*   **주제:** 자가진단만으로는 놓치기 쉬운, 하이브리드 차량의 시스템 오류 Top 3.
*   **핵심 목적:** 시청자의 '기술적 불안감'을 극대화하고, 이를 해소하는 전문 진단 보고서(Standard Tier 상품) 구매로 연결 (Anomaly Loop Closure).
*   **형식/포맷:** 쇼츠 (9:16), 속도감 있는 데이터 중심 내레이션.
*   **총 예상 길이:** 45~55초.

---

## 📄 I. [SCRIPT & NARRATIVE FLOW] - Writer용 지침

**[톤앤매너 가이드]**
*   **확신 (Authority):** 모든 내레이션은 '전문가'의 입장에서, 데이터를 근거로 말해야 합니다. 추측성 표현 금지.
*   **속도:** 전체적으로 빠르고 간결하게 진행하되, 중요한 오류 폭로 부분에서는 *일시 정지*하는 듯한 연출(Pause)을 통해 긴장감을 극대화합니다.

**[시간대별 스크립트 및 핵심 지침]**

| 시간 (Time Code) | 구조 단계 | 내레이션 목표 (Script Focus) | 감정 곡선 (Emotion Curve) |
| :---: | :---: | :--- | :--- |
| **0~3초** | 🚀 HOOK (시선 장악) | "혹시... 당신의 차가 보내는 이 경고 신호를 무시하고 계신 건 아닌지요?"<br> (데이터 기반 질문 던지기. 자가진단의 한계 지적.) | [최대 의문/불안감] - '나만 모르는 진실'이라는 위협 제시. |
| **4~15초** | 🔍 문제 제기 (Premise) | "대부분의 정비사는 육안으로 보이는 부품 고장을 점검합니다. 하지만 최신 하이브리드 시스템은 다릅니다."<br> (문제 정의: 단순 고장이 아닌 '데이터 오류'가 핵심임을 제시.) | [호기심/지식적 우월감] - 시청자에게 '전문 지식'을 가진 듯한 느낌 부여. |
| **16~35초** | ⚠️ 오류 폭로 (Climax) | "문제는 전력 계통이 정상 범위 내에서 미세하게 패턴을 벗어나는 데이터 신호를 보낼 때 발생합니다."<br> *(구체적 사례 제시: 인버터/배터리 파형 그래프 비교)*<br>"자가 측정으로는 절대 잡을 수 없는, 이 '미세 노이즈 플레어'가 핵심입니다." | [최고조의 불안감/충격] - 데이터 시각화를 통해 위협 요소를 극대화. |
| **36~45초** | 💡 해결책 제시 & CTA (Resolution) | "하지만 이 오류는 전문 장비와 종합 분석이 필요합니다. 저희가 자체 개발한 진단 보고서(Diagnostic Report)는 단순 점검을 넘어, 데이터 흐름 전체를 추적합니다."<br> *(CTA 강조: '전문가의 시각'으로 구매 결정 유도)* | [안도감 $\rightarrow$ 해결책 제시] - 불안함을 해소하는 동시에, 서비스의 가치를 명확히 각인. |
| **46~End** | 🔄 루프 엔딩 (Loop Trigger) | "이 데이터를 완벽하게 이해하고 싶다면... 다음 영상에서 더 깊은 오류 분석을 확인하세요."<br> (질문형 끝맺음으로 재반복 유도.) | [미완의 질문/다음 궁금증] - 시청자가 답을 찾기 위해 다시 돌려보게 만듦. |

## 🎨 II. [VISUAL & EDITING FLOW] - Designer용 지침

**[핵심 비주얼 시스템 가이드: Anomaly Loop 적용]**
1.  **색상 팔레트:** 정상 데이터 = **Cyan (규칙적, 부드러움)** / 오류 신호 = **Red/Yellow (경고, 노이즈)**.
2.  **그래픽 필수 요소:** 일반적인 '부품' 샷은 최소화하고, 대신 '데이터 흐름(Data Flow)'과 '파형 그래프(Waveform Graph)'를 핵심 비주얼로 사용해야 합니다.

| 시간 (Time Code) | 시각적 연출 지침 (Visual Action) | 효과/애니메이션 요구사항 |
| :---: | :---: | :--- |
| **0~3초** | 🚨 강렬한 경고 화면 전환 (Black Screen $\rightarrow$ Red Flash). | 속도감 있는 컷 전환. 'WARNING' 같은 빨간색 경고 자막 오버레이 필수. |
| **4~15초** | 하이브리드 시스템의 개념적 다이어그램 제시. | Cyan 라인으로 연결된 데이터 흐름(정보/전력)을 부드럽게 보여주며, 전문성을 강조. |
| **16~35초** | **[클라이맥스] 핵심 시각 자료:** 파형 그래프 비교 (Waveform Comparison). | 1. Cyan 라인으로 정상 파형 제시. 2. 갑자기 Red 노이즈 플레어(Noise Flare)가 그 위에 겹쳐지는 애니메이션 효과 (최대 충격). 3. 'Anomaly'라는 단어가 화면을 흔들며 강조되어야 함. |
| **36~45초** | 진단 보고서 인터페이스 Mockup 제시. | 실제 데이터 시각화(그래프, 수치)가 가득 찬 고해상도의 깔끔한 UI 샷으로 전환 (신뢰도 확보). CTA 문구와 함께 '전문성'이 느껴지도록 연출. |
| **46~End** | 루프 엔딩 화면: 도입부의 경고 신호 이미지로 회귀. | 마지막 프레임은 첫 프레임과 색감, 구도가 일치하도록 편집하여 시청자의 재반복(Re-watch)을 유도한다. |
