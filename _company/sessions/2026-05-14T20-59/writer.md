✍️ Writer: 작업 시작합니다.

CEO님의 지시사항은 지금까지 확립된 모든 전문적 불안 요소(Pain Point)와 비즈니스 모델을 연결하여, 잠재 고객의 **심리적 공포를 극대화**하고 즉각적인 '진단 필요성'을 느끼게 만드는 판매 페이지 초안입니다.

랜딩 페이지 카피는 일반적인 제품 홍보가 아닌, **"당신이 모르는 위험에 대한 경고문(Warning/Diagnostic Report)"**의 톤앤매너를 유지해야 합니다. 따라서 제목과 서브헤드라인 모두 '질문'이나 '강한 선언적 공포' 형태로 구성했습니다.

## 🚨 랜딩 페이지 카피라이팅 세트: The Diagnosis Ecosystem (3가지 후크)

### 🚀 [Hook Set 1] - 재정 시스템 리스크 (The Retirement Cliff)
*   **공포 자극:** 시간의 흐름에 따른 구조적 부실. 내가 가진 것이 시간이 지나면서 무너질 것 같은 불안감.
*   **타겟 Pain Point:** 연금/은퇴 자산의 지속 가능성 의문.

| 요소 | 카피라이팅 초안 (Headline & Subheadline) | 톤앤매너 주석 및 강점 |
| :--- | :--- | :--- |
| **메인 제목** | **[경고] 당신의 은퇴 자산은 '만료화(Obsolescence)'되고 있습니다. 이 숫자를 무시하지 마십시오.** | [근거: Researcher - 1번 Pain Point]. 가장 강력한 단어는 '경고'와 '만료화'. 단순 부족이 아닌, 구조적 실패를 암시하여 공포 극대화. |
| **서브헤드라인** | 단순히 돈을 모으지 못해서가 아닙니다. 당신의 포트폴리오 자체가 사회 시스템 변화 속도를 따라잡지 못하는 *구조적 결함*이 발생했습니다. 지금 당장 진단해야 할 3가지 '시스템 리스크'를 공개합니다. | [근거: Hyunbin - Core Value]. 문제를 개인의 노력(돈 모으기) 차원이 아닌, 외부 시스템(사회 변화 속도) 문제로 확장하여 전문 컨설팅의 필요성을 부여함. |
| **CTA 유도 문구** | ❌ 불안한 추측에 의존하지 마세요. 객관적인 '시스템 진단 보고서'를 통해 현재 자산의 생존 기간을 정확히 예측하십시오. | 구매는 공포 해소라는 기능으로 정의됨. |

### 🧠 [Hook Set 2] - 경력/지식 시스템 리스크 (Knowledge Obsolescence)
*   **공포 자극:** 내가 가진 전문성이 시간이 지날수록 무가치해지고 있다는 무력감. AI에게 대체당할 것이라는 불안함.
*   **타겟 Pain Point:** 노하우의 감가상각, 반복 업무에서의 무기력함.

| 요소 | 카피라이팅 초안 (Headline & Subheadline) | 톤앤매너 주석 및 강점 |
| :--- | :--- | :--- |
| **메인 제목** | **[🚨 Alert] 당신의 '노하우'는 이미 데이터 드리프트(Data Drift)를 시작했습니다.** | [근거: Writer 개인 메모리 - Data Drift]. 전문 용어를 사용해 지적인 공포를 유도. 노하우가 사라지는 것이 아니라, *변형*되고 있다는 표현이 더 치명적임. |
| **서브헤드라인** | 10년 전의 '최고 학위'나 '성공 경험'은 이제 시스템의 평균값일 뿐입니다. AI 시대에 필요한 것은 지식이 아닌, 스스로 오류를 발견하고 재정의하는 *진단 프로토콜*을 갖추는 것입니다. | [근거: Writer 개인 메모리 - 15-30초]. 지식 자체보다 '프로토콜'이라는 방법론적 진단을 파는 구조로 전환함. |
| **CTA 유도 문구** | 당신의 커리어 시스템이 최신 기술 트렌드에 맞춰 작동하고 있는지? 지금, 객관적인 [전문가진단 프로토콜]을 통해 검증하십시오. | 문제 해결을 '점검'이라는 행위(진단)와 연결함. |

### ⚙️ [Hook Set 3] - 종합 시스템 불안 요소 (The Universal Anomaly)
*   **공포 자극:** 눈에 보이지 않는 곳에서부터 문제가 시작되고 있다는 막연하지만 강력한 느낌. 가장 포괄적이고 권위적인 공포감.
*   **타겟 Pain Point:** 전반적인 삶의 불확실성, 사각지대의 존재.

**요약 및 판매 전략 (Sales Flow Summary)**:
1. **후크 노출:** 3가지 Hook 중 고객의 현재 상황에 맞는 것으로 선택하여 페이지 상단에 배치한다. (최적화된 A/B 테스트 필요)
2. **문제 심화:** "당신이 느끼는 불안함은 당연한 것이 아닙니다. 그것은 시스템적 결함을 인지하는 *정상적인* 감각입니다."라는 문장으로 공감을 최대화한다.
3. **솔루션 제시:** '진단'을 유일한 해결책으로 정의하고, Basic $\rightarrow$ Standard $\rightarrow$ Premium 순서로 계층적 판매(Laddering)를 유도하는 상품 구성도를 명확히 배치한다.
