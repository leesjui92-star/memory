💻 Developer: 작업 시작합니다.

해당 오류 `fatal: couldn't find remote ref main`은 로컬 Git이 원격 저장소(remote)에서 `main` 브랜치에 해당하는 참조(ref)를 찾지 못했음을 의미합니다. 이는 보통 원격 저장소의 브랜치 이름 불일치, 원격 정보의 손상, 또는 로컬 캐시 문제로 인해 발생합니다.

아래는 원인 진단 및 즉각적인 해결 방법입니다. **반드시 터미널에서 해당 리포지토리 경로로 이동하여 다음 명령어들을 순서대로 실행하십시오.**

### 1. 현황 진단 (Diagnosis)

가장 먼저, 로컬 저장소와 원격 저장소의 현재 상태를 확인합니다.

**명령어:**
```bash
git remote show origin
```
**설명:** 이 명령은 `origin`이라는 원격 저장소에 대해 현재 설정된 모든 정보를 보여주어, 실제로 어떤 브랜치들이 존재하고 추적 중인지 파악하는 데 도움을 줍니다.

### 2. 원인별 해결책 (Solutions)

#### A. 브랜치 이름 불일치 확인 및 변경 (Branch Name Mismatch)

많은 레거시 저장소에서 기본 브랜치 이름이 `master`로 설정되어 있을 수 있습니다.

**해결 단계:**
1. **원격 브랜치 목록 확인:**
   ```bash
   git branch -r
   ```
2. 만약 `origin/master`가 존재한다면, 이를 `main`으로 변경하여 푸시를 시도합니다.
   ```bash
   git branch -m master main
   git push -u origin main
   ```

#### B. 원격 추적 정보 재설정 및 강제 동기화 (Force Synchronization)

로컬에 저장된 원격 참조 정보를 무효화하고 Git이 다시 원격 상태를 읽도록 강제합니다.

**해결 단계:**
1. **원격 추적 정보 삭제 (선택 사항, 주의 필요):**
   ```bash
   git remote prune origin
   ```
2. **모든 원격 브랜치 정보를 강제로 재설정 및 가져오기:**
   ```bash
   git fetch --all
   git reset --hard origin/main  # 만약 main이 존재한다면 실행
   # 또는 git reset --hard origin/master # master를 기본으로 시도할 경우
   ```

#### C. 가장 확실한 해결책: 리모트 브랜치 강제 업데이트 (The Direct Fix)

만약 `main` 브랜치가 실제로 원격에 존재하지만 로컬이 이를 인식하지 못하는 경우, 다음 명령을 사용하여 원격의 모든 정보를 다시 가져옵니다.

**최종 실행 명령어:**
```bash
git fetch origin
git pull origin main
```
**설명:** 이 명령어는 `origin` 저장소에서 `main` 브랜치의 최신 상태를 확인하고, 로컬에 해당 내용을 병합(merge)하거나 리베이스하여 동기화합니다. 만약 여전히 문제가 발생하면, `git remote update` 명령을 시도해 볼 수 있습니다.

## 🛠️ Part 3: 필수 제작 장치 목록 (Sound & Visual Devices Checklist)

제작 단계에서 반드시 체크하고 활용해야 할, 즉시 적용 가능한 기술적 요소들입니다. 이 요소들이 콘텐츠의 전문성과 임팩트를 결정합니다.

### 🔊 사운드 디자인 장치 (Audio Devices)
*   **Ambient Noise Layering:** 일반적인 배경음 외에, **저주파수의 떨림(Drone Sound)**이나 미세한 **금속성 마찰음**을 깔아 심리적 압박감을 조성합니다.
*   **Sudden Silence (공백):** 가장 큰 공포는 '소리가 갑자기 사라지는 순간'입니다. 클라이맥스 직전 1~2초 동안 모든 사운드를 제거하여 관객의 청각적 예민함을 극대화하세요.
*   **Reverb & Echo:** 목소리나 발자국 소리에 과도한 잔향(Echo)을 넣어, 공간이 넓고 위험하다는 느낌을 부여합니다. (폐쇄공포증 자극).
*   **Binaural Recording Effect:** 3D 사운드처럼 좌우에서 특정 소리가 다가오거나 사라지는 효과를 주어 현실감을 높입니다.

### 🎬 시각적 연출 장치 (Visual Devices)
*   **Quick Jump Cuts & Montage:** 공포 상황의 단편적인 장면들을 매우 빠르게 교차 편집하여, 관객이 전체 그림을 파악하기 어렵게 만듭니다. (혼란 유발).
*   **Color Grading (톤 보정):** 전반적으로 채도를 낮추고(Desaturation), **짙은 청록색/회색 톤**을 메인 컬러로 사용하여 비현실적이고 차가운 분위기를 연출합니다.
*   **Dutch Angle (사선 구도):** 카메라를 수평이 아닌 기울어진 각도로 촬영하여, 시각적으로 불안정하고 위협적인 느낌을 부여합니다.
*   **POV Effect & Glitch:** 핸드헬드를 기본으로 사용하며, 화면에 순간적으로 **지글거림(Glitch)**이나 노이즈 필터를 넣어 '현실이 깨지는' 듯한 착각을 유도합니다.

## 📈 Part 1: 초기 핵심 KPI (Key Performance Indicators) 설계

스릴러/공포 쇼츠 채널의 특성상, 조회수(Views)보다 **사용자 행동 심리**에 기반한 지표가 훨씬 중요합니다. 아래 세 가지 지표를 측정하고 최우선으로 관리해야 합니다.

### 1. 핵심 성과 지표 (North Star Metric): 재반복 비율 (Loop Rate)
*   **정의:** 시청자가 쇼츠를 처음부터 끝까지 본 후, 스스로 영상을 다시 재생하는 비율 또는 다음 콘텐츠로 넘어가지 않고 채널에 머무르는 시간/횟수. (가장 중요)
*   **단기 목표 기준:** **최소 65% 이상**. (경쟁사 평균 대비 높은 수준을 유지하며 트래픽 유입 증명)
*   **측정 가이드라인:** 쇼츠의 마지막 1~2초에 반드시 '다음 단서가 있다'는 느낌이나, 핵심 질문(Who? Why?)이 남도록 의도적으로 설계해야 합니다.

### 2. 콘텐츠 최적화 지표: 평균 시청 지속 시간 (Average View Duration, AVD)
*   **정의:** 쇼츠 전체 길이 대비 실제 시청자가 머문 시간 비율.
*   **단기 목표 기준:** **최소 영상 길이의 85% 이상**. (쇼츠는 짧으므로, '완주율'이 곧 생존력입니다.)
*   **측정 가이드라인:** AVD 그래프에서 가장 급격하게 하락하는 구간(Drop-off Point)을 찾아내어, 해당 지점 이전에 강력한 후크(Hook)나 반전 요소를 배치하도록 스크립트 수정에 반영합니다.

### 3. 유입 및 발견 가능성 지표: 클릭률 (Click Through Rate, CTR)
*   **정의:** 노출된 제목/썸네일 대비 실제 클릭이 발생한 비율. (알고리즘 추천을 받기 위한 전제 조건).
*   **단기 목표 기준:** **최소 8% 이상**.
*   **측정 가이드라인:** 시청자의 호기심(Curiosity)를 자극하되, 스포일러가 되지 않도록 '질문형 제목' 또는 '충격적인 결과만 제시하는 제목' 구조를 활용합니다. (예: "이 집에 절대 들어가면 안 되는 이유 ⚠️")

## 🖼️ Part 2: 썸네일 레이아웃 및 구도 원칙 (The Art of Ambiguity)

핵심 목표는 **"이게 대체 무슨 상황이지?"** 라는 질문을 유발하는 것입니다. 단지 무서운 이미지를 나열하기보다, *정보의 결핍*을 활용해야 합니다.

### 🔎 썸네일 공통 원칙 (The Rule Set)
1.  **클로즈업 주력:** 인물의 얼굴 전체를 보여주기보다, **눈동자, 손가락, 옷깃의 디테일, 혹은 모호한 사물에 포커스**합니다. (감정 대신 '디테일'을 통해 공포 유발).
2.  **대비 활용:** 전경(Foreground)은 밝거나 선명하게 처리하고, 배경(Background)은 **깊고 어둡게(Low Key)** 블러/노출 조절을 하여 시선이 모호한 공간으로 향하게 만듭니다. (Depth of Field 필수).
3.  **불필요한 정보 제거:** 썸네일에는 *최소한의 요소*만 배치합니다. (예: 인물 + 사물 + 제목)

### ✨ 추천 썸네일 컨셉 3안 (High-Impact Blueprints)

#### 💡 Concept 1: [The Unseen Witness] - 모호함 활용
*   **주제:** 주인공이 *무언가를 발견했지만, 그것을 완전히 보여줄 수 없는* 상황.
*   **구도/레이아웃:** 화면의 **2/3 지점 바깥쪽**에 초점을 맞춥니다. 인물은 측면에서 뒷모습(Back View)으로 배치하거나, 시선이 특정 방향을 향하게 처리합니다.
*   **시각 요소:** 배경에는 아웃포커싱된 형태의 실루엣이나 빛의 굴절 같은 '미확인 존재'를 배치하고, 그 위에 `Oswald` 타이포로 **질문형 문구**(`🚨 저건 누구지?`)를 삽입합니다.
*   **톤:** Slate Blue와 Moss Green을 혼합한 새벽빛 느낌.

#### 💡 Concept 2: [The Detailed Focus] - 사물/신체 부위 클로즈업 활용
*   **주제:** 공포의 근원지(Source)가 인간이 아닌 '사물'이나 '신체의 일부'일 때 가장 효과적입니다.
*   **구도/레이아웃:** 썸네일의 **중앙 50% 영역**을 차지하도록 클로즈업합니다. (예: 문틈 사이, 거울 속 왜곡된 반영, 바닥에 떨어진 물건).
*   **시각 요소:** 사물 주변에 `Danger Pop` 색상의 경고선(Warning Tape)이나 작은 핏자국 그래픽을 추가하여 긴급성을 부여합니다. 인물의 손이 이 사물을 *가리키는* 구도를 활용하면 완벽합니다.
*   **톤:** 하드한 대비와 차가운 Gray 톤.

#### 💡 Concept 3: [The POV Confrontation] - 관객 몰입형 (시청자 위치 지정)
*   **주제:** 시청자가 주인공과 함께 공포 상황을 목격하는 듯한 '1인칭' 경험.
*   **구도/레이아웃:** 카메라의 *정면*에서 촬영된 것처럼 느껴지게 합니다. 프레임 하단에 인물의 발이나 가방 일부가 걸쳐져 있는 구도를 사용합니다 (즉, 관객이 그들과 함께 현장에 있다는 느낌).
*   **시각 요소:** 시선이 향하는 지점(화면 중앙의 30% 영역)에만 **강한 빛 번짐 효과(Bloom)**를 주어 '무언가'가 숨겨져 있음을 암시합니다. 이 부분에 제목을 배치하여 궁금증을 극대화합니다.
*   **톤:** 어둠과 대비되는 Cool Mist Accent의 미묘한 광원 사용.

# 🎬 스릴러/공포 쇼츠 스토리텔링 & 자동화 시스템 구축 가이드라인

제시된 CEO 지시에 따라, 시청자의 집중력을 최대로 끌어올리는 **'3단 구조(Hook $\rightarrow$ Tension $\rightarrow$ Twist)'**의 구체적인 스크립트 개발 템플릿을 완성했습니다. 이 가이드는 단순히 글쓰기 지침을 넘어, 촬영/편집 단계까지 고려한 '자동화 가능한 프로세스 설계도'입니다.

---

## 📝 A. 쇼츠 스크립트 구조 (The 3-Act Template)

| 구조 | 시간대 (누적) | 핵심 목적 | 감정적 아크 (Emotional Goal) | 필수 요소 및 지침 |
| :---: | :---: | :---: | :---: | :--- |
| **1단계: 강렬한 후크 (The Hook)** | 0초 ~ 3초 | 시청자 스크롤 정지 (Stop Scrolling). | 충격, 궁금증 (Curiosity) | **[필수]** 평범함의 파괴. 갑작스러운 사운드, 질문형 자막, 클로즈업된 기이한 물체 제시. *절대 설명 금지.* |
| **2단계: 긴장감 고조 (The Build-up)** | 4초 ~ 50초 | 몰입 유지 및 공포 증폭. | 불안, 기대감 (Suspense) | **[핵심]** 정보의 점진적 제공(Small Reveal). '이게 진짜일까?'라는 의문을 지속적으로 심어주고, 거짓 결말을 넣어 시청자가 다음 전개를 예상하게 만듦. |
| **3단계: 반전/결말 (The Payoff)** | 51초 ~ 60초 | 감정적 해소 혹은 재충격. | 경악, 혼란 (Shock) | **[필수]** 처음 제시된 정보의 의미를 완전히 뒤집는 결말(Twist). 시청자가 '왜?'라는 질문을 던지게 만들어 댓글 참여 유도. |

---

## ⚙️ B. 단계별 스크립트 작성 및 제작 지침 (Actionable Scripts)

### 1. [0~3초] 후크 개발 가이드라인: "Show, Don't Tell" 원칙
*   **✅ 사운드 디자인:** 웅장한 음악 대신 **급작스러운 정적(Silence)** 또는 높은 주파수의 날카로운 노이즈를 사용합니다. (가장 효과적)
*   **✅ 비주얼 연출:** 화면을 가득 채우는 **극단적인 클로즈업(Extreme Close-up)**으로 시청자의 초점을 좁힙니다. (예: 누군가의 눈동자, 바닥의 핏자국 등)
*   **✅ 스크립트 예시 문구:** "⚠️ 이걸 보고도 아무렇지 않은 사람이 있나요?" 또는 "지금까지 본 모든 이야기가 거짓말이라면?"과 같은 **질문형 자막**을 전면에 배치합니다.

### 2. [4~50초] 긴장감 고조 스크립트 가이드라인: "False Resolution"의 활용
*   **✅ 스토리텔링:** 초반에 '위험하다'는 것을 보여준 후, 잠시 **안전한 듯한 장면(False Safety)**을 배치합니다. 이 안전함이 곧 가장 큰 함정이 됩니다. (예: 탈출하는 것 같은데, 뒤에서 누가 따라오는 사운드가 들림)
*   **✅ 페이싱:** 템포를 의도적으로 조절해야 합니다. 초반에 빠르게 정보를 몰아주다가, 중간 지점(20~30초)에서는 **의도적인 슬로우 모션과 긴 침묵**을 배치하여 압박감을 극대화합니다.
*   **✅ 시각 단서:** Designer가 정의한 `Cool Mist Accent` 컬러를 활용하여 '단서'나 '경고 표시(⚠️)'만 미스터리하게 보여줍니다.

### 3. [51~60초] 반전/결말 스크립트 가이드라인: "The Loop" 원칙
*   **✅ 구조:** 결말을 통해 시청자에게 **'이건 시작일 뿐이다'**라는 느낌을 주어야 합니다. (Loop)
    *   **Twist A (시간적 반전):** 주인공이 사실은 공포를 경험하는 사람이 아니라, 그 공포를 유도하는 사람(관찰자)이었다는 설정으로 마무리합니다.
    *   **Twist B (시점 전환):** 관객이 끝까지 믿어왔던 '현실' 자체가 가짜였음을 깨닫게 합니다. (예: 영상 전체가 사실은 꿈, 혹은 VR 게임 속 체험이었음)
*   **✅ CTA 통합:** 결말 직후, 화면 하단에 **"당신이라면 어떻게 했을 것 같나요?"**와 같은 댓글 유도 문구를 띄워 이탈을 막습니다.

$$\text{Keywords/Trends} \xrightarrow[\text{Comment Harvester}]{\text{Memory}} \text{Concept Generation} \xrightarrow[\text{Writer Template}]{\text{Scripting}} \text{Visual Assets Collection} \xrightarrow[\text{Designer Rules}]{\text{Editing Suite}} \text{Sound Layering} \xrightarrow[\text{KPI Checklist}]{\text{Review}} \text{Metadata & Scheduling}$$

## 📑 단계별 실행 가이드라인 (The Repeatable Process)

### Phase 1: 기획 및 스크립트 자동 생성 (Script Generation - AI Driven)
**목표:** 막연한 아이디어를 '시간 단위의 액션 목록'으로 전환한다.
*   **입력 데이터:** `comment_harvester`에서 누적된 **후크 단어** + `trend_sniper`가 추출한 **최신 공포 키워드** (예: "문 잠금", "미스터리 인물", "이상 기온 변화").
*   **작업 도구:** LLM (AI 프롬프트 기반)
*   **실행 단계:**
    1.  **프롬프트 입력:** [Writer]가 정의한 3단 구조(Hook $\rightarrow$ Tension $\rightarrow$ Twist) 템플릿 전체를 AI에 던지며, *키워드와 KPI 목표치*를 함께 주입합니다.
    2.  **출력 검토 (Critical Check):** 스크립트의 각 구간마다 **[필수 사운드]**, **[필수 비주얼 샷(Shot List)]**, **[자막/메시지 구조]**가 명확히 분리되어 있는지 확인합니다.
    3.  **결과물:** 시간대별 스크립트 + 상세한 촬영/장면 리스트 (Shot List).

### Phase 2: 에셋 준비 및 촬영 (Asset Preparation - Efficiency Focused)
**목표:** 최소한의 인력 투입으로 최대의 비주얼 자료를 확보한다.
*   **작업 도구:** 카메라, 로케이션, 스톡 푸티지 라이브러리
*   **실행 단계:**
    1.  **샷 리스트 기반 촬영:** Phase 1에서 나온 Shot List 순서대로 필요한 장면만 집중적으로 촬영합니다. (예: '어두운 복도', '손으로 문고리 만지는 클로즈업' 등)
    2.  **비주얼 가이드 적용:** 모든 영상은 [Designer]가 정의한 **톤 앤 매너(Deep Slate Blue, Charcoal Gray)**를 유지하도록 촬영 환경과 조명에 신경 씁니다. (색감 통일이 핵심).
    3.  **자료 분류:** 확보된 영상을 '샷 ID'와 함께 폴더별로 정리합니다.

### Phase 3: 후반 작업 파이프라인 (Post-Production - The Core Automation)
**목표:** 스크립트의 감정적 아크를 사운드와 편집으로 구현한다.
*   **작업 도구:** 전문 영상 편집 프로그램 (Premiere Pro, DaVinci Resolve 등)
*   **순서 및 핵심 지침:**

| 순서 | 작업 내용 | [필수] 체크포인트 (KPI 연동) | 역할 강조 요소 |
| :---: | :--- | :--- | :--- |
| **1. 비주얼 편집** | 샷 리스트에 따라 영상을 배치하고, 타이밍을 조절한다. | **[AVD/Hook]:** 0~3초 구간에서 시청자가 이탈하지 않도록 빠른 컷 전환과 강한 대비(Contrast)를 유지하는가? | **"정보의 결핍"** (불안감을 유발하며 장면을 끊기지 않게 이어가야 함). |
| **2. 사운드 디자인** | 영상에 맞는 배경음, 효과음(SFX), 대사를 오버레이 한다. | **[Suspense]:** 공포를 조성하는 소리는 '갑작스러운 정적'과 '낮은 주파수의 앰비언트 노이즈'가 핵심이다. 사운드가 시각 정보의 빈틈을 메꿔야 한다. | **사운드 레이어링:** BGM (지속적 불안) $\rightarrow$ SFX (순간 충격/발소리) $\rightarrow$ 침묵(최고조 긴장). |
| **3. 자막 및 그래픽** | [Writer]의 스크립트 구조에 맞춰 모든 텍스트를 배치한다. | **[브랜드 통일]:** 타이포그래피(Oswald/Noto Sans)와 색상 팔레트(Cool Mist Accent, Danger Pop)만 사용했는가? 자막은 호기심 유발 질문 형태로 구성되어야 한다. | **강제적 시선 분산:** 중요한 정보나 경고 문구는 화면의 예상치 못한 곳에 배치한다. |
| **4. 최종 검토** | 전체 영상 재생을 통해 감정적 아크를 체크한다. | **[Loop Rate]:** 결말(Twist) 이후, 다음 단서가 궁금해서 영상을 **재생하게 만드는 강제 장치**가 있는가? (이것이 성공 여부의 90%) | 완성된 콘텐츠는 반드시 '왜?'라는 질문을 남기고 끝난다. |

### Phase 4: 업로드 최적화 및 예약 (Deployment - Algorithm Driven)
**목표:** 검색 노출과 추천 알고리즘 점수를 극대화한다.
*   **작업 도구:** YouTube Studio API / 트렌드 데이터
*   **실행 단계:**
    1.  **제목 작성 (CTR Max):** [공동 목표]에서 정의한 '질문형/충격 결과 제시' 구조를 따른다. (예: "⚠️이 집에 절대 들어가면 안 되는 3가지 이유")
    2.  **썸네일 제작 (Curiosity Hook):** [Designer]가 정한 원칙(클로즈업, 정보의 결핍)에 따라 시각적 질문을 던지는 구도를 완성한다. **절대 모든 것을 보여주지 않는다.**
    3.  **메타데이터 작성:** 스크립트 내에서 언급된 핵심 키워드 5~10개를 추출하여 태그와 설명란에 배치하고, 경쟁사 분석 보고서([competitor_brief])의 성공 패턴을 참고하여 구조화한다.
    4.  **업로드 예약:** 가장 트래픽이 높을 것으로 예상되는 시간대에 예약 업로드를 진행한다.

## 'Anomaly Loop' 테스트 영상 비주얼 시스템 브리프

이 브리프는 정의된 브랜드 가이드라인(어두운 배경, 네온 시안 텍스트 대비)과 '해결되지 않은 의문(Looping)'을 유도하는 심리적 불안감이라는 핵심 주제를 바탕으로 제작되었습니다. 모든 요소는 고대비와 긴장감을 극대화하도록 설계되었습니다.

### 1. 인트로 (Intro Sequence) 브리프

**목표:** 시청자의 즉각적인 몰입과 '이상 현상'에 대한 의문을 심어주어 다음 내용을 보게 만드는 것.
**길이:** 약 5~7초 내외의 빠른 편집.

| 요소 | 상세 지침 | 디자인 적용 규칙 | 참고 사항 |
| :--- | :--- | :--- | :--- |
| **배경 (Background)** | 완전한 블랙 (#000000) 또는 극도로 어두운 짙은 그레이 (#1A1A1A). 미세한 노이즈나 글리치 효과를 배경에 은은하게 삽입. | 저채도 블루/그린 계열의 잔상(Ghosting)을 아주 희미하게 적용하여 불안감 조성. | 영상 전체 분위기를 지배함. |
| **타이포그래피 (Text)** | 핵심 문구는 네온 시안색 (#00FFFF 또는 #00FFFF에 가까운 밝은 청록색). 폰트는 산세리프체 중 고딕 계열(예: Orbitron, Space Grotesk 등)을 사용. | 텍스트 주변에 미세한 글로우(Glow) 효과를 적용하여 빛이 번지는 듯한 느낌 강조. | **핵심 문구 예시:** "Anomaly Loop" 또는 "The Unanswered Question" |
| **모션/효과** | 타이포그래피가 화면 중앙에서 서서히 확대되거나, 화면 전체에 미세하게 떨림(Jitter) 효과 발생 후 멈춤. | 빠른 전환 속도와 정지된 순간의 대비를 활용하여 긴장감 극대화. |

### 2. 아웃트로 (Outro Sequence) 브리프

**목표:** 시청자에게 생각할 거리를 남기고, 다음 행동(댓글/재시청)을 유도하며 여운을 길게 남기는 것.
**길이:** 약 5초 내외.

| 요소 | 상세 지침 | 디자인 적용 규칙 | 참고 사항 |
| :--- | :--- | :--- | :--- |
| **배경 (Background)** | 인트로와 동일하게 어두운 배경 유지. 그러나 화면 하단에 미세한 시안색의 물결 또는 패턴이 느리게 흐르도록 연출. | 차분함 속의 불안감을 유지. 너무 자극적이지 않게 마무리. |
| **CTA (Call to Action)** | "당신의 생각은 무엇인가요?"와 같은 질문을 중앙에 배치. 텍스트 색상은 시안색(#00FFFF)으로 통일. | CTA 문구 아래에는 작은 글씨로 채널 로고 또는 다음 영상 예고를 삽입하여 마무리. |
| **모션/효과** | 화면이 서서히 페이드 아웃(Fade Out)되면서, 마지막 질문 텍스트가 잠시 멈춘 후 사라짐. |

### 3. 핵심 썸네일 브리프 (3안 비교 정리)

**목표:** '미스터리와 궁금증'을 유발하여 클릭률(CTR)을 극대화하는 레이아웃 원칙 적용.
**공통 규칙:** 어두운 배경, 네온 시안/밝은 그린 대비, 인물의 클로즈업 또는 모호한 오브젝트 활용.

#### 썸네일 컨셉 1: The Glitch (디지털 불안감 강조)

*   **주요 구도:** 인물의 눈 또는 얼굴의 클로즈업.
*   **배경:** 완전한 블랙. 배경에 디지털 노이즈(Glitch Effect)가 강하게 삽입되어 화면이 깨진 듯한 느낌을 부여.
*   **텍스트 배치:** 중앙 상단에 "Anomaly Loop"를 네온 시안으로 매우 크게 배치. 텍스트 주변에 픽셀화된 테두리 효과 추가.

*   **레이아웃:** 화면 전체를 기하학적인 패턴이나 반복되는 문양(예: 격자무늬, 타일 패턴)으로 채웁니다. 이 패턴 중 일부만 시안색으로 비정상적으로 왜곡되거나 사라지게 처리합니다.
*   **비주얼:** 배경은 흑백 또는 어두운 회색 계열을 사용하되, 반복되는 패턴의 경계선에만 강렬한 네온 시안색 라인을 적용하여 '시스템 오류' 느낌을 극대화합니다.

## 🎬 'Anomaly Loop' 비주얼 시스템 및 템플릿 가이드라인

### 1. 브랜드 컬러 팔레트 (Color Palette)

심리적 불안감(Psychological Unease) 극대화와 고대비(High Contrast)를 핵심 원칙으로 설정합니다.

| 역할 | 색상 이름 | HEX 코드 | RGB 값 | 사용 목적 |
| :---: | :---: | :---: | :---: | :--- |
| **배경 (Primary BG)** | Deep Void Black | `#0A0A0A` | (10, 10, 10) | 영상 및 썸네일의 주 배경. 깊이와 공허함 표현. |
| **강조색 (Accent/Neon)** | Neon Cyan | `#00FFFF` | (0, 255, 255) | 핵심 텍스트, 강조선, 경고 표시. 시각적 충격 및 디지털 불안감 유도. |
| **보조색 (Secondary BG)** | Dark Gray | `#1A1A1A` | (26, 26, 26) | 중간 배경 또는 그림자 처리 영역. 깊이감을 유지. |
| **텍스트 (Text)** | Ghost White | `#F0F0F0` | (240, 240, 240) | 주 설명 텍스트. 네온 시안과의 대비를 극대화. |

### 2. 타이포그래피 시스템 (Typography System)

긴장감과 미스터리를 조성하는 산세리프체(Sans-Serif) 계열을 사용합니다.

*   **헤드라인/후크 (Hook Titles):** **Bebas Neue** 또는 **Anton**
    *   스타일: 매우 두껍고, 좁은 자간(Tight Tracking), 대문자 사용. (긴박함 표현)
    *   색상: Neon Cyan (`#00FFFF`)
*   **본문/설명 (Body Text):** **Inter** 또는 **Roboto Mono**
    *   스타일: 깔끔하지만 약간의 기계적인 느낌을 주는 폰트.
    *   색상: Ghost White (`#F0F0F0`)
*   **강조 효과:** 모든 핵심 정보에는 `Neon Cyan` 색상의 두꺼운 테두리(Stroke)를 적용하여 배경과 분리도를 극대화합니다.

### 3. 썸네일 컨셉 및 레이아웃 가이드라인 (Thumbnail Templates)

핵심은 '미스터리와 궁금증'을 유발하는 구체적인 시각적 요소의 배치입니다.

#### A. 기본 구조 원칙
1.  **배경:** 무조건 `Deep Void Black` (`#0A0A0A`) 사용.
2.  **중앙 집중:** 시청자의 시선이 즉시 핵심 요소(인물/상황)로 향하도록 배치.
3.  **대비 극대화:** 모든 텍스트와 주요 오브젝트는 `Neon Cyan`으로 처리하고, 주변에 어두운 그림자(`Dark Gray`)를 살짝 넣어 입체감을 부여합니다.

#### B. 컨셉 3안 (Anomaly Loop 적용)

| 컨셉 ID | 핵심 레이아웃 | 시각적 요소 강조 | 목표 감정 유도 |
| :---: | :---: | :---: | :---: |
| **T-01** | **클로즈업 & 경계선** | 인물의 눈 또는 특정 사물에 초점을 맞춘 극단적인 클로즈업. 화면 전체에 얇고 불규칙한 `Neon Cyan` 선(Glitch effect)을 배경으로 깔기. | 직접적인 불안감, 심리적 압박 |
| **T-02** | **공간의 균열** | 인물은 중앙에 배치하고, 주변 공간(배경)이 왜곡되거나 이중 노출된 듯한 비현실적인 구도 사용. 텍스트는 화면 하단 또는 우측 상단에 배치하여 '무언가 잘못되었다'는 느낌을 강조. | 현실 불일치, 인지 부조화 |
| **T-03** | **심볼 & 대비** | 단순한 기하학적 도형(원, 사각형)을 배경으로 사용하고, 그 위에 `Neon Cyan` 색상의 미니멀한 심볼이나 텍스트를 배치. (H-04 모듈 적용) | 추상적인 공포, 패턴의 반복에 대한 의문 |

### 4. 영상 인트로/아웃트로 템플릿 (Video Templates)

영상 시작과 끝에 사용될 고정된 비주얼 시스템을 정의합니다.

*   **인트로 시퀀스 (0~5초):**
    1.  화면: `Deep Void Black` 배경. 화면 중앙에 `Neon Cyan`으로 **H-01 (직접적 질문)** 텍스트가 빠르게 나타남. (폰트: Bebas Neue, 크기 최대)
    2.  효과: 텍스트 등장 시 화면 전체에 미세한 글리치(Glitch) 효과와 함께 짧은 노이즈/화면 깜빡임 발생.
    3.  음악: 낮은 주파수의 앰비언트 사운드나 날카로운 신호음 삽입.

*   **아웃트로 시퀀스 (마무리):**
    1.  화면: `Dark Gray` 배경으로 전환.
    2.  텍스트: **"당신의 의문은 계속된다."** (Ghost White, Inter체)
    3.  다음 행동 유도: 구독/재생 버튼 영역을 `Neon Cyan`으로 강조하고, 다음 콘텐츠에 대한 미스터리 질문(예: "다음 루프는 무엇인가?")을 작은 글씨로 삽입.

### 💡 구체적인 영상 아이디어 도출 (Actionable Ideas)

위 키워드들을 기반으로 'Anomaly Loop' 콘텐츠 제작에 즉시 활용 가능한 초기 영상 주제를 제안합니다. 모든 아이디어는 **'해결되지 않은 의문'을 제시**하여 시청자가 스스로 답을 찾도록 유도하는 데 초점을 맞춥니다.

#### 1. Anomaly Loop: 현실의 반복과 균열 (Looping Focus)
*   **핵심 키워드:** Anomaly Loop, Unseen Patterns
*   **영상 아이디어:** **"완벽하게 똑같은 방, 하지만 단 하나의 차이"**
    *   **콘셉트:** 시각적으로 완벽히 동일한 공간(방, 복도 등)을 반복해서 보여주지만, 아주 미세한 디테일(빛의 각도, 그림자의 위치, 물체의 미묘한 변형)이 루프 내내 변화하고 있음을 강조합니다.
    *   **후크 예시:** "당신은 이 방에 갇혀 있다. 모든 것이 똑같은데, 왜 당신의 눈은 다른 것을 보고 있는가?"
    *   **적용 모듈:** T-03 (감각적 디테일 강조) 활용 극대화.

#### 2. The Unfinished Story: 기억의 불완전성 (Memory Focus)
*   **핵심 키워드:** The Unfinished Story, Echoes of Doubt
*   **영상 아이디어:** **"기억의 조각들: 내가 경험한 사건은 진짜였을까?"**
    *   **콘셉트:** 과거의 특정 기억(사소하거나 모호했던 일상)을 재현하는 장면들을 제시하고, 각 장면에 '무언가 숨겨진 진실'이 암시되는 시각적 단서를 삽입합니다.
    *   **후크 예시:** "당신의 가장 행복했던 순간은 거짓인가? 이 영상은 당신의 기억 속에 묻어둔 미완의 이야기를 꺼낸다."
    *   **적용 모듈:** H-02 (개인화된 위협)를 통해 시청자의 내면을 직접적으로 자극.

#### 3. Subtle Glitches: 디지털 세계의 불안감 (Digital Anxiety Focus)
*   **핵심 키워드:** Subtle Glitches, Anomaly Loop
*   **영상 아이디어:** **"스크린 속의 오류: 당신이 보는 화면은 조작되고 있다"**
    *   **콘셉트:** 컴퓨터 화면, 스마트폰 앱 인터페이스 등 디지털 환경에서 발생하는 미세한 시각적 오류(글자가 잠시 사라짐, 픽셀의 왜곡, 비정상적인 깜박임)를 극도로 클로즈업하여 보여줍니다.
    *   **후크 예시:** "당신의 화면은 당신을 속이고 있다. 이 영상은 디지털 세계에 숨겨진 미묘한 오류들을 포착한다."
    *   **적용 모듈:** T-02 (논리적 모순 제시)를 통해 디지털 현실의 불신 유도.

#### 4. Echoes of Doubt: 내면의 의심 (Self-Doubt Focus)
*   **핵심 키워드:** Echoes of Doubt, Subtle Glitches
*   **영상 아이디어:** **"내 안의 목소리: 당신이 믿는 모든 것에 대한 회의감"**
    *   **콘셉트:** 인물이 혼자 고독한 공간에서 불안해하며 스스로에게 질문을 던지는 장면을 연출합니다. 외부 환경보다는 내면의 그림자와 침묵에 집중하여 시청자가 자신의 불안을 투사하게 만듭니다.
    *   **후크 예시:** "당신은 정말 괜찮은가? 이 영상은 당신 안의 가장 깊은 의심을 증폭시킨다."
    *   **적용 모듈:** T-04 (자기 성찰 유도)를 통해 시청자의 내면 불안감 극대화.
